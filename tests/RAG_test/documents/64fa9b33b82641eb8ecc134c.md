# 2023年8月13日，美国夏威夷州毛伊岛的野火造成至少80人死亡，约4500人流离失所，2207座建筑物被损坏或摧毁。

2023-08-13 10:40，正文：中新网8月13日电 综合外媒报道，截至当地时间11日晚，美国夏威夷州毛伊岛野火已造成至少80人死亡。美媒称，此次野火重灾区、海滨度假小镇拉海纳几乎被夷为平地，其大量文化遗产化成灰烬。据报道，有记录的火灾已造成约4500人流离失所，2207座建筑物被损坏或摧毁，其中大部分是住宅楼。《华尔街日报》称，目前还不能确定具体失踪人数，当地官员表示，随着搜救工作继续，死亡人数预计会进一步上升。据美国有线电视新闻网(CNN)报道，毛伊岛卡纳帕利地区的火灾现已100%得到控制，拉海纳地区的火灾85%得到控制。与消防员同行的职业摄影师丹尼尔·沙利文称，消防人员自8日起一直在“夜以继日”地工作，以扑灭大火，直升机投下了“数百加仑的水”。他表示，人们此番面临的是大规模的森林火灾，“当这些树过热时，树根就会在地下燃烧。”丹尼尔·沙利文将这场大火与席卷美国造成重大伤亡的卡特里娜飓风作比，称毛伊岛“被摧毁了，什么都没有了”。据报道，目前通往拉海纳的交通受阻，令试图将救援物资带入灾区的居民感到沮丧。一位当地餐馆老板表示，“他们(居民)无处可去……每个人都处于混乱之中，不知道该做什么。有太多无家可归的人。他们拥有的一切，他们的钱，他们的信用卡，一切都没了。”CNN称，夏威夷号称拥有全球规模最大的户外联网公共安全预警系统，部署约400个警报器，其中毛伊岛有80个警报器。但是，当大火发生时，这些警报器并没有发出警报。不少民众表示，他们没有听到任何警报，是在看到火焰或听到爆炸声时开始逃跑的。据此前报道，受干热天气和飓风“多拉”影响，有逾10万人口的夏威夷群岛第二大岛毛伊岛8日爆发野火并迅速蔓延。美国总统拜登宣布夏威夷州出现“重大灾难”，批准予以联邦支援。美国媒体称，此次野火是夏威夷自1959年建州以来死亡人数最多的自然灾害，也是美国近年来死伤最严重的野火灾害。
