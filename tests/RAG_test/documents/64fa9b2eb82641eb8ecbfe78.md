# 2023年7月30日，来自世界知名高校的30名优秀学子在珠海完成了为期15天的全球优秀青年人才暑期实践计划。

2023-8-1 14:17，正文：

 

期待到大湾区干事创业 

南方日报讯 (记者/张紫微)7月30日，“珠梦未来，海纳英才”珠海2023年全球优秀青年人才暑期实践计划正式收官。此前，30名来自世界知名高校的优秀学子来到珠海，展开15天跨境实践活动，深入了解大湾区一体化发展新气象，其中硕博士占90%以上。

活动中，青年学子们按专业分成6组，分别走进纳思达、汤臣倍健等珠海企业进行产学实践，感受珠海产业创新的动力和大湾区的发展脉搏。

“我参观了纳思达平沙产业园，深入了解了激光打印的业务布局和发展情况，还进行了实训体验，参与由导师带教、组内讨论的项目头脑风暴。”来自香港理工大学的彭昊说，通过海外项目组的实习经历提高了专业水平，接下来将继续努力，把所学的经验运用到未来的职业生涯中。

“在华发集团的实践中，我了解了珠海产业园新兴模式，这种创新的产业布局为企业带来了显著的竞争优势。”斯坦福大学学子张雨欣说。

作为向青年学子提供实践平台的企业之一，云洲智能总经理助理李春夫表示：“这次活动从全球知名高校引来了很多优秀青年人才，对企业是最好的宣传，也有利于促进人才梯队的建设。”

学子们还展开了4天跨境城市认知活动，除了参观珠海和横琴的各大景点，还走进澳门，与澳门中联办、澳门专才发展学会等展开对话交流。

活动结束后，30名青年人才被授予“校园引才推荐官”称号。他们纷纷表示，回学校后要把珠海的青春活力、多元开放和对人才友好的城市形象宣传出去，推荐更多优秀学子到大湾区干事创业。
