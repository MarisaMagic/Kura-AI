# 2022年8月16日，由上海市通信管理局指导，中国信通院、上海新兴信息通信技术应用研究院、上海电信主办的第二届“光华杯”千兆光网应用创新大赛东部大区赛在上海举行。

08-14 09:33，正文：中国证券报记者8月11日获悉，由上海市通信管理局指导，中国信通院、上海新兴信息通信技术应用研究院、上海电信主办的第二届“光华杯”千兆光网应用创新大赛东部大区赛将于8月16日起在上海举行，大赛汇集了来自上海、江苏、浙江、福建三省一市的优秀案例。千兆光网是新一代信息通信基础设施的重要组成，采用固定光纤连接，具有传输带宽大、抗干扰能力强等优势，更适合室内和复杂环境，能为各类数字化应用提供更出色的网络支持，是5G、数据中心、物联网等通信基础设施的“承载底座”。目前我国已进入推动数字化、智能化、智慧化深入发展的阶段，千兆光网和5G是新型数字基础设施的重要载体。当前，我国千兆光网已经具备覆盖超过5亿户家庭的能力，千兆宽带用户达到1.15亿户，网络能力和用户规模全球领先，我国千兆光网引领全球发展，成效显著。在千兆光网建设的基础上，普及“万兆”网络，开始列入我国网络建设的计划中。上海新兴信息通信技术应用研究院表示，2022年举办的首届“光华杯”千兆光网应用创新大赛得到了社会各界的广泛关注，在全国掀起了千兆光网应用创新的热潮，为我国新型信息基础设施赋能经济社会数字化转型和高质量发展搭建起融合创新的平台，今年的第二届“光华杯”大赛更将我国千兆光网应用创新氛围推向新高潮。上海新兴通信研究院以举办“光华杯”为契机，积极推进应用探索和场景落地，构建起创新驱动的千兆光网行业应用新生态，助力上海形成协同发展的千兆光网产业发展新格局。来源：中国证券报·中证网 作者：徐杨温馨提示：最新动态随时看，请关注金投网APP。
