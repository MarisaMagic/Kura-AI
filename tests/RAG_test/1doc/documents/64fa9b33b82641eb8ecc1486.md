# 2023年，跨境电商SHEIN宣布将在接下来的5年内投入5亿元继续深化供应商赋能，包括技术创新、培训支持、工厂扩建及供应商社区服务等方面。

08-11 11:49，正文：跨境电商SHEIN（中文名：希音）8月10日宣布，自2023年起的5年内，将投入5亿元继续深化供应商赋能。SHEIN方面表示，截至今年上半年，SHEIN已累计支持供应商工厂修建面积近24万平方米、培训超240场、同时继续推进儿童之家、聚星光等供应商社区公益，赋能供应商社区与生态的长期可持续发展，通过全方位推动供应商工厂综合能力提升，助力服装制造产业转型升级和国际化出海。SHEIN方面称，过往多年来，SHEIN持续通过按需生产“小单快反”的柔性供应链模式提升市场供应与需求的适配能力，通过技术创新推动服装生产制造商的数字化转型升级，不仅可以更好满足消费者的多元时尚需求，也从根源上更好解决困扰行业的高库存与浪费问题。未来5年，公司将投入5亿元，围绕技术创新、培训支持、工厂扩建以及供应商社区服务等多方面持续投入供应商赋能工作。其中在技术创新领域，SHEIN在行业创新打造的柔性供应链基础上，建立了其首个服装制造创新研究中心，将其按需生产的创新实践与精益生产结合进行前沿探索，并最终将精益生产解决方案赋能其全球的供应商社区，打造行业柔性供应链标准、助力制造产业升级。公开信息显示，SHEIN 2008年在南京成立，2022年4月完成了由Tiger Global Management、红杉中国、泛大西洋投资集团、顺为资本等参与的10亿美元融资。根据胡润研究院发布的《2022年中全球独角兽榜》，SHEIN以4000亿元人民币的估值位列全球第五大“独角兽”企业。来源：中国证券报·中证网 作者：田鸿伟温馨提示：最新动态随时看，请关注金投网APP。
