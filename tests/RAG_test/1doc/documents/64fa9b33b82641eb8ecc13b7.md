# 2023年8月5日，容声在深圳和无锡举行了“超薄平嵌，家居无界”平嵌系列新品十城市品鉴会，容声携平嵌系列新品与知名平台设计师同台亮相。

08-07 11:45，正文：相遇品质生活，点亮家居之美。8月5日，容声“超薄平嵌，家居无界”平嵌系列新品十城市品鉴会于深圳、无锡双城先后拉开帷幕，现场，容声携平嵌系列新品与知名平台设计师同台亮相，再度掀起一场家装美学的风暴。著名建筑师路德维希·密斯·凡德罗曾说过“Less is more”，简单的3个英文单词，却清晰表达出当下时代年轻人的审美价值观。如今，简而不陋、繁而不杂的装修风格，已成为一种家居美学的新潮流，其更加强调家居整体的美感，而随着“嵌入式”冰箱的诞生，也打开了家居与家电融合发展的新趋势。“嵌入式”冰箱通过“不凸出”的装饰风格，深刻共鸣“less isi more”的当代审美价值观，直击主流年轻群体的内心需求。奥维云网公布的数据显示，嵌入式冰箱线下市场的零售额占比从2022年的19.1%增至2023年一季度的23.1%，预计今年整体将接近30%—35%，市场的认可有目共睹。而容声作为40年的冰箱企业，去年已率先牵头发布《可嵌入式的独立式家用电冰箱》为消费者选购冰箱提供了真实有效的标准依托，填补行业空白，并先后推出容声WILL无边界冰箱605、容声双净Pro·平嵌冰箱506，以“正面不突出、侧面不留缝”的标准，赢得市场一致好评。本次活动，两款主力机型与知名设计师同台亮相，其整机60CM平嵌，无缝贴合橱柜，实现家电与家居的完美融合，打造家居一体化的全新体验，为更多家庭注入家居美感。40年笃志前行，以产品赋能设计，以设计传递美好生活。凭借领先行业的产品技术和极具前瞻性的设计理念，容声再次以美学品质生活致敬每一位消费者，为未来一体化家居持续打造新的可能性。
