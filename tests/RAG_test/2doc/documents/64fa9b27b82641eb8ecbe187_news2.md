# 2023年8月2日，法国里昂大学和比利时布鲁塞尔自由大学的研究团队在《自然》杂志上发布了两项癌症研究突破，他们发现一种名为netrin-1的蛋白质在肿瘤发展中有重要作用，且阻断该蛋白能抑制癌症的生长和转移。（news2）

另一项研究还对该试剂进行首次人体试验，展示出它对晚期子宫内膜癌个体患者的作用，表明这一抗肿瘤策略值得进一步研究。据论文介绍，随着癌症进展，它们会发生细胞层面的改变，称为上皮细胞间质转化，与肿瘤的发展、侵袭、转移和对化疗及免疫疗法的抗性有关。阻断这一转变的疗法可能是癌症治疗的一个很有前景的方法。一种名为netrin-1的蛋白质已知在一些癌症中上调，在肿瘤发展中有所作用。两项新研究表明，阻断这一蛋白可以抑制上皮细胞间质转化。第一篇论文中，论文共同通讯作者、法国里昂大学Agnès Bernet、Patrick Mehlen和同事及合作者研究发现，netrin-1在人类子宫内膜癌中会上调。在该疾病的小鼠模型中，研究表明阻断netrin-1的活性会触发癌细胞死亡，抑制上皮细胞间质转化。基于这些发现，论文作者在一项人体1期临床试验中调查了NP137的潜力，这是一种阻断netrin-1的单克隆抗体，试验包含了14名晚期子宫内膜癌患者。
