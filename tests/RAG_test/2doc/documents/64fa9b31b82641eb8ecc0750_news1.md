# 2022年10月20日，安徽阜阳杭摩科技新材料有限公司二期2号固体车间三层R2204B反应釜内发生触电事故，由于无锡市鼎丰压力容器有限公司两名维修人员违规进入事故反应釜，携带的插座连接电缆绝缘层破损，触碰到破损处外露的带电铜导线，引发触电事故，造成3人死亡，直接经济损失700.2万元。（news1）

来源：北京日报综合@微博管理员 、平安霸州、@果然视频、长江日报等
2023-08-04 10:39，正文：安徽省应急管理厅近日通报两起工贸事故：2023年7月19日，铜陵市铜陵鑫佳粉体新材料科技有限公司（以下简称鑫佳公司）发生一起粉尘爆燃事故，造成1人死亡、1人受伤。7月30日，宣城市郎溪县安徽氟士德氟塑科技有限公司（以下简称氟士德公司）发生一起可燃性气体燃烧事故，造成2人死亡、3人受伤。安徽省应急管理厅表示，安徽省政府主要负责同志、分管负责同志分别作出批示，要求查清事故责任，对企业安全管理不到位、违章违规作业等问题严肃查处、严格整改，要加强动火、高空、有限空间等特殊作业领域隐患排查和安全监管，坚决遏制事故多发势头。为深刻汲取事故教训，举一反三，坚决遏制工贸行业各类事故发生。两起事故涉及可燃性粉尘、危险化学品使用、动火作业安全管理等问题。
