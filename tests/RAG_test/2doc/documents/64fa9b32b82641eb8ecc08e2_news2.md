# 2023年8月2日，韩国全罗北道扶安郡新万金举行的第25届世界童军大露营开营仪式上，由于高温天气，共有207人中暑。（news2）

据韩联社3日报道，大露营开营仪式2日在韩国全罗北道扶安郡新万金一带举行，吸引了来自全球158个国家和地区的4.3万名14-17岁青少年参与。2日晚，韩国总统尹锡悦偕夫人金建希出席开营仪式，为参与者加油助威。然而，活动开始后不久，就陆续有大量人员因中暑被送往医院救治。高温致童军大露营百余人中暑 图源 韩媒3日，世界童军大露营组织委员会秘书长崔昌行在记者会上表示，开营仪式共造成108人中暑，加上出现头痛、腹痛症状和筋骨损伤的人员在内，共有139人受伤。而2日全天的大露营活动造成992人受伤，其中207人中暑，其他还包括被虫咬伤、消化道疾病等。据《韩国时报》3日报道，此次活动在一片滩涂上举行，由于过于开阔，无法提供足够阴凉空间。该地区白天气温达35摄氏度，帐篷内温度甚至更高。除高温外，世界各地参与者及其父母还指责活动组织方“毫无准备”“不专业”。
