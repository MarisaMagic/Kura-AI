# 2023年7月30日，巴西华人文化交流协会在里约热内卢举办了“推动中巴人文交流 助力国际传播建设”专题论坛，参与对话的包括巴西华人文化交流协会主席上官建峰、前主席尹霄敏、前主席程普等人。（news2）

李金章表示，目前，中巴关系正处于历史最好时期。新形势下增进中巴友好合作离不开华侨华人的支持、参与和奉献，希望巴西华人协会在新一届领导层带领下，继续秉承团结进取的优良传统，为祖国的繁荣发展及和平统一大业作出新的贡献，为中巴友好谱写新的篇章。中国驻圣保罗总领事陈曦也在会上致辞，希望巴西华人协会继续努力，团结全侨建设好“圣保罗华助中心”，为广大侨胞提供关爱救助，为侨胞排忧解难。巴西华人协会新任监事长刘皓表示，华协是我家，荣辱与共靠大家，巴西华人协会将秉承“爱侨爱乡，团结互助”的宗旨，扎实工作，无私奉献，为促进中巴文化经贸交流和构建和谐侨社作出新贡献。中国驻巴西大使馆政务参赞田敏，驻圣保罗副总领事胡英，驻圣保罗侨务领事李斯宁、新到任的侨务领事张于成以及巴西前联邦众议员华裔威廉·巫等也出席了就职典礼。
