# 2023年8月18日，浙江省温州市鳌江海事处在舥艚港检查发现两艘疑似自卸砂船存在多项严重违法行为。（news2）

活动当天，海警执法员还对辖区内无居民岛屿、用海项目等开展巡航检查，加强对重点海域和重点船舶污染管理情况进行监控监管，重点核查辖区内船舶非法排放生活污水、油污水等海洋倾废倾倒行为，以及非法捕捞、海洋资源非法开采利用等行为。今年6月，福州海警局在辖区海域连续查获2艘涉嫌违规倾倒废弃物的运泥船。为有效固定证据，执法员通过询问涉案人员、查询施工日志、多方走访比对等方式，最终查明上述船舶在施工期间，在未取得《废弃物海洋倾倒许可证》的情况下，将船载淤泥倾倒在福清市江阴港附近海域的事实。相关执法员指出，这两艘运泥船的行为已涉嫌违反《中华人民共和国海洋环境保护法》第五十五条之规定：未取得废弃物海洋倾倒许可证，向海洋倾倒废弃物。在事实面前，上述船舶所属公司负责人对其违法行为供认不讳。8月8日，福州海警局依法对上述两艘船舶所属公司做出罚款35万元人民币的行政处罚。
