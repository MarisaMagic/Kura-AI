# 2023年7月26日，全国专精特新中小企业发展大会在杭州召开，湖北省在第五批国家级专精特新'小巨人'企业名单中，入围企业数量达217家。（news2）

zol.com.cn/826/8268084.html
，正文：据工业和信息化部新闻宣传中心官方公众号消息，2023年全国专精特新中小企业发展大会于7月26日在浙江杭州举行。截至目前，我国已累计培育专精特新“小巨人”企业1.2万余家，专精特新中小企业超9.8万家，创新型中小企业达21.5万家。 在这1.2万家企业中，制造业企业超过1万家。超过四成的“小巨人”企业聚集在新材料、新一代信息技术、新能源及智能网联汽车领域，超过六成的企业深耕工业基础领域。 在创新能力方面，这些“小巨人”企业拥有超过20万项发明专利，户均发明专利约为17项。同时，这些企业作为主要起草单位，制订、修订标准总计4万个，户均超过3个。 在配套能力方面，“小巨人”企业普遍与大企业建立了良好的合作关系，超过九成的企业为国内外知名大企业配套。 “专精特新”企业是指具备“专业化、精细化、特色化、新颖化”特征的企业，“小巨人”企业是中小企业群体中的优秀代表。
