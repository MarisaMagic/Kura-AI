# 2023年7月24日，俄罗斯总统普京签署法案，禁止在俄罗斯进行性别重置手术（变性手术）。（news2）

报道称，乌克兰议会本月早些时候已通过该法案。法案发起者表示，这将帮助乌克兰人放弃俄罗斯传统，按照自身传统和节日生活。美联社报道称，部分乌克兰人去年已开始在12月25日庆祝圣诞节，这一举动代表着远离俄罗斯及其文化和宗教传统。乌克兰国家通讯社报道，欧盟理事会当地时间28日宣布对俄罗斯7名个人和5家实体实施限制性措施。报道称，上述个人和实体开展了数字信息操纵活动，旨在散布有关俄乌冲突的谣言。俄罗斯政府网站当地时间29日发布消息称，俄总理米舒斯京已签署法令，将出口大米的禁令延长至2023年12月31日。消息称，俄方此举是为了维护国内市场稳定。此外，该禁令不适用于俄向欧亚经济联盟国家供应的和用作人道主义援助的大米。塔斯社当地时间29日报道，俄罗斯外交部发言人扎哈罗娃在第二届俄罗斯-非洲峰会期间表示，俄罗斯通过官方及非官方渠道收到了约30项关于解决乌克兰危机的和平倡议。
