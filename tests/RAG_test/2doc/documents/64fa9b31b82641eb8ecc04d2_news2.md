# 2023年8月1日，北京，“文化中国·水立方杯”中文歌曲大赛总决赛落幕，美国西雅图赛区的肖晴赢得海外赛区青少年组的第一名。（news2）

本届“百歌颂中华”歌咏活动总决赛由中共广东省委宣传部、中共广东省直属机关工作委员会、广东省教育厅、广东省文化和旅游厅、广东省总工会、共青团广东省委员会、广东省妇女联合会、广东省文学艺术界联合会主办。于8月5日至8日在广州举行的总决赛共举办了2场合唱比赛、2场歌手（组合）比赛和2场少儿组线上评审，通过现场打分、现场亮分的方式评选出获奖选手。“百歌颂中华”歌咏活动自1994年开展至今，形式不断创新求变，品牌不断被打磨擦亮，不仅在广东省内深入人心，在全国也颇具影响力。本次活动自今年4月起在全省全面启动，由选拔赛、复赛（佛山赛区、揭阳赛区、茂名赛区）、总决赛及节目展演组成，得到了21个地级以上市及相关单位的积极响应。
