# 2023年8月4日，国家税务总局总会计师罗天舒透露，今年上半年，全国新增减税降费及退税缓费9279亿元，为民营经济、实体经济和创新驱动发展提供了有力支持。（news1）

国家税务总局28日公布，上半年，全国新增减税降费及退税缓费9279亿元(人民币，下同)。28日在北京举行的新闻发布会上，国家税务总局收入规划核算司司长荣海楼介绍，税务部门落实落细各项税费优惠政策，确保红利精准直达经营主体。上半年，全国新增减税降费及退税缓费9279亿元，其中先后实施的两批延续优化创新的税费优惠政策5832亿元、留抵退税3167亿元、其他政策280亿元。上半年，各项税费优惠政策带来的红利中，制造业及与之相关的批发零售业占比最高，累计新增减税降费及退税缓费3818亿元，占比41%。中小微企业受益最明显，新增减税降费及退税缓费5766亿元，占比62%。发布会上，国家税务总局新闻发言人黄运介绍，上半年，包括小微企业和个体工商户在内的民营经济纳税人缴费人新增减税降费及退税缓费7049亿元，占比76%，是政策惠及的主体。在7月份已提前享受研发费用加计扣除优惠的企业中，民营企业户数占比达94.3%，超过29万户，民营企业享受研发费用加计扣除金额占全部金额的76.6%。
