# 2023年7月31日，欧盟在布鲁塞尔表态支持西非国家经济共同体(西共体)对尼日尔政变采取的所有措施，要求尼日尔政变军人立即无条件恢复总统巴祖姆的职权。（news1）

（文章来源：中国新闻网）
每经AI快讯，当地时间7月30日，西非国家经济共同体（西共体）在尼日利亚首都阿布贾举行了一次讨论尼日尔近期局势的特别峰会，西共体国家元首和政府首脑委员会向尼日尔军方发出了为期7天的“最后通牒”，要求恢复宪法秩序并恢复巴祖姆的总统职务。此外，西共体决定关闭成员国与尼日尔的陆地边境，暂停西共体成员国与尼日尔之间的所有商业航班，暂停成员国与尼日尔之间的所有商业和金融交易，冻结所有服务交易，包括能源交易。西共体委员会主席在宣布这一决定时表示，成员国所有国防参谋长将召开紧急会议，制定有效的战略，实施可能的军事行动，以恢复巴祖姆的职位。他说，西共体将“采取一切必要措施恢复尼日尔共和国的宪法秩序，此类措施可能包括使用武力”。（央视新闻）
当地时间13日，尼日利亚一个代表团在与尼日尔政变军人领导人会面后发表声明说，在该代表团的斡旋下，尼日尔政变军人领导人同意与西共体展开对话。
