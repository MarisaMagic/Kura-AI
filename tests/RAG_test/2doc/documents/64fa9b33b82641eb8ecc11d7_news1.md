# 2023年8月8日，葡萄牙波塔莱格雷地区Reguengo发生山火，烧毁了数千公顷土地，迫使约1400人疏散，奥德米拉市市长赫尔德·格雷罗表示局势严峻。（news1）

8-8 13:33，正文： 中新社北京8月8日电 里斯本消息：据葡萄牙卢萨通讯社报道，葡民防部门当地时间7日表示，该国南部城市奥德米拉市5日发生野火，截至7日下午，野火以每小时过火面积超过1.25公顷的态势蔓延，迫使约1400人进行预防性疏散。 据路透社报道，高温与强风天气为灭火工作带来困难，大火已摧毁约6700公顷土地。目前有800多名消防员正在参与灭火，但火势已向南蔓延至阿尔加维。为预防起见，当局已疏散19个小村庄、4个旅游民宿和1个露营地的民众，并封锁数条道路。 目前正值夏季旅游旺季，葡萄牙等南欧国家一直在努力应对破纪录的高温天气。葡萄牙气象局7日在包括首都里斯本在内的六个地区发布了极端高温红色预警。
