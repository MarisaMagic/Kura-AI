# 2023年7月23日，NBA董事会批准黄蜂老板迈克尔·乔丹将球队出售给由加布·普洛特金和里克·施纳尔领头的集团，预计交易估值为30亿美元，将在未来1至2周内完成。（news2）

来源: 前瞻网举报/反馈
记者｜杨弋北京时间2023年6月16日晚，美国职业篮球联赛（NBA）夏洛特黄蜂队官方宣布，球队老板迈克尔·乔丹已达成出售协议，将所持大部分股权转让给由盖布·普罗特金（Gabe Plotkin）和里克·施内尔（Rick Schnall）领导的买方集团。另据ESPN报道，此次黄蜂队将以30亿美元的估值易主，而交易达成后，乔丹仍然将保留少数股权，并在球队留有一席之地。据介绍，此次收购者之一的普罗特金本就是黄蜂队的小股东；而施内尔也曾在2015年，加入以8.5亿美元收购老鹰队的财团，成为老鹰队的小股东。目前，施内尔正在出售他老鹰队的股份，预计将在几周内完成。而一旦NBA完成相关审查和批准程序，两人将正式成为球队的掌舵者，而乔丹则将结束对球队长达13年的所有权。球员时期，乔丹曾带领芝加哥公牛队完成两次NBA三连冠的壮举；而他个人也曾夺得5次常规赛MVP和6次总决赛MVP奖项，并至今保持着多项数据纪录，因此享有“篮球之神”的美誉。
