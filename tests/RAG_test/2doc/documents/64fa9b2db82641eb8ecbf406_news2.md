# 2023年8月12日，位于北纬81度附近海域，由自然资源部组织的中国第13次北冰洋科学考察队乘坐“雪龙2”号极地科考破冰船，正式开始海冰综合调查作业。（news2）

8月17日，它已在北纬84度破冰前行。中国媒体称，此次考察由中国自然资源部及其所属极地研究所组织，考察重点之一是北冰洋加克洋中脊的地质和地球物理。 科研人员还将进行大气、海冰、海洋和底质环境调查、生物群落和资源调查以及污染物监测。据第13次北冰洋科学考察队领队王金辉介绍，一个关键目标是收集该地区的基因标本。他表示，科考队通过海水和沉积物样品培养分离了130株北极菌株，提取了68份海洋生物基因标本，采集环境DNA样品9份，进一步丰富了极地基因库和海洋生物标本。 “雪龙2”号是一艘顶级的现代化科考船，为研究人员提供了高标准的设施。它为科考队提供了一个舒适的港湾，他们每天轮班进行科考工作，持续约40天。这艘122米长的破冰船上配有图书馆和健身房。有一组医生提供医疗服务，4名厨师为100多名科考队员提供均衡的饮食。 科考队负责人说，这次科考是与来自俄罗斯和泰国的伙伴合作进行的。“雪龙2”号预计于9月下旬返回上海。
