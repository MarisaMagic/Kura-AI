# 2023年7月29日，台湾爆火的大陆网络歌曲《求佛》背景音乐的“魔性舞蹈”，各大社交平台上出现了台湾网友和政治人物柯文哲跟风拍摄的影片。（news1）

网络神曲求佛在岛内爆火，一些热舞视频传到大陆社交媒体，大陆网友都吃惊“没想到《求佛》在台湾这么火!”“我们还能不能、能不能再见面，我在佛前苦苦求了几千年”，2006年的大陆网络神曲《求佛》凭借短视频的传播如今在台湾爆火，引发关于两岸文化力的思考。网络神曲求佛在岛内爆火！台湾联合新闻网30日称，一句无厘头的台词“我现在耳机里听的是誓言版的求佛”，搭配洗脑的旋律和歌词及丝滑的舞步，这股“求佛”短视频风潮席卷两岸。众多岛内网友各显神通、用《求佛》当背景音乐跳舞，连政治人物柯文哲也“混入”网红青春团体合拍一版“求佛舞”。7月12日，柯文哲到高雄为选举造势，一名支持者的女儿称，被柯文哲跳《求佛》的视频圈粉。柯文哲资料图图自台湾联合新闻网台湾《联合报》30日称，除了“求佛潮”外，台湾近期冒出不少来自大陆的街头小吃，交谈、网络用语中也都出现了“陆味”。
