# 2023年7月27日，西安战士战旗杂技团在新加坡滨海艺术中心上演新版杂技芭蕾剧《天鹅湖》，新加坡总统哈莉玛亲临现场观看。（news1）

7月27日-30日，西演·西安战士战旗杂技团新版杂技芭蕾剧《天鹅湖》将走出国门，在新加坡滨海艺术中心倾情上演，为新加坡观众献上来自中国的文化厚礼。7月24日，西演·西安战士战旗杂技团在曲江竞技中心召开“赴新演出动员会”，团长张权在启程前夕为此次赴新演职人员们带去殷殷嘱托，此次演出是团队自疫情后首次走出国门，时间紧任务重，希望大家充分发挥“战士战旗”的专业精神，互帮互助，一鼓作气，用最好的状态完成每一场演出，同时也要充分了解当地风土人情，遵守纪律法规，为新加坡观众奉上一部“兼收并蓄”的世界杂技作品。2023年是中国与新加坡建交33周年，中新建交33周年以来各项合作交流硕果累累；2023年也是“一带一路”倡议提出的10周年，新加坡作为“一带一路”重要支点国家，共建“一带一路”已成为中新合作的重点和亮点。
