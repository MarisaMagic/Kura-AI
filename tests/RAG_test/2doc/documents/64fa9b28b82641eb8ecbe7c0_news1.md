# 2023年7月28日，国务院“互联网+督查”平台开始征集阻碍民营经济发展壮大的问题线索和意见建议，以解决民营经济发展壮大面临的困难和问题。（news1）

于公众而言，已经丝毫不再陌生的国务院“互联网+督查”平台，事实上从2019年4月正式开通以来就一直高效运作，全年无休接收公众投诉反馈、汇总整理问题线索进而督促查办，通过互联网技术赋能，形成监督压力。作为呼应，此番线索征集可以说是促进民营经济发展的又一重大举措。几乎与之同步，包括国家发改委、工信部、商务部在内的多部委均在7月内召开民营企业座谈会，倾听民营企业发展困境，研讨解决民营经济实际难题，并明确“健全常态化沟通交流机制”及“加强政策支持和服务保障”。“互联网+督查”这个老熟人，专题收集整理阻碍民营经济发展壮大的问题线索，分量不可谓不重。梳理此番面向社会征集的十个方面问题线索，与《关于促进民营经济发展壮大的意见》中的具体措施密切关联，每一项具体问题的征集方向分别对应文件中“持续破除市场准入壁垒”“全面落实公平竞争政策制度”“依法保护民营企业产权和企业家权”等国家政策的禁止项。
