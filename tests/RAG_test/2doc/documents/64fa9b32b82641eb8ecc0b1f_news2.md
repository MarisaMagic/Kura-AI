# 2023年7月27日，西安战士战旗杂技团在新加坡滨海艺术中心上演新版杂技芭蕾剧《天鹅湖》，新加坡总统哈莉玛亲临现场观看。（news2）

2023年是中国与新加坡建交33周年，中新建交33周年以来各项合作交流硕果累累；2023年也是“一带一路”倡议提出的10周年，新加坡作为“一带一路”重要支点国家，共建“一带一路”已成为中新合作的重点和亮点。将要亮相新加坡的西演·西安战士战旗杂技团新版杂技芭蕾剧《天鹅湖》在创排之初就创新性地融入了西域风貌以及对大唐文明、长安文化的展现，剧目整体蕴含东西方交流的人类文明史格局，富含各美其美、美美与共的大同理念，契合共建“一带一路”的重要思想。而在27日的首演会上，演出获得的收益将悉数捐予“总统挑战”。此次受邀前往新加坡进行文化交流，是战士战旗疫情后首次海外演出，是团队弘扬中华传统杂技艺术，展示中华文化自信、彰显国家形象的一大机遇。本次战士战旗海外演出同时也将助力新加坡本地公益事业，为中、新两国之间友好往来贡献来自战士战旗的一份力量。
