# 2023年7月26日，安徽省霍山县组织开展高温期间的安全生产和消防安全大检查大排查。（news2）

强化工作场所防暑降温措施,严格落实40°C、37°C、35°C等高温情况下室外禁止作业、限时作业、减少作业时间等要求。新安晚报 安徽网 大皖客户端记者 余康生 伍静
连日来,肥西县根据统一部署,以“四零”措施迅速组织开展高温期间交通安全隐患大排査大整治,切实筑牢安全防线。彻底排査,零懈怠。按照划片分区包干,组织执法人员对全县危化品企业,旅游客运企业,开展全方位、立体式检査,不漏一家、不漏车、不漏一人。7月19日,副县长、公安局长桑祥庆深入紫蓬山片区进行检查指导,督促企业落实各项安全生产措施,抓好安全生产的“最后一公里”。截至发稿,全县“两危一客”企业已全部检査一遍,禁止高温时段承压罐体运输剧毒化学品的要求全部告知遍,对少数动态监控落实不严格的企业下发了责令整改通知书。全力除患,零遗漏。认真落实交通安全常态化检查制度,扎实推进全县危化品车辆、公路客运车辆未检验、未报废、交通违法未处理“清零”。
