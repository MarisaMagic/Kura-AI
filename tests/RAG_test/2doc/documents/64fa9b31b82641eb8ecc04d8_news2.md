# 2023年8月1日，在郑州召开的河南智慧文旅大会上，由河南省文化和旅游厅、百度、河南一百度联合打造的“河南非遗一张图”正式上线。（news2）

本次活动旨在助力河南民间文化艺术的发展、传承与创新，探索河南文旅文创融合发展新路径，全面加快推动河南文化资源大省向文化强省的战略跨越，以文化自信筑牢自信自强的中国底色。河南龙桂文化旅游发展有限公司董事长高峰表示，新郑市文化底蕴深厚，拥有8000年的裴李岗文化、5000年的黄帝文化、2700年的郑韩文化，是中华人文始祖轩辕黄帝出生、建都地。黄帝千古情景区以科技传承文化、用时尚演绎经典、用演艺活化历史，用精品来传承黄帝精神、讲好黄河故事、弘扬中原文化，把它打造成文化的新天地、中原的新名片、大家的新乐园，为实现河南更加出彩增光添彩。民间文化艺术节不仅是艺术的盛会，也是非遗传承人、创作者创作展演的大舞台。当晚，河南省文化和旅游厅非遗处，河南省非物质文化遗产保护和智慧化中心等为上榜人员颁发证书。本次活动受到社会各界的关心和关注。
