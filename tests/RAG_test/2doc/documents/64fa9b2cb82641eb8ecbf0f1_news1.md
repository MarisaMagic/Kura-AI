# 2023年8月11日，空军航空兵某团无人机大队大队长李阳，携带无人机与歼-16同框进行了训练，成功验证了某型无人机在复杂地域打击能力。（news1）

对此，中国军事专家傅前哨10日接受《环球时报》记者采访时表示，此举显示解放军正在摸索无人机与有人战机协同作战的各种战法战术。解放军无人机与歼-16战斗机罕见同框报道介绍称，李阳是解放军空军航空兵某团无人机大队大队长，先后出色完成50余项重大任务，荣立二等功1次，三等功2次，光荣当选二十大代表，今年还被评为“最美新时代革命军人”。据介绍，他曾在一次无人机试射中创下两项纪录，并成功验证了某型无人机在复杂地域的打击能力，为后续融入体系作战等提供了关键数据支撑。他还研究出10多套战法，并拓展出“无人机-”“无人机+”的作战模式，其中“‘无人机-’主要减的是后勤保障，‘无人机+’主要加的是训法战法融入体系”。李阳认为，未来战争是一种认知的对抗，“在无人装备、无人武器背后的人有什么概念、什么认知，是决定战场胜败的关键因素”。
