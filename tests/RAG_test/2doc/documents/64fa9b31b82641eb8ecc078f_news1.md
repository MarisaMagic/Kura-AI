# 2023年8月3日，国家防总向各省（自治区、直辖市）防汛抗旱指挥部、新疆生产建设兵团防汛抗旱指挥部以及国家防总各成员单位发出通知，要求全力维护人民生命财产安全，同时也对防汛救灾工作进行了一系列的指导。（news1）

国家防总于7月30日针对北京、天津、河北、山西、河南启动防汛Ⅱ级应急响应，已派出5个工作组赴重点区域协助指导防范应对工作。应急管理部联合农业农村部下发紧急通知，部署重点地区紧急调用排灌机械设备，开展救灾抢排田间积水工作。水利部要求有关省市即刻进入应急响应工作状态，做好蓄滞洪区运用准备。（来源：央视网）举报/反馈
据应急管理部消息，国家防总认真贯彻落实习近平总书记关于防汛救灾工作重要指示精神，8月3日向各省（自治区、直辖市）防汛抗旱指挥部、新疆生产建设兵团防汛抗旱指挥部，各流域防汛抗旱总指挥部以及国家防总各成员单位发出通知，要求各地各部门切实把思想和行动统一到习近平总书记重要指示精神上来，深刻领悟“两个确立”的决定性意义，把防汛救灾作为开展学习贯彻习近平新时代中国特色社会主义思想主题教育的一项重要检验，清醒认识当前防汛救灾形势的严峻性复杂性，坚持对人民群众极端负责的态度，发扬不怕疲劳、连续作战精神，采取更加有力有效措施，全力维护人民生命财产安全，以实际行动做到“两个维护”。
