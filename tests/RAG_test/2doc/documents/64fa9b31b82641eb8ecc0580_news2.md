# 2023年8月1日，日本航空公司旗下的廉航公司日本春秋航空发布了其官方虚拟形象，并启动征名活动。（news2）

这也是自2020年以来，重庆首次恢复至日本直飞客运航线。8月5日，厦门航空工作人员和旅客合影。厦门航空供图“目前，正值日本的花火大会和重庆的夏季旅游旺季，两边都值得游玩。”有在日本从事旅游行业的业界人士表示，直飞航线的恢复让日本、重庆的航空旅客不必再转机，往来更便利。按照航班计划，厦门航空重庆直飞大阪航线每周三班，每周二、四、六执飞。去程航班号MF8653，8时10分(当地时间，下同)从重庆起飞，12时45分到达大阪；返程航班号MF8654，13时45分从大阪起飞，17时10分到达重庆，起飞/降落点为重庆江北国际机场T3航站楼、大阪关西国际机场T1航站楼。广告 他只是个小司机，伺候的却是一个富太太，小人物一步步平步青云扶摇直上！ ×8月5日，旅客在重庆江北国际机场值机，准备搭乘MF8653航班飞往日本。厦门航空供图中新社记者了解到，此前，春秋航空曾开通运营重庆至大阪客运航线，后于2020年停航。
