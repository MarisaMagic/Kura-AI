# 2023年7月22日，韩国首尔，由多个韩国民间团体组织的“停战70年朝鲜半岛和平行动”举行反战游行活动，反对韩美日加强军事合作，提倡和平共存、合作共赢的亚洲。（news2）

广东、天津、黑龙江、浙江、贵州、西藏戒毒管理局领导及有关同志，广东省司法行政戒毒系统相关部门和省直戒毒场所、肇庆市强制隔离戒毒所主要负责同志参加会议。附件：责任编辑:王佳茹
