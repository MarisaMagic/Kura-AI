# 2023年8月7日，国家森防指办公室和应急管理部在内蒙古、黑龙江、新疆等地召开视频调度会议，应对近期频繁的雷击火事故。（news1）

国家森防指办公室、应急管理部于8月7日召开视频调度会，视频连线内蒙古、黑龙江、新疆等重点省区，调度雷击火防范应对情况，邀请国家森防指专家组专家分析通报近期雷击火总体火险形势。 会议指出，入夏以来，内蒙古和黑龙江大兴安岭北部林区、新疆阿勒泰地区气候突破常规，强对流天气高发，叠加严重旱情，雷击火风险高。针对严峻复杂形势，相关地区党委、政府高度重视，大兴安岭林业集团、内蒙古森工集团和国家综合性消防救援队伍、北方航空护林总站及时处置，高效扑救，基本实现了“打早打小打了”。 会议强调，近期上述地区高火险态势仍将维持一段时间，局地火险有迅速升高趋势，要不断强化责任意识和底线思维，以“时时放心不下”的责任感，坚决做好雷击火防控工作。要紧紧围绕“早发现、快处置、保安全”总要求，加强监测预警和滚动会商研判，重点做好雷电高发时段和多发地区实时监控。
