# 2023-08-08，新疆天业天伟化工有限公司化工厂厂长孙中常在现场开展周安全检查，实施严格管理并落实各项安全措施，提升公司安全生产水平。（news1）

来源：上海法治报举报/反馈
　　今日永州讯（通讯员 蒋翔）为认真贯彻落实“奋战四十天 全年保平安”安全生产攻坚行动要求，确保危化领域安全生产形势持续稳定，12月12日，祁阳市应急管理局局长王利波带队，对辖区加油站开展安全检查，帮助企业排查安全隐患，优化企业营商环境。　　在威泰加油站、中兴加油站、长益加油站、白水镇仁亲加油站等地，王利波听取了企业安全生产工作汇报，查看了加油站安全生产管理制度、员工安全教育培训、日常隐患排查、设备设施维护保养和检查检测记录、加油站值班制度、用火用电制度、应急预案演练等台账资料，重点对加油站内的储罐区、加油区、卸油区等部位的消防应急设施设备配备、加油机日常维护及使用、卸油岛静电接地装置运行等情况进行细致检查。针对检查中发现的问题，及时反馈给加油站负责人，并提出整改建议，督促落实到位。
