# 2023年8月5日，侵华日军第七三一部队罪证陈列馆在黑龙江省牡丹江市首次公布《日军哈尔滨第一陆军病院原簿》。（news1）

【责任编辑：于璧嘉】
来源：中国青年报客户端，正文： 中国青年报客户端北京8月18日电（中青报·中青网记者 胡文利）8月5日，哈尔滨市侵华日军第七三一部队罪证陈列馆与中共牡丹江市西安区委员会联合举办“侵华日军细菌战罪证陈列”展览及相关研讨会，首次对外公布《日军哈尔滨第一陆军病院原簿》。在中国外交部8月18日下午举行的例行记者会上，发言人汪文斌表示，有关历史资料再次表明日本军国主义发动细菌战的事实铁证如山，不容否认和抵赖。外交部发言人汪文斌。图片来自外交部汪文斌表示，第二次世界大战期间，侵华日军公然违反国际法，对中国人民发动了令人发指的细菌战，进行了惨无人道的人体活体试验，犯下了反人类的滔天罪行。日方应正视并深刻反省日本军国主义侵略历史，以史为鉴、消除遗毒，不要重蹈覆辙。
