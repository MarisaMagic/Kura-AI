# 2023年8月1日，中共中央政治局委员、国务院副总理张国清赶赴北京市门头沟区，指导防汛抢险救灾工作，呼吁全力做好抢险救援应急处置，尽快恢复正常生产生活秩序。（news1）

他强调，要坚决贯彻习近平总书记重要指示精神，落实李强总理要求，积极应对极端强降雨影响，全力做好抢险救援应急处置，尽快恢复正常生产生活秩序，确保人民群众生命财产安全，确保社会大局稳定。（新华社）举报/反馈
据新华社北京8月1日电 受党中央、国务院委派，中共中央政治局委员、国务院副总理张国清8月1日中午率有关方面负责同志，紧急赶赴北京市门头沟区指导防汛抢险救灾工作。他强调，要坚决贯彻习近平总书记重要指示精神，落实李强总理要求，积极应对极端强降雨影响，全力做好抢险救援应急处置，尽快恢复正常生产生活秩序，确保人民群众生命财产安全，确保社会大局稳定。
