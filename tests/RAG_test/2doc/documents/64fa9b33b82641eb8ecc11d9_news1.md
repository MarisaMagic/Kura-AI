# 2023年7月6日，意大利政府决定对本国银行因高利率获取的巨额利润一次性征收40%的税，此举引发了欧洲整个银行业的轩然大波。（news1）

2023-08-09 16:17，正文：智通财经APP获悉，意大利就其针对银行征收暴利税的计划发布了一份澄清声明，称该计划对一些银行的影响可能有限，税款不会超过银行总资产的0.1%，而不是此前所谓的“从银行数十亿欧元的额外利润中征收40%的税项”。意大利财政部在周二晚间的一份声明中表示，已经提高了存款利率的银行“不会受到批准的计划的重大影响”。在意大利放松对银行征税的立场的影响下，截至发稿，泛欧斯托克600指数涨0.86%，触及一周以来高点。欧洲银行股则涨1.4%，意大利最大的两家银行——联合圣保罗银行和(Intesa Sanpaolo SpA)和联合信贷银行(UniCredit SpA)——的涨幅在1.7%至2.5%之间。此前，意大利总理梅洛尼所领导的内阁出人意料地批准了今年对银行“额外利润”征税的计划。据报道，这项税收将为国库带来超过20亿欧元(22亿美元)的收入。意大利副总理马泰奥表示，意大利同意在2023年“从银行数十亿欧元的额外利润中征收40%的税项”，这笔资金将用于减税和支持首次购房者的抵押贷款。
