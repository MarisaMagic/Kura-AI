# 2023年7月28日，中国海军“和平方舟”号医院船在执行“和谐使命-2023”任务的过程中抵达汤加王国努库阿洛法港，进行为期7天的友好访问并开展医疗服务。（news1）

(完)
2023-07-28 20:06:11，正文：中新社努库阿洛法7月28日电 (徐巍 李珂嘉贺 刘博)执行“和谐使命-2023”任务的中国海军“和平方舟”号医院船28日上午抵达任务第二站汤加努库阿洛法港，对汤加王国进行为期7天的友好访问并提供人道主义医疗服务。这是和平方舟第三次访问汤加。10时许，在汤海军巡逻艇“银箭”号的引导下，和平方舟缓缓驶抵努库阿洛法港乌纳码头。汤方在码头举行了隆重的传统欢迎仪式，汤加皇家军乐队演奏中汤两国国歌，当地民众向“和谐使命-2023”任务指挥员献上花环，表演民族舞蹈，吟诵赞美诗并祈祷。汤加首相胡阿卡瓦梅利库及内政大臣、军方参谋长助理等官员，中国驻汤加大使曹小林、武官王伟及使馆工作人员，当地民众、华侨华人和中资机构代表等在码头迎接。欢迎仪式上，胡阿卡瓦梅利库代表汤方热烈欢迎和平方舟第三次到访，由衷感谢中国政府和人民一直以来对汤加的真诚帮助。
