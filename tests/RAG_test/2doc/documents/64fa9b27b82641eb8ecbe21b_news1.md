# 2023年8月16日，中国科学院院士、中国医学科学院学部委员杨正林在海南大学南繁种业与生命健康院士论坛上揭示脂代谢异常致盲机制。（news1）

此次，新的脂质血管“邮政编码”被发现，和配体配对成功后，它能对肺部疾病的监测和诊断起到积极作用。未来，若能找到更多“邮政编码”，就能形成四通八达的药物递送网络，使更多患者从中获益。
2023-08-16，正文：8月15日，2023年第二十届京台青年科学家论坛在京举办。北京市科协党组书记、常务副主席沈洁在致辞中表示，京台青年科学家论坛是两岸民间科技界共同培育和打造的重要交流平台，已连续走过了二十个春秋，见证了两岸科技工作者在开展民间科技交流合作、深化京台融合发展的扎实成效。北京市科协将继续发挥好联系两岸科技工作者桥梁纽带作用，秉持“两岸一家亲”理念，持续深化京台科技人文交流合作。国际欧亚科学院院士、北京大学邬伦教授，台湾东华大学校长、台湾信息学会理事长赵涵捷教授，围绕加强京台科技交流、促进两地融合发展作开幕主旨报告。
