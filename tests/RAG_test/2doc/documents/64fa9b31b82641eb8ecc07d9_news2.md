# 2023-08-08，新疆天业天伟化工有限公司化工厂厂长孙中常在现场开展周安全检查，实施严格管理并落实各项安全措施，提升公司安全生产水平。（news2）

对年纪较大、身体有疾病的工人要心中有数，给予关照。工地要准备好茶水、防暑药品，做好防中暑工作，杜绝发生因高温导致人员伤亡情况。孙立新一行还仔细检查了施工现场、听取施工安全情况介绍，要求按照安全生产法律法规和规范标准严格组织施工，对交办的问题彻底整改到位，切实消除安全隐患，坚决杜绝安全生产事故发生。在仔细检查扬尘治理措施落实情况过程中，孙立新一行对工地范围硬化道路、建立洗车平台、喷雾降尘、有效管理建筑垃圾等做法给予肯定。在芙蓉名著、芙蓉学苑等房地产开发项目，孙立新一行要求抓好工程质量、安全生产，以质量吸引顾客，向安全生产要效益。据了解，自7月28日双峰县住建局新的领导班子组建后，就将建筑施工监管与服务列入了重要工作议程，关心关注建筑施工将成为常态。
