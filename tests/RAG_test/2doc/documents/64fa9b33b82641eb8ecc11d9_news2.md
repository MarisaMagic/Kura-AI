# 2023年7月6日，意大利政府决定对本国银行因高利率获取的巨额利润一次性征收40%的税，此举引发了欧洲整个银行业的轩然大波。（news2）

责任编辑：李桐
08-10 02:17，正文：财联社8月10日讯（编辑 史正丞）在短短一天时间里，面对着资产市场传递出的压力，意大利极右翼政府忙不迭地稀释颇为吸引眼球的“40%银行暴利税”带来的冲击。当地时间周一晚间，意大利副总理萨尔维尼表态称，将针对意大利银行业因欧央行加息获得的额外盈利征收40%的暴利税。这些钱将用于减税和向首次购房者发放贷款补贴。随后，勤奋的分析师们不得不熬夜加班，试图给投资者们厘清这个突发事件的影响。虽然意大利政府预期“银行暴利税”大概能增加30亿欧元的收入，但Banor Capital的证券主管Gianmarco Rania周三对媒体复盘称，在周二一整天时间里，分析师们纷纷拿出自己的成果，如果按照意大利政府的表述，“银行暴利税”的所得将远远超过30亿欧元，大概要到45-50亿左右。Rania解释称，按照最初的讲法，意大利中小规模银行的2023年利润，可能会受到20-25%的影响，大银行也要面对8-15%的冲击。
