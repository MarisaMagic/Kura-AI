# 2023年7月28日，乌克兰使用改装为打击型的S-200防空导弹对俄罗斯罗斯托夫州塔甘罗格市的民用基础设施实施打击，但导弹被俄军防空系统拦截，其残骸坠入市区，导致十余人受伤。（news1）

俄总统普京已听取相关汇报。俄国防部在声明中称，乌克兰使用改装为打击型的S-200防空导弹对塔甘罗格发动袭击。俄防空系统发现并拦截了导弹，其碎片落在塔甘罗格市区。据塔斯社报道，被击落的导弹在塔甘罗格市艺术博物馆所在区域发生爆炸，但未引发火灾。袭击导致该市博物馆、咖啡馆和公寓楼等建筑受损。塔斯社援引俄卫生部联邦灾难医学中心消息称，目前受伤人数已达16人，其中一人伤势严重。俄总统新闻秘书佩斯科夫表示，普京已获悉罗斯托夫地区遭袭的消息。当天晚些时候，俄国防部再度通报称，乌军再次试图使用改装为打击型的S-200防空导弹实施袭击，俄防空系统在罗斯托夫州亚速市附近成功拦截了这枚导弹，残骸坠入无人区域，地面上没有人员受伤。塔斯社称，美国国家安全委员会战略沟通协调员约翰·柯比表示，美国已明确表示“不鼓励或协助对俄境内发动袭击”。
