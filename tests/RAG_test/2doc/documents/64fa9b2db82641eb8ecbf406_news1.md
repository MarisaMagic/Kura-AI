# 2023年8月12日，位于北纬81度附近海域，由自然资源部组织的中国第13次北冰洋科学考察队乘坐“雪龙2”号极地科考破冰船，正式开始海冰综合调查作业。（news1）

7月12日，中国第13次北冰洋科学考察队搭乘“雪龙2”号从上海出发，前往北冰洋执行科学考察任务。过去12天里，“雪龙2”号经东海、日本海、鄂霍次克海、白令海等海域一路北上，穿越白令海峡，顺利抵达北极圈。进入北极圈后，考察队将继续向着预定作业地点航行。根据日程安排，“雪龙2”号预计将于26日航行至楚科奇海盆，考察队将正式开展大洋科考作业。新华社记者 魏弘毅 摄这是7月25日从“雪龙2”号极地科考破冰船拍摄的北极圈内的浮冰。7月25日，穿越北极圈后，浮冰逐渐增多，“雪龙2”号极地科考破冰船驾驶员加强对前方海况和冰情的瞭望。这是7月25日从“雪龙2”号极地科考破冰船驾驶台拍摄的景色。举报/反馈
