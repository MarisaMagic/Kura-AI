# 2021年8月3日，受台风“杜苏芮”影响，北京房山区张坊镇穆家口村农户穆先生的23亩果树受损，人保财险北京分公司迅速赔付9.2万元。（news1）

”太平洋财险房山支公司业务经理告诉记者，现在公司本着特事特办、应赔尽赔、简化或后补手续的原则，一旦确定了受损情况，都会尽快给农户打款。最终，根据农作物的受损情况和生长周期进，公司确定赔付该生态基地为7万余元。并于8月8日，将理赔款赔付给生态基地。“速度还是挺快的。”该生态基地负责人表示。房山受灾农户赔付进展！面对暴雨灾害带来的影响，房山区农业农村局主动上前，及时联系政策性农业保险承包公司，按照“快查勘、快定损、快赔付”原则，加快受灾农户理赔工作，最大限度保障农民利益。区农业农村局积极做好因暴雨受灾农户理赔工作：督促政策性农业保险承包公司主动对接投保农户，最大限度地保障农民利益。自7月29日到8月4日，核实受损温室大棚257亩，玉米678亩，葡萄、桃、李子、核桃等5385.8亩，涉及农户820多户。截至8月7日，我区政策性农业保险共赔付温室大棚、果树树体等99.26亩，累计赔付金额80.
