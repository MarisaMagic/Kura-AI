# 2023年7月23日，NBA董事会批准黄蜂老板迈克尔·乔丹将球队出售给由加布·普洛特金和里克·施纳尔领头的集团，预计交易估值为30亿美元，将在未来1至2周内完成。（news1）

一旦获批初步预计这笔交易将在几周内完成。今年2月，根据《福布斯》的年度报告，所有30支NBA球队的估值首次达到或超过12亿美元。其中，夏洛特黄蜂队以12.5亿美元的估值位居第28名：夏洛特黄蜂队(Charlotte Hornets)是一支位于美国北卡罗来纳州夏洛特的职业篮球队，其前身夏洛特山猫队于2004年建队并加入美国男篮职业联赛(NBA)，是NBA联盟最年轻的球队。现从属于NBA东部联盟的东南赛区。2010年3月19日，经联盟董事会通过，迈克尔.乔丹在夏洛特与球队前任老板约翰逊完成交接，正式接手夏洛特山猫队(黄蜂队的前身)。来源: 前瞻网举报/反馈
记者｜杨弋北京时间2023年6月16日晚，美国职业篮球联赛（NBA）夏洛特黄蜂队官方宣布，球队老板迈克尔·乔丹已达成出售协议，将所持大部分股权转让给由盖布·普罗特金（Gabe Plotkin）和里克·施内尔（Rick Schnall）领导的买方集团。
