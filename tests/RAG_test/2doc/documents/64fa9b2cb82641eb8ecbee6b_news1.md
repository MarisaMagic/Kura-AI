# 2023年7月下旬，位于武汉新洲区双柳街的武汉同济航天城医院正式开业。（news1）

来源：新洲发布微信公众号据了解，武汉同济航天城医院占地面积200多亩，包含200张公共卫生应急床位和800张常规医疗床位，2022年12月26日取得三级综合医院医疗机构执业许可证，12月28日开始试运营。医院设有内科、外科、妇产科、儿科、眼科、耳鼻咽喉科等29项一级诊疗科目，同时配有新洲首台128排螺旋CT，实时四维心血管彩色多普勒超声诊断仪、X线血管造影系统（DSA）、核磁共振、电子胃肠镜等医疗设备，能够规范开展医疗救治服务。武汉同济航天城医院。记者任勇 摄同济医院相关负责人表示，试运营阶段，同济医院持续派驻专家，通过开设门诊、手术、病例会诊等方式，快速聚集优势技术为周边群众提供优质、安全、便捷的医疗服务。接下来，同济医院将为武汉同济航天城医院移植先进的管理模式、培训先进的医院文化、输入先进的诊疗技术、建立先进的服务体系。
