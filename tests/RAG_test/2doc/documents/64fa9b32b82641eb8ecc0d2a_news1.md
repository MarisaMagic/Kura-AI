# 新沂御品名庄食品有限公司拟处置位于江苏省新沂市新店镇的土地使用权、房屋建筑物、在建工程、机器设备、库存商品及厂区内苗木等资产。（news1）

鉴于当事人已履行了进货查验义务，能如实说明进货来源，积极配合案件调查，根据《中华人民共和国食品安全法》第一百二十七条和《浙江省食品小作坊小餐饮店小食杂店和食品摊贩管理规定》第二十三条第一款第(九)项的规定，嵊州市市场监督管理局决定对当事人免于处罚。潇湘晨报综合
，正文：大众网记者 陈姿羽 通讯员 马斌杰 东营报道8月4日，河口区退役军人事务局、河口区工商联共同举行“荣军联盟”授牌仪式，为成员单位东营农商银行河颐支行颁授牌匾。河口区“荣军联盟”是由区退役军人事务局发起成立，通过招募全区范围内的商贸商超、金融保险、餐饮娱乐、医疗康养、交通物流、教育培训、网络通信等各类企业、商家、机构作为成员单位，为现役军人、持有“全国优待证”的退役军人提供优惠优待的一个荣军服务组织。
