# 2023年8月15日，吉林省推广焊接与切割作业安全信息查询平台，实现焊接与切割作业的信息化监管。（news2）

全面排查，强化整治。鲁西新区应急管理局坚持把安全执法检查作为安全监管的基础工作，组织安全生产执法精干力量开展全方位、地毯式的检查。据了解，活动开展以来，共出动检查组11个，人员106人次，检查企业33家次，排查问题隐患83项，其中作业准备方面问题11项，作业现场管理方面问题36项，违法违规施工方面问题1项，教育培训方面问题14项，消防演练方面问题8项。中国山东网记者 袁素环 通讯员 袁国栋 报道举报/反馈
7月18日，山东省人民政府安全生产委员会办公室印发关于《关于开展违规电气焊作业和违规施工专项整治的方案》的通知，《方案》指出，自即日起至12月31日，全省将集中开展违规电气焊作业和违规施工专项整治。本次专项整治范围涉及全省范围内涉电气焊作业和违规施工作业的各社会单位，重点是人员密集场所、多业态合用场所、“厂中厂”以及医院、养老院、学校幼儿园、文博单位、建筑施工工地、劳动密集企业、危化企业、化工罐区等敏感特殊场所。
