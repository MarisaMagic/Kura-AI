# 2023年8月1日，根据欧盟委员会推出的5G观察报告，早期排除中国5G供应商的欧盟国家在5G网络人口覆盖率上大幅度落后，其中瑞典的5G网络人口覆盖率仅略高于20%，位列所有27个国家的最后。（news2）

比利时和罗马尼亚更落后，分别约为30%和27%，瑞典以略高于20%的人口覆盖率排在所有27个国家的末尾。　　此外，在欧盟委员会的数字经济与社会指数（DESI）中，瑞典在互通性领域的排名从第二(2020年)下降到第九(2022年)，比利时从第6位跌至第27，爱沙尼亚从第14跌至第26，拉脱维亚从第4跌至第20，罗马尼亚从第11跌至第15。　　德媒称，这种排除(中企)的负面影响在英国也很明显。华为最初于2020年1月获得英国批准，但几个月后被排除在英国5G扩展之外。美国网速测试统计公司Ookla今年2月警告称，英国的平均下载速度继续向着相当低的水平缓慢下滑。　　丹麦电信分析师约翰·斯特兰德的市场研究显示，塞浦路斯是唯一一个100%从中国供应商(即华为和中兴通讯)获得5G天线的欧盟国家。在欧盟委员会5G观察报告中，塞浦路斯以100%的5G人口覆盖率位居欧洲第一。
