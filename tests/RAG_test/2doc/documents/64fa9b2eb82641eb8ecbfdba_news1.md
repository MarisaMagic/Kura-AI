# 2023年7月30日，巴西华人文化交流协会在里约热内卢举办了“推动中巴人文交流 助力国际传播建设”专题论坛，参与对话的包括巴西华人文化交流协会主席上官建峰、前主席尹霄敏、前主席程普等人。（news1）

中国驻里约热内卢总领事陈小玲、数百位当地华侨华人代表以及正在里约进行慰侨演出的国务院侨办“文化中国·四海同春”赴南美艺术团全体成员出席了此次典礼。陈小玲在致辞中肯定了该协会多年来在增进巴西华侨华人与祖（籍）国情感沟通，以及推动中巴两国民间文化交流方面所作的贡献。尹相丛在就职典礼上表示，该协会在过去几年里坚持协会宗旨，努力传播中华文化、打造跨文化交流平台，并且在维护中国和平统一、促进侨社和谐发展等方面做了大量工作，取得丰硕成果。巴西华人文化交流协会创立于２０００年，以“开展文化交流、弘扬中华文化”为己任，经过十余年的发展，目前已成为巴西有影响力的侨团之一。该协会连续多年协助国侨办和中国侨联在里约市举办“文化中国·四海同春”以及“亲情中华”艺术团慰问演出。
