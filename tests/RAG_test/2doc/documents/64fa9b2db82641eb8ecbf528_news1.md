# 2023年7月18日，中国第26批赴刚果（金）的维和工兵在刚果（金）东部卡莱亥地区成功完成鲁济拉桥梁的救援工程，为灾区的交通恢复提供了重要保障。（news1）

张琦摄中国赴刚果(金)维和工兵分队组织岗哨交接。张琦摄人民网约翰内斯堡9月24日电(记者闫韫明)当地时间9月23日，中国第26批赴刚果(金)维和工兵分队与第27批维和工兵分队在南基武省布卡武市的中国半岛营区内圆满完成了第26次轮换交接，这也标志着中国第27批赴刚果(金)维和工兵分队将正式履行联合国赋予的维和任务。连日来，两批维和官兵对车辆机械、武器装备、办公物资、通信设备、物资器材、医疗用品等多项内容进行了交接，并围绕任务区当前安全形势、执行任务的注意事项和经验技巧进行交流和学习，确保各个环节能够无缝衔接。据了解，中国第27批赴刚果(金)维和工兵分队主要担负任务区内的工程保障、道路抢修、桥梁架设、机场构筑、人道主义援助等任务，为当地民众和联合国驻刚果(金)稳定特派团各维和部队提供有利援助。根据计划安排，中国第26批赴刚果(金)维和工兵分队第二梯队108名官兵将于本月下旬从戈马机场启程回国。
