# 2023年8月18日，中国铁路武汉局集团有限公司推出“武汉+武当山+襄阳”及“武汉+神农架+襄阳”旅游计次票业务，旅客可以通过12306网站、12306手机APP购买。（news2）

其中武汉、汉口两站和神农架、兴山两站分别实现同城乘车，旅客可根据需要选择在其中一站上下车。两种旅游计次票有优惠吗？记者以“武汉+武当山+襄阳”为例算了一笔账，以所能购买的最高价车票计算，汉口至武当山西，二等座票价242元；武当山西至襄阳，二等座票价84元；襄阳东至汉口，二等座票价145元，共计471元，比420元多出51元。“如果往返次数较多，则优惠体现更明显。”武铁客运部相关负责人介绍，此次推出的旅游计次票，主要是满足旅客个性化、差异化需求。计次票不限定车次，旅客可选择乘坐任意停靠相应区间的动车组列车，未使用可全额退款，产品启用后9天内有效。据悉，旅客可通过席位预约和直接刷证两种方式乘车。席位预约即在12306网站等平台提前预约产品所对应的发到站及座位。直接刷证即乘车人可持购买产品时所使用的有效身份证原件，直接进站刷证检票获取席位乘车，但该方式前提为相应车辆有剩余座位。
，正文：8月15日，北京市市场监管局对北京市儿童鞋产品质量监督抽查结果进行公示。
