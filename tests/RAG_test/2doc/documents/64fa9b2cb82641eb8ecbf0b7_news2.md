# 2023年8月7日，美国和伊朗在霍尔木兹海峡增强战力，伊朗伊斯兰革命卫队为其海军配备了一批新型无人机和导弹等武器装备，美国可能将向途经霍尔木兹海峡的商船派遣武装船员和海军陆战队员。（news2）

与此同时，美国向该地区派遣了更多战斗机，以“阻止伊朗在波斯湾地区劫持商船”。报道称，据伊通社消息，11个伊朗空军基地参加了此次名为“最高领袖奉献者-11”的军事演习。位于霍尔木兹海峡入口处阿巴斯港的一个空军基地参加了演习。霍尔木兹海峡是波斯湾的狭窄入口，全球20%的原油都要经过这里，战略地位重要。伊朗空军将有超过90架战斗机、轰炸机和无人机将参加此次演习。伊朗空军司令哈米德·瓦赫迪将军说，此次演习传递的信息是该地区的友谊、和平与安全。他说：“可持续安全、改善和促进地区关系、和平共处以及保卫空中边界都在议程上。”报道称，伊朗不时举行此类演习，称这些演习的目的是评估部队的战备状态，并展示该国的军事实力。报道指出，美国上周表示，将向霍尔木兹海峡和阿曼湾增派战斗机和一艘军舰，以加强安全。五角大楼称，美海军“托马斯·哈德纳”号驱逐舰和数架F-35隐身战斗机将派往该地区。
