# 2023年8月1日，在郑州召开的河南智慧文旅大会上，由河南省文化和旅游厅、百度、河南一百度联合打造的“河南非遗一张图”正式上线。（news1）

河南省文化和旅游厅非遗处、知名专家学者、来自省内各地的非遗传承人，以及黄帝千古情景区主要负责人、媒体人士等一百余人参加活动。河南省非物质文化遗产保护和智慧化中心主任李全民在致辞中提到，河南历史悠久、文脉厚重、文化旅游资源丰富，河南作为一个文化资源大省，文化形态多样，民俗文化资源十分丰富。近年来，随着国潮和互联网的兴起，跨界融合和触网成为非遗保护传承新趋势，河南非遗也在不断推陈出新，“河南非遗代表性项目热搜榜”“河南非遗代表性传承人热搜榜”频频火爆出圈，“河南非遗一张图”首创非遗可视化知识图谱，进一步激发了非遗保护传承的内生动力。本次活动旨在助力河南民间文化艺术的发展、传承与创新，探索河南文旅文创融合发展新路径，全面加快推动河南文化资源大省向文化强省的战略跨越，以文化自信筑牢自信自强的中国底色。
