# 2023年8月18日，浙江省温州市鳌江海事处在舥艚港检查发现两艘疑似自卸砂船存在多项严重违法行为。（news1）

相关执法员指出，这两艘运泥船的行为已涉嫌违反《中华人民共和国海洋环境保护法》第五十五条之规定：未取得废弃物海洋倾倒许可证，向海洋倾倒废弃物。在事实面前，上述船舶所属公司负责人对其违法行为供认不讳。8月8日，福州海警局依法对上述两艘船舶所属公司做出罚款35万元人民币的行政处罚。自2019年挂牌成立以来，福州海警局始终坚持守海有责、守海担责、守海尽责，累计查处海洋类行政案件279起，查获无合法齐全手续海砂80余万吨、渔获物14.5万公斤，有效保护了辖区海域海洋生态环境。福州海警局负责人表示，将加大海上巡逻密度，强化敏感海域监管力度，以整治海洋资源环境突出问题和打击涉渔违法犯罪为重点，持续深化打击成果，不断为海洋生态建设和海洋资源保护贡献海警力量。(完)
