# 2023年7月19日，广西壮族自治区本级土地推介会在南宁成功举办，推介22幅约2978亩优质地块，6家企业意向投资签约土地共389.16亩。（news2）

克而瑞信息集团广西区域副总经理韦凤仙对2023年度广西壮族自治区本级22幅优质地块进行重点推介。据介绍，2023年度广西壮族自治区本级土地优质推介地块22幅，分布在南宁、柳州、桂林、来宾、崇左5个设区市，合计面积约2977.96亩，单幅地块规模在13亩至365亩不等，涵盖住宅、商业、仓储等诸多用途，用地选择面广，投资方向多元化。其中，南宁数量和面积占比最高，共10幅地块，合计约1223.88亩，分布在青秀、兴宁和经开区三大区域；柳州和桂林各1幅，分别为鱼峰区约187亩商住地块和雁山区约292.29亩纯住宅地块；来宾7幅，分布在河西片区、城南新区、华侨投资区、城北区，合计约704.79亩，均为商住地块；崇左3幅，分布在江州区和扶绥县空港经济区，合计约570亩，不乏超200亩的大地块。本次推介部分地块可根据企业的投资需求和周边配套等情况，采用灵活的供应方式，还可以为企业提供一对一精准服务，土地资源配置更优化，更契合市场需求。
