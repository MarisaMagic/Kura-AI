# 2023年7月20日，欧洲环境署公布报告指出，空气污染是欧洲最大环境健康风险，2021年欧洲联盟13个成员国未能兑现减排承诺。（news2）

付璐建议， “十四五”期间，应尽快建立多部门、多行业对空气与气候协同治理的共识、形成中长期各规划之间的协同，结构调整应采取总量控制与措施灵活并重的策略。有条件的城市，应通过包括成本-效益分析等多种政策分析手段，识别能够促进减污降碳协同增效的措施组合，优化减排路径。值得注意的是，近期，世界卫生组织在更新版《全球空气质量指南》中从严限定了多项污染物的健康指导值。为此《报告》建议，我国应在“十四五”期间适时考量修订中国国家标准，收紧包括PM2.5和臭氧在内的污染物限值，并研究增设臭氧长期目标值。
新京报快讯（记者 邓琦）12日上午，生态环境部发布2019年3月和1至3月全国空气质量。今年前3月，全国168个重点城市中，山西临汾空气质量最差，再次垫底。具体排名显示，2019年3月，168个重点城市中淄博、枣庄、潍坊、临沂市等20个城市空气质量相对较差（从第168名到第149名）；海口、拉萨、深圳市等20个城市空气质量相对较好。
