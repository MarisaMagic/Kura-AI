# 2023年8月18日，中国铁路武汉局集团有限公司推出“武汉+武当山+襄阳”及“武汉+神农架+襄阳”旅游计次票业务，旅客可以通过12306网站、12306手机APP购买。（news1）

李纪堂摄人民网武汉8月16日电 (记者肖璐欣、张隽)记者从中国铁路武汉局集团有限公司获悉，8月18日起，武铁开通汉十高铁、郑渝高铁旅游计次票，汉十高铁、郑渝高铁旅游计次票包括“武汉+武当山+襄阳”及“武汉+神农架+襄阳”两款，分别定价为420元和445元。旅客可通过12306网站、铁路12306APP购买，并享受一定优惠。“武汉+武当山+襄阳”旅游计次票包含“汉口(武汉)—武当山西”“武当山西—襄阳东”“襄阳东—汉口 (武汉)”三段行程各 1 张二等座车票；“武汉+神农架+襄阳”旅游计次票包含“汉口(武汉) —神农架(兴山)”“神农架(兴山)—襄阳东”“襄阳东—汉口 (武汉)”三段行程各 1 张二等座车票。其中武汉、汉口两站和神农架、兴山两站分别实现同城乘车，旅客可根据需要选择在其中一站上下车。两种旅游计次票有优惠吗？
