# 2023年7月26日，全国专精特新中小企业发展大会在杭州召开，湖北省在第五批国家级专精特新'小巨人'企业名单中，入围企业数量达217家。（news1）

到2023年，武汉市级“专精特新”培育企业超过1200家，省级专精特新“小巨人”企业达到500家，争创国家级专精特新“小巨人”企业260家。专精特新即专业化、精细化、特色化、新颖化。专精特新小巨人企业，是专精特新企业中的佼佼者，即专注于细分市场、创新能力强、市场占有率高、掌握关键核心技术、质量效益优的排头兵企业。行动计划提出，实施中小企业成长工程。大力培育市场主体，进一步优化企业开办服务，推动“证照分离”改革事项全覆盖，力争年均新登记市场主体20万户以上。对获批国家、省级专精特新“小巨人”企业，市级财政分别给予50万元、20万元奖励。行动计划提出，支持“专精特新”企业独立或者联合高等院校、科研院所共建研发机构，实现“专精特新”企业研发机构全覆盖。采取政府引导、市场化运作、开放服务方式，建设一批中小企业公共技术服务平台。支持“专精特新”企业开展高价值专利组合培育，对符合条件的项目，一次性给予50万元支持。武汉将推进“专精特新”企业智能化转型全覆盖。
