# 2023年7月下旬，位于武汉新洲区双柳街的武汉同济航天城医院正式开业。（news2）

其中,同济医院国家重大公共卫生事件医学中心是这是首个在北京、上海之外设置的国家级医学中心,也是全国第六个国家级医学中心,预计在3-5年内完成规划建设。协和医院质子医学中心项目用地约50亩,一期拟投入7亿元,建设面积2.55万平方米,拟设3个治疗舱、实验室,配套相应设备设施。该中心是国家明确建设的5家质子中心之一,将填补武汉市尖端肿瘤治疗技术的空白。据介绍,六个项目的总投资加起来超过100亿元,是近几年来武汉市公共卫生领域最大的投入。今天6大项目正式开工,“四区”重点项目将于2021年完工投用,“两院”项目将于2至5年内完工投用。【责任编辑:艾师伟】
7月21日位于武汉新洲区双柳街的武汉同济航天城医院正式投用武汉都市圈又添一个综合性三级医院武汉同济航天城医院。来源：新洲发布微信公众号据了解，武汉同济航天城医院占地面积200多亩，包含200张公共卫生应急床位和800张常规医疗床位，2022年12月26日取得三级综合医院医疗机构执业许可证，12月28日开始试运营。
