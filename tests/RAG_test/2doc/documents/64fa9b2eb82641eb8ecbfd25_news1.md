# 2023年7月27日，中国驻日本大使馆在东京举行招待会，庆祝中国人民解放军建军96周年，吴江浩大使和皇甫群星少将分别致辞。（news1）

中新社曼谷八月一日电(记者 顾时宏)中国驻泰国使馆国防兼海、空军武官安作山少将夫妇七月三十一日晚在泰国曼谷香格里拉饭店举行“八一”建军节招待会，隆重庆祝中国人民解放军建军八十周年。中国驻泰王国大使张九桓夫妇参加了招待会。泰国国安会主席兼陆军司令颂提上将、国防部长本洛上将、最高副司令派洛上将、海军参谋长威拉蓬上将、特战部队司令素莱中将、制宪委员会主席巴颂先生、总理府副秘书长帕拉达先生等泰国政府和军队高级官员、社会各界人士、驻泰使团和武官团人员、驻泰中资机构代表、华人华侨及留学生等五百五十余人应邀出席了招待会。招待会气氛热烈友好，来宾纷纷对中国建军节表示祝贺，对近年来中国政治经济发展、军队现代化建设所取得的突出成就深表赞赏，并衷心祝愿中泰两国、两军友好关系不断深入发展。
2023年7月27日，驻克罗地亚使馆举办招待会，庆祝中国人民解放军建军96周年。
