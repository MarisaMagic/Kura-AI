# 2023年8月15日，由中央宣传部、中央精神文明建设办公室和青海省委、青海省人民政府联合举办的2023年文化科技卫生“三下乡”集中示范活动在青海省海北藏族自治州刚察县举行。（news1）

2023年文化科技卫生“三下乡”集中示范活动8月下旬活动简介：为深入学习贯彻党的二十大和二十届一中、二中全会精神，进一步动员社会各方力量全面推进乡村振兴，加快农业农村现代化，建设宜居宜业和美乡村，中宣部等联合组织开展2023年文化科技卫生“三下乡”活动。按照要求，由文化和旅游部牵头深入内蒙古自治区适时开展集中示范活动。主办单位：文化和旅游部艺术司2.“江流万古·文润千年——2023年中华传统晒书活动”启动仪式8月22日活动简介：2023年中华传统晒书活动的主场活动拟定于8月22日，在江苏省扬州市举行，公共服务司负责同志出席。主办单位：文化和旅游部公共服务司3.2023年中国文化馆年会8月29至30日活动简介：2023年中国文化馆年会将于8月29日至30日在内蒙古包头市举办，主题是“文化馆：人民的终身美育学校”，活动由中国文化馆协会与包头市人民政府共同举办，议程包括开闭幕活动、专题研讨、展览会、演出交流活动等。主办单位：文化和旅游部公共服务司4.
