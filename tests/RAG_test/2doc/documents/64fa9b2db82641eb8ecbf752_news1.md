# 2023年，在北京，中央军委批准军委政治工作部修订并编写《习近平强军思想学习纲要（2023年版）》并正式出版发行。（news1）

，正文：近日，由中央文献出版社、解放军出版社出版的《中国共产党军事工作重要文献选编》在全国发行，这部重要文献集收入中国共产党自1921年7月成立至2022年10月二十大召开期间关于军事工作的重要文献共119篇。强国必须强军，军强才能国安。军队是国家稳定发展的强大后盾，我们要坚定不移走好强军之路。加强思想建设是“先导”。我们党在革命、建设、改革各个历史时期，坚持把马克思主义基本原理同中国革命战争和人民军队建设实践相结合，创建和培育了人民军队，创造了具有中国特色的马克思主义军事理论成果。理论创新每前进一步，理论武装就要跟进一步，以思想到位确保行动到位。我们要以学习贯彻习近平新时代中国特色社会主义思想主题教育为契机，系统学习习近平强军思想和《中国共产党军事工作重要文献选编》，用创新理论成果武装头脑、指导实践，让广大官兵树立正确的世界观、人生观、价值观，增强保家卫国的主观能动性。加强政治建设是“根本”。
