# 2023年8月7日，美国和伊朗在霍尔木兹海峡增强战力，伊朗伊斯兰革命卫队为其海军配备了一批新型无人机和导弹等武器装备，美国可能将向途经霍尔木兹海峡的商船派遣武装船员和海军陆战队员。（news1）

目前，美国正在考虑采取更严厉的行动。美联社周四引用了四名美国官员的话报道称，“美国军方考虑将武装人员部署在穿越霍尔木兹海峡的商船上，这是一种闻所未闻的行动，旨在阻止伊朗扣押和骚扰民用船只”。一些报道显示，海军陆战队已经在接受拟议项目的训练。霍尔木兹海峡是海湾与印度洋之间的唯一通道，也是全球原油航运最为重要的通道之一。一旦霍尔木兹海峡被封锁，全世界大约20%的石油供应量将无法从波斯湾通过油轮运出，主要西方发达国家的工业秩序立即会出现激烈动荡。持续不断的“油轮战”始于2019年夏天，最近出现的新的头条新闻包括：美国悄悄扣押伊朗原油促使伊朗扣押了一艘运往休斯顿的油轮。官员们并没有透露潜在计划的细节，但国防部长劳埃德·奥斯汀宣布已向海湾地区增派海军陆战队。
