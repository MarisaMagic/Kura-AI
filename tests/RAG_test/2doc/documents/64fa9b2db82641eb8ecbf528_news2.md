# 2023年7月18日，中国第26批赴刚果（金）的维和工兵在刚果（金）东部卡莱亥地区成功完成鲁济拉桥梁的救援工程，为灾区的交通恢复提供了重要保障。（news2）

据了解，中国第27批赴刚果(金)维和工兵分队主要担负任务区内的工程保障、道路抢修、桥梁架设、机场构筑、人道主义援助等任务，为当地民众和联合国驻刚果(金)稳定特派团各维和部队提供有利援助。根据计划安排，中国第26批赴刚果(金)维和工兵分队第二梯队108名官兵将于本月下旬从戈马机场启程回国。举报/反馈
本文转自：人民网核查官检查装备性能。周家祥摄人民网约翰内斯堡8月3日电 （记者闫韫明、通讯员王锦伟、党天宇、周家祥）当地时间8月2日，中国第26批赴刚果（金）维和工兵分队高标准通过第三季度装备核查，这也是该分队任务期内的最后一次装备核查，参加核查的所有车机装备战技术性能全部达标。装备核查是联合国根据与出兵国签订的《谅解备忘录》，每季度对出兵国所提供的装备设施进行的综合性检查评估，并作为对出兵国维和设施、装备予以经济补偿的根本方法和重要依据。
