# 2023年08月08日，万达集团首席副总裁刘海波被公安机关带走。（news1）

第 2762期】 来源：中国新闻网8月8日消息，多家媒体报道称，万达集团高级副总裁刘海波已被公安机关带走，被带走的具体原因目前不详。万达内部知情人士透露，刘海波确实被警方带走调查，主要原因是涉及企业内部贪腐，而且数额巨大。另有知情人士称，除了刘海波，万达投资口也有其他人被公安机关带走。2010年，刘海波加入大连万达商业集团，先后担任总裁助理、发展部常务副总经理、发展部总经理、区域总经理、集团首席副总裁、高级副总裁等职位。一直以来分管万达集团的投资业务，可以说是万达“老将”。刘海波名下共关联5家企业，其中仅1家为存续状态，为万达旗下大连万达稳泰管理咨询合伙企业(有限合伙)，成立于2017年5月，王健林、张霖、齐界、刘海波等人为合伙人。其中王健林持有该合伙企业72.28%股份，为最大股东。此外，大连万达稳泰管理咨询合伙企业(有限合伙)共对外投资1家企业，为大连万达商业管理集团股份有限公司。
