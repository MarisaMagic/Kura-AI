# 2021年8月13日，美国夏威夷州毛伊岛的野火造成93人遇难，1.2万人口的拉海纳镇被完全烧毁。（news2）

(完)举报/反馈
▲ 这是8月10日拍摄的美国夏威夷州毛伊岛著名旅游城镇拉海纳野火过后的景象。美国夏威夷州毛伊岛8日燃起至少三处野火，过火面积逾800公顷。截至10日，野火造成至少53人死亡、约千人失联，超万户家庭断电。此外，野火还造成上千座建筑物被毁，岛上著名海滨度假小镇拉海纳几乎化为灰烬。有当地研究人员认为，毛伊岛野火为夏威夷迄今为止最致命的野火，而据美国加利福尼亚州消防局的数据，这也是美国过去100年来第二致命的大火，仅次于2018年11月造成85人死亡的坎普大火。美国总统拜登已批准夏威夷州进入“重大灾难状态”，美国联邦政府正部署海军第三舰队、陆军和美国海岸警卫队协助当地应急人员，海军陆战队也正提供黑鹰直升机帮助灭火。据美媒报道，毛伊县10日发布通报称，截至10日下午，野火已致53人丧生、数十人受伤，其中一些人伤势严重。
