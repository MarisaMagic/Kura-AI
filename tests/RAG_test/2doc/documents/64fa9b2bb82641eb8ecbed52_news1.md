# 2023年上半年，江门市政府成功引进44个投资额超过10亿元的项目，计划投资额达849亿元，增长了23.3%。（news1）

全力冲刺千亿GDP强区,争当江门制造业高质量发展的主力军。1-6月,新会区各项招商数据成绩亮眼,各项主要考核任务指标完成情况均优于时间进度,项目数、投资额、超10亿元项目等均“领跑”全市。其中,成功引进亿元以上项目实现同比增长45.5%,涵盖新能源、新材料、新装备、新一代信息技术、工业新平台及职教等新兴战略性产业。同时,新会区在项目储备方面底气十足。据统计,目前在谈投资意愿强烈的项目线索共63条,计划总投资额超700亿元,其中,超100亿项目线索2条,超过10亿元项目线索超20条。全员招商 硕果盈枝28支招商队伍多点发力今年以来,新会区在香港、澳门成功举办新春交流推介会,在深圳成功举办现代产业招商推介大会和招商合作伙伴招商恳谈会,在新会举办广东(江门)新能源电池产业高质量发展合作交流会、“新启大湾区 会见枢纽城”2023江门新会城市发展推介会.新会区上半年主动出击,积极开展和参与了10场招商推介活动,赴上海、成都、宜宾、深圳、广州、东莞等地参加了25场次大型专题展会,
