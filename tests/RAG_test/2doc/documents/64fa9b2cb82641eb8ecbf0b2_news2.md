# 2023年8月5日，侵华日军第七三一部队罪证陈列馆在黑龙江省牡丹江市首次公布《日军哈尔滨第一陆军病院原簿》。（news2）

《日军哈尔滨第一陆军病院原薄》部分内容的影印版本。刘璐摄 初步判定日军哈尔滨第一陆军病院是七三一部队医学犯罪的延伸机构，其在筹建之初就与日本细菌战大本营计划制定息息相关，是日本细菌战重要参与者与关联者。七三一部队人体实验和细菌战由日本战时医疗机构协同实施的，上至七三一部队、各师团防疫给水部，并延伸到日军陆军病院。这是日本自上而下，推动日军战时医疗机构有组织、有计划协同实施的集团犯罪。5日，哈尔滨市侵华日军第七三一部队罪证陈列馆与中共牡丹江市西安区委员会“馆地共建”内容之一，共同纪念中国人民战争暨世界反法西斯战争胜利78周年系列活动在牡丹江西安区举行，活动由“侵华日军细菌战罪证陈列”面向公众开放、七三一部队医学犯罪“新档案、新发现”发布会、侵华日军细菌战与毒气战学术研讨会、“哈尔滨市侵华日军细菌战与毒气战史研究会”2023年会四部分组成。
