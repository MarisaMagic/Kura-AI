# 2023年7月28日，中国海军“和平方舟”号医院船在执行“和谐使命-2023”任务的过程中抵达汤加王国努库阿洛法港，进行为期7天的友好访问并开展医疗服务。（news2）

黎 宇摄解放军报努库阿洛法8月4日电 记者李伟欣、谢菲报道：当地时间4日上午10时，中国海军和平方舟医院船圆满结束对汤加的访问和医疗服务，解缆驶离努库阿洛法港，前往“和谐使命-2023”任务的第三站瓦努阿图。中汤两国海军还在努库阿洛法港外海举行了以编队运动、通信操演和海空立体搜救为主要内容的联合演练。在为期7天的医疗服务中，和平方舟医院船为当地民众、华人华侨等诊疗服务6895人次，完成手术39例。单日主平台诊疗量和手术量，均创下执行“和谐使命-2023”任务以来最高纪录。在全天候开展医疗服务的同时，和平方舟医院船还先后派出8批医疗专家赴3个村级卫生中心和维奥拉医院，与当地医护人员开展联合诊疗。医疗救护直升机搭载医疗分队前出埃瓦岛，为300多名村民提供医疗服务。汤加国王图普六世登船看望慰问了中方医护人员和汤加住院民众。
