# 2021年8月3日，受台风“杜苏芮”影响，北京房山区张坊镇穆家口村农户穆先生的23亩果树受损，人保财险北京分公司迅速赔付9.2万元。（news2）

同时，引导投保户及时报案，保险公司接到报案后第一时间组织查勘，加快理赔工作进度。窦店镇白草洼村农户的连栋薄膜大棚因为泄洪受灾，太平洋财险房山支公司8月2日接到报案，及时去现场进行实地查勘，确认现场情况后，考虑到时期特殊，将原本需要3天以上的赔付流程缩短至48小时内，于8月4日完成1.12万元的赔付。张坊镇穆家口村村民自家经营的核桃园受灾严重，由于他先前在中国人民财产保险股份有限公司北京市房山支公司投保了“果树树体种植保险”，情况稳定后他便去房山支公司报案，勘查人员第一时间去现场进行勘测，发现因暴雨造成的洪涝致使承保桃树地块土壤疏松，积水排除后果树树体倾斜、树根折断，树体施救成活率几乎为零，最终确实损失达到全损标准，快速赔付金额92000元，于8月4日完成赔付。
