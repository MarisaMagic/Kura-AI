# 2023年7月30日，来自日本、蒙古、俄罗斯、韩国、泰国以及中国的师生在呼和浩特内蒙古展览馆体验剪纸艺术。（news1）

”乌兹别克斯坦籍留学生兹航说。此次体验活动不仅让留学生们近距离接触了中国传统剪纸文化，也为促进不同国家之间的文化交流搭建了平台。“我觉得中国传统文化真是太有魅力和吸引力了。”留学生强生说。(完)【责任编辑:肖梦吟】
中新网重庆12月6日电(记者 钟旖)“我可以跟您合照吗？”“这个帽子里有机关吗？方便给我看看吗？”……6日，在重庆大学校园内，刚表演完川剧变脸的民间艺人李勇被学生团团围住。几分钟前，学生距离他不到一米，却看不出变脸的任何破绽，啧啧称奇。当天，由教育部高校思想政治工作创新发展中心(重庆大学)、重庆大学党委宣传部联合主办的“遗起寻迹时间之美”非遗面对面活动拉开帷幕。
