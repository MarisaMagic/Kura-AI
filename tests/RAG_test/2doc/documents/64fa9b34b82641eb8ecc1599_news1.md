# 2023年7月19日，广西壮族自治区本级土地推介会在南宁成功举办，推介22幅约2978亩优质地块，6家企业意向投资签约土地共389.16亩。（news1）

活动中，6家企业意向投资签约广西自治区本级土地共389.16亩。广西土地储备中心与广西地矿建设集团有限公司、广西路建工程集团有限公司、广西华南岩土工程有限公司、广西盛洲北斗科技有限公司、广西泰中教育投资有限公司、广西京九房地产开发有限责任公司等企业现场签订了投资意向协议。主办方 供图本次活动在政银企之间搭建起了有效的互通平台，充分发挥了政银企协同效能，高效服务企业、服务项目落地，对进一步优化广西土地市场配置，促进广西房地产市场持续平稳健康发展具有积极意义。（完）",
"近日，广西壮族自治区自然资源厅举行2023年度广西壮族自治区本级土地推介会，公开推介自治区本级土地优质地块22幅，面积近3000亩，有6家企业现场达成了投资意向。本次推介的地块分布在南宁、柳州、桂林、来宾、崇左5个设区市，合计面积2977.96亩，单幅地块面积为13亩至365亩不等，涵盖住宅、商业、服务业、仓储等诸多用途，用地选择面广，投资方向多元。其中南宁市拟出让地块10幅，合计面积1223.
