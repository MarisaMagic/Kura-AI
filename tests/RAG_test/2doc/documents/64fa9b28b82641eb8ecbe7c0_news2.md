# 2023年7月28日，国务院“互联网+督查”平台开始征集阻碍民营经济发展壮大的问题线索和意见建议，以解决民营经济发展壮大面临的困难和问题。（news2）

“互联网+督查”这个老熟人，专题收集整理阻碍民营经济发展壮大的问题线索，分量不可谓不重。梳理此番面向社会征集的十个方面问题线索，与《关于促进民营经济发展壮大的意见》中的具体措施密切关联，每一项具体问题的征集方向分别对应文件中“持续破除市场准入壁垒”“全面落实公平竞争政策制度”“依法保护民营企业产权和企业家权”等国家政策的禁止项。而且问题表现描述非常细致，只需要对号入座、完成个案责任主体信息填写，即可提交线索。短短几年时间，“互联网+督查”平台实现的行政监督，事实上已经形成了一套“有问题找督查”和通过互联网随手投诉反馈的现代权力监督机制。“互联网+督查”高调护航民营经济发展，其已经拥有并成型的监督范式同样有能力高效落地。普通社会成员可以通过便捷的互联网方式找到并激活的国家级监督力量，如今市场主体、民营企业同样可以实现。
