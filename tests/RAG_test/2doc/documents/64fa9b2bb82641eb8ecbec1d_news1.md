# 2023年8月14日晚，餐饮企业全聚德公布半年度报告，上半年营收6.68亿元，净利润2791.67万元，同比均有大幅增加，同时在北京、上海、杭州、长春等地开设了104家新门店。（news1）

受上半年餐饮市场回暖影响，今年上半年全聚德的营收约为6.68亿元，同比（较上年同期）增长104.06%；归属于上市公司股东的净利润约为2791.67万元，去年同期净亏损1.53亿元。基本每股收益0.091元/股。具体来看，主营的餐饮业上半年为全聚德贡献了78.21%的收入，达5.22亿元，同比实现翻番。商品销售业务营收占比20.01%，达1.34亿元，同比增长78.98%。租赁业务营收1191.35万元，占比1.78%，同比增长9.18%。分地区来看，华北地区营收占比最高，超七成达4.73亿元，同比增长136.47%；华中地区营收2520.1万元，占比仅3.77%，在六个地区中排名第四，但同比增幅超6倍。全聚德分地区的营收数据上半年各业务毛利率实现大幅增长。其中，餐饮业务毛利率为13.02%，同比增长43.16%；商品销售毛利率为37.81%，同比增长26.26%。
