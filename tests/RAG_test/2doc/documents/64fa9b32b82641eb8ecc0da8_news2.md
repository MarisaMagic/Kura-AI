# 近日，平安健康医疗科技有限公司与汤臣倍健股份有限公司签署了战略合作协议，期望通过结合汤臣倍健的产品和平安健康的健康管理服务，满足广大用户的综合性健康需求，提升全民健康素养水平。（news2）

彼时的平安健康，乃至整个中国互联网医疗正面临着史无前例的发展机遇。新冠疫情期间，患者线下就诊不便，在线问诊需求量呈指数式增长，巨大的流量在此时涌入了互联网医疗企业。据平安健康2020年中报，疫情高峰期间，平安好医生APP访问人次超11.1亿，APP新注册用户数量是疫情之前的10倍，APP新增用户日均问诊量是疫情之前的9倍。“从短期看，互联网医疗企业将普遍受惠于爆发性增长的在线问诊量和用户流量；从中长期来看，互联网医疗企业只有充分利用好这次流量红利并不断提升用户价值，才能真正成为互联网医疗行业绝对龙头。”在接任后第一份财报的董事长致辞中，方蔚豪如此说道。方蔚豪首先从渠道、产品服务、能力等方面进行了战略升级，他曾经直言，医疗健康服务与金融、保险服务的协同，一直是平安健康探索的重要方向。而与平安集团的合作关系是平安健康在该方向上的最大优势之一，服务好平安集团体系内超过2亿的金融客户并进行高效转化是平安健康的首要任务。
