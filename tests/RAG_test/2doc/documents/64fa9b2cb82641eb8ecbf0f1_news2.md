# 2023年8月11日，空军航空兵某团无人机大队大队长李阳，携带无人机与歼-16同框进行了训练，成功验证了某型无人机在复杂地域打击能力。（news2）

他还研究出10多套战法，并拓展出“无人机-”“无人机+”的作战模式，其中“‘无人机-’主要减的是后勤保障，‘无人机+’主要加的是训法战法融入体系”。李阳认为，未来战争是一种认知的对抗，“在无人装备、无人武器背后的人有什么概念、什么认知，是决定战场胜败的关键因素”。引起外界关注的是，该视频不但展示了“攻击-2”察打一体无人机执行侦察以及发射导弹摧毁地面目标的场景，而且还罕见地展出了它与歼-16战斗机同框的场景。有分析认为，近年来各国都在发展有人驾驶飞机与无人机的协同作战概念，包括让人类飞行员在空中直接控制无人机执行各种高危险任务，从而减少战场的人员损失。美国空军还规划未来将由F-35A隐形战斗机与下一代战斗机指挥多架无人僚机并肩作战。因此这次中国空军“攻击-2”察打一体无人机与歼-16战斗机罕见同框的场景就备受关注。
