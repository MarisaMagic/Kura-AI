# 2023年7月24日，俄罗斯总统普京签署法案，禁止在俄罗斯进行性别重置手术（变性手术）。（news1）

资料图：俄罗斯总统普京。 据英国《卫报》此前报道，俄罗斯国家杜马(下议院)7月25日曾表示，征兵法案通过后，从2024年1月1日起，18岁至30岁的公民将被征召服兵役。法案还禁止应征入伍者在征兵办公室向他们发出征兵通知后离开俄罗斯。 此前，俄罗斯规定18岁至27岁的男性必须服一年兵役，每年征兵两次。俄罗斯国家杜马国防事务委员会主席安德烈·卡尔塔波洛夫(Andrei Kartapolov)曾表示：“法律草案的措辞发生了变化，因为人口形势严峻，影响了动员资源的数量。” 【编辑:陈彩霞】 更多精彩内容请进入国际频道
