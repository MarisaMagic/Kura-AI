# 2023年7月31日，俄罗斯国防部长绍伊古表明，对于无人机袭击事件，俄方已加强防护并提高对乌克兰军事目标打击力度。（news2）

当天凌晨，基辅拉响了防空警报。此前，当地时间8月1日，俄罗斯莫斯科商务区再次遭遇无人机袭击。这已经是自7月以来，莫斯科第五次遭到无人机袭击。同日，俄罗斯总统普京在克里姆林宫会见俄罗斯联邦委员会主席马特维延科。马特维延科向普京报告了目前俄罗斯政府为支持前线俄罗斯士兵所采取的措施。俄总统新闻秘书佩斯科夫表示，目前乌克兰发动的无人机袭击威胁确实存在，俄方正在采取相应的应对措施。责编：林根校对：杨立林举报/反馈
参考消息网8月2日报道据路透社报道，波兰当地时间8月1日称，正在紧急向东部边境部署军队，此前波兰指责俄罗斯紧密盟友白俄罗斯的军用直升机侵犯其领空。白俄罗斯军方否认侵犯领空，并指责北约成员波兰（俄乌冲突中乌克兰最强烈的支持者之一）编造指责，为增派军队提供理由。波兰国防部说，国防部正派出“额外的军队和资源，包括武装直升机。
