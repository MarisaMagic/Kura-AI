# 2023年8月2日，武汉轨道交通12号线青菱站至罗家村站区间右线由武汉地铁集团、中铁开投集团投资建设、中铁四局承建的盾构区间顺利贯通。（news2）

”8月2日上午，武汉轨道交通12号线青菱站至罗家村站区间右线接收端，项目盾构副经理康朝阳屏气凝神，密切关注电子屏上的盾构掘进数据。巨大的轰鸣声中，直径约6.4米的“井冈山5号”刀盘旋转，逐渐从掌子面后“露出真容”。上午10时许，由武汉地铁集团、中铁开投集团参与投资建设、中铁四局承建的武汉轨道交通12号线青菱站至罗家村站区间右线顺利贯通，为武汉地铁首条环线12号线首个贯通的盾构区间，工程建设全面进入快车道。武汉轨道交通12号线设站37座，串联武汉三镇成环，经过7个中心城区，与18条线路可实现换乘，是世界第二长、亚洲第一长地铁环线，线路两次穿越长江、一次穿越汉江。全线共需72台盾构施工，目前正在同步掘进的有15台盾构。施工方中铁四局项目总工程师张舵介绍，此次洞通的青菱站至罗家村站区间右线全长874米，该区间穿越富水砂层及淤泥质不良地层，盾构掘进有如“在泥浆中滑行”。
