# 2023年上半年，广东省公安厅交通管理局曝光了国省道、高速公路十大事故多发路段，其中包括茂名市、湛江市、河源市等地。（news2）

其中，仅打击恶意逃废金融债务一项，就依法协助金融机构收回不良贷款21亿元人民币，对警示金融“老赖”、打击信贷领域犯罪等发挥了积极作用。此外，山东公安交通管理部门也采取多项举措，保障道路交通安全。山东省公安厅交通警察总队总队长刘大为说，该省公安交警部门今年持续推进道路交通安全隐患大排查大整治工作，精准化整治重点违法行为，在2023年“车流”上升20.7%的情况下，全省道路交通事故起数、死亡人数、较大事故起数同比实现三下降，道路交通安全形势平稳有序。以山东省交安委名义，公安交通管理部门今年还对63处重大事故隐患、411处事故多发路段、8个较大事故频发和8个死亡事故高发的县(市、区)“挂牌督办”。对较大事故和“四类”涉企亡人事故全部深度调查，已办案964起，追责191人，刑事立案数、行政处罚数同比上升11%、12%。(完)举报/反馈
