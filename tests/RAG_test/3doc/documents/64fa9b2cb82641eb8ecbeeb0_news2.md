# 2023年7月28日晚，湖北省第十六届中学生运动会在鄂州国际会展中心举行开幕式，全省18支代表团参加。（news2）

本次开幕式共分为三个篇章：《百湖汇江流》见证吴王古都的前世今生，见证城市的沧桑巨变；《千帆竞鄂渚》展现了青少年运动在鄂州欣欣向荣、蓬勃发展；《万机通寰宇》向世界发出邀请函，未来，这里将是开放包容、多元一体、万商云集的圣地。文体展演 极目新闻记者赵德龙 摄开幕式现场座无虚席。“演职人员的倾情演出，配合绚烂的光影效果，瞬间就将氛围拉满。”市民刘女士说，舞台上还有小演员，不难想象他们背后的努力。文体展演 极目新闻记者赵德龙 摄据了解，为筹办本次开幕式，前后20余所学校参加演出，经过80多天紧张排练，1118位台前幕后演职人员辛勤付出，最终为观众呈现出一场视听盛宴。“本次开幕式整体效果达到了预期水平，全体演职人员连续排练2个多月，克服了种种困难，希望大家继续关注我们闭幕式的演出。”省中运会开幕式总导演李翔说。
