# 2023年7月20日，北京举行东南亚孔子学院联席会议，向马来西亚、泰国、印度尼西亚、新加坡的五所新建孔子学院授牌。（news2）

来自东南亚10个国家的孔子学院(课堂)及中外方合作院校代表近300人齐聚北京,共享孔子学院办学经验,共话区域内孔院协同创新,共谋东南亚孔院发展新愿景。本次会议由中国国际中文教育基金会主办、北京语言大学承办,会议期间举办1场专家论坛,1场案例分享,2场分组研讨,国际中文教育资源展同步举行。在开幕式上,中国国际中文教育基金会理事长杨卫、中国-东盟中心教育文化旅游部主任Hadi Tjahjono、教育部国际合作与交流司二级巡视员吴劲松、教育部中外语言交流合作中心副主任胡志平、北京语言大学校长段鹏分别致辞,中国国际中文教育基金会副理事长、秘书长赵灵山主持。吴劲松二级巡视员代表中国教育部对会议的召开表示热烈祝贺,对东南亚孔子学院在发展规模、多元化、特色化以及本土化发展方面取得的成就表示肯定。吴劲松指出,进入新阶段,孔子学院要坚持创新发展、坚持高质量发展、坚持协同发展,
