# 2023年8月10日，国家发改委宣布自8月9日24时起，国内汽、柴油价格每吨分别提高240元、230元，北京92号汽油价格破8元。（news3）

中国国家发改委26日消息，根据近期国际市场油价变化情况，按照现行成品油价格形成机制，自2023年7月26日24时起，国内汽、柴油价格每吨分别提高275元(人民币，下同)和260元。 折合升价，全国平均来看，92号汽油、95号汽油及0号柴油每升分别上调0.22元、0.23元及0.22元。卓创资讯成品油分析师徐娜指出，本轮调价落地后，消费者出行成本小幅增加。以油箱容量为50升的家用轿车为例，加满一箱92号汽油将多花11元。 油耗方面，以月跑2000公里，百公里油耗在8升的小型私家车为例，到下次调价窗口开启(8月9日24时)之前，消费者用油成本将增加16元。 从物流行业来看，以月跑10000公里，百公里油耗在38升的重卡为例，到下次调价窗口开启前，单辆车的燃油成本将增加390元。 值得注意的是，此次调价落地后，自6月28日以来，1个月时间内，中国成品油价历经三次连续上涨。 徐娜透露，“三连涨”后，中国汽、柴油累计上调幅度分别在每吨500元及每吨480元，折算成升价，92号汽油、95号汽油及0号柴油累计每升分别上调0.
