# 2023年8月17日，广州市中级人民法院公布了《广州法院服务保障民营经济发展壮大的若干措施》及其典型案例，其中包括18条针对民营经济发展的措施。（news2）

在回答人民网提问“从本次发布的案例看，人民法院服务保障民营经济发展壮大的工作有哪些新的特点”时，最高人民法院民二庭庭长林文学表示，本次发布的典型案例，从不同角度体现了人民法院以审判工作现代化促进民营经济发展壮大。林文学指出，一是坚持能动司法理念，坚持依法平等保护原则，持续优化法治化营商环境。人民法院依法保护民营企业产权和企业家合法权益，坚持双赢多赢共赢理念，在法律框架内寻求化解纠纷的最佳方案，实现政治效果、社会效果和法律效果的有机统一。二是坚持“抓前端、治未病”理念，强化诉源治理。人民法院充分发挥司法建议的社会治理功能。积极参与企业合规改革，把办案和治理有机结合起来，努力把矛盾纠纷解决在萌芽状态。三是坚持案结事了、政通人和理念。人民法院坚持“如我在诉”、换位思考。
