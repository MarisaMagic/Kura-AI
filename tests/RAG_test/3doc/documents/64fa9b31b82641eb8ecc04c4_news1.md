# 2023年8月1日，广西首家国家级人力资源服务产业园在广西柳州市开园运营，由柳州市市长张壮、广西壮族自治区人力资源和社会保障厅厅长唐标文等人出席。（news1）

在展示板块，全国144家人力资源服务领军企业和粤港澳重点用人单位参展交流，河南在大会展示区设有“豫见河南共创未来”人力资源服务业发展成果展，中国·中原人力资源服务产业园和河南人才集团两家单位作为参会代表在现场设展，2个人力资源服务合作代表项目在大会现场签约。在比赛板块，我省有3个项目参加人力资源服务创新创业大赛和路演。在招聘板块，河南能源集团等5家国有大型企业参加粤港澳大湾区青年人才双选会。近年来，河南人力资源服务业快速发展，成为实施“创新驱动、科教兴省、人才强省”战略的重要抓手。河南以中国·中原人力资源服务产业园为龙头，大力发展专业性、行业性人力资源市场，构建布局合理、特色突出的“米”字形专业人力资源市场群。“人力资源服务业是现代服务业的重要组成部分，对促进高质量充分就业，服务经济社会高质量发展具有重要意义。”省人社厅有关部门负责人说，目前，河南已挂牌成立人力资源服务产业园51家，全省各类人力资源服务机构3000多家，从业人员超过4万人，全年营业收入突破800亿元。
