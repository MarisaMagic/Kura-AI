# 2023年8月10日，首都医科大学附属北京天坛医院神经外科专家团队在西藏拉萨为西藏自治区第二人民医院推进神经外科学科建设。（news1）

【编辑:王盼盼】
新华网拉萨8月10日电(记者格桑朗杰)10日,中国科学院院士、国家神经系统疾病临床医学研究中心主任赵继宗带领北京天坛医院专家团队在西藏自治区第二人民医院进行神经外科查房及手术教学,并开展专业座谈会、学术讲座及义诊活动,助力西藏神经外科医学发展。在西藏自治区第二人民医院,赵继宗院士(左二)与医院医疗工作者交流(8月10日摄)。新华社记者 张汝锋 摄据了解,为了促进西藏自治区神经外科医学更好发展,赵继宗院士专家团队多次进藏指导西藏神经外科学术建设,助力推动西藏医疗水平。随着2019年西藏自治区第二人民医院建立“赵继宗院士西藏神经外科技术指导中心”以来,赵继宗院士专家团队定期到西藏自治区第二人民医院驻地坐诊,指导一线临床工作,提高临床救治能力,进行学术交流,帮助提升学科建设,整体带动西藏神经外科建设。赵继宗院士(左一)查看患者的CT片(8月10日摄)。新华社记者 张汝锋 摄赵继宗院士表示,
