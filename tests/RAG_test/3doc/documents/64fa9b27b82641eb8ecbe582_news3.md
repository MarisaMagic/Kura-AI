# 2023年7月21日，菲律宾火山地震研究所在马荣火山顶部火山口观测到持续28秒的短时熔岩喷射。（news3）

据菲火山地震研究所通报，当前马荣火山口仍在缓慢喷出岩浆，岩浆顺山体而下，最长一处达3.4公里。在过去24小时里，该所还在马荣火山录得31次火山地震、1次火山碎屑密度流以及87次落石事件。菲火山地震研究所指出，当前马荣火山喷发警戒级别维持在三级，意味着其仍处于“相对较高的动荡水平”，有可能在未来几周甚至几天内发生“危险喷发”。该所表示，将继续对马荣火山保持密切监测，并警告民众不要进入以火山口为圆心、半径6公里的“危险区域”，同时建议飞行员避免在火山山顶附近飞行。马荣火山位于菲律宾吕宋岛东南部的阿尔拜省，海拔约2400米，是菲境内最活跃的火山之一。（完）举报/反馈
