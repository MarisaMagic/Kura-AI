# 2023年7月26日，由中国驻伦敦旅游办事处、欧洲时报英国分社和中国尚图坊联合主办的“美丽中英”摄影大赛在英国伦敦启动，向全球摄影爱好者征集作品。（news2）

“中国拥有如此多样的风景，参赛作品将展现其非凡的广度和多样性。”英国皇家摄影协会项目总监迈克尔·普里查德（Dr. Michael Pritchard）分享了与中国摄影师合作的经历。“对我来说，照片胜过千言万语。向我的家人展示在中国拍摄的照片，将比我用文字叙述更能让他们了解我在中国的所见所闻。”本次大赛由中国驻伦敦旅游办事处、欧洲时报英国分社和中国尚图坊联合主办。本次大赛作品征集截止日期为10月31日，遴选出的50份入围优秀作品将在主办方的社媒账号及元宇宙画廊中展示。比赛还将最后评出3名特等奖、9名二等奖、15名三等奖以及30名荣誉奖。人民网伦敦7月26日电 （余颖、狄心悦）26日上午， “美丽中英”摄影大赛在中国驻英国大使馆文化处正式启动，本次大赛用镜头语言打破地理的隔阂，邀请全球摄影爱好者上传作品，一同发现美丽中英、魅力中英。
