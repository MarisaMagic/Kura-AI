# 2023年8月10日，首都医科大学附属北京天坛医院神经外科专家团队在西藏拉萨为西藏自治区第二人民医院推进神经外科学科建设。（news3）

让西藏当地骨干医生到天坛医院锻炼学习,开展全方位帮扶,培养本地人才,让高原群众享受更优质的医疗资源。赵继宗院士(右一)在西藏自治区第二人民医院为患者义诊(8月10日摄)。新华社记者 张汝锋 摄“在各方关心帮助下,近年来,西藏自治区第二人民医院神经外科团队已经常规开展了脊柱脊髓疾病、脑血管病、神经肿瘤等多种新技术、新业务。”西藏自治区第二人民医院院长格桑顿珠表示,近年来医院的神经外科医疗水平得到了跨越式发展,患者的就医环境、便捷度和舒适度得到了大幅提升,自2014年以来上百名神经外科患者在西藏得到了及时救治。(完)
