# 2023年8月13日，在尼日尔首都尼亚美，尼日利亚伊斯兰高级学者代表团与尼日尔政变领导人阿卜杜拉赫曼·奇亚尼会面后，尼日尔军方表示愿通过外交途径解决当前问题，缓和与西非国家经济共同体的对峙局面。（news1）

西非国家经济共同体关于尼日尔问题的第二次领导人会议8月10日在位于尼日利亚首都阿布贾的总部召开，会议决定命令西共体部队待命，但同时表示将致力于和平解决尼日尔危机。▲尼日尔政变军人领导人阿卜杜拉赫曼·奇亚尼 图据央视新闻据尼日利亚媒体Premium Times报道，在西共体召开紧急会议几小时前，尼日尔政变军人在国家电视台发布由其领导人阿卜杜拉赫曼·奇亚尼签署的法令，宣布成立新政府。8月11日，非洲联盟委员会发表声明，非盟委员会主席法基表示，支持西共体10日通过的涉及尼日尔危机的决定。法基还呼吁尼日尔政变军人停止恶化与西共体关系，立即释放尼日尔总统巴祖姆及其家属和政府成员。国际社会对尼日尔总统巴祖姆的境况担忧加剧。欧盟与非盟11日对于巴祖姆恶化的拘留条件表示谴责，并呼吁尼日尔军政府立即释放巴祖姆。
