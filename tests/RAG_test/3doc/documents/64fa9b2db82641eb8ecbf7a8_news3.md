# 2021年7月22日至28日，德州学院经济管理学院实践团赴山东省威海市郐家村开展以“电商助农”为主题的大学生暑期“三下乡”社会实践活动，通过网络电商直播帮助村民销售编织簸箕。（news3）

本次社会实践活动学生通过体验直播助农及交流访谈的方式，不仅进一步加深了对直播助农的了解与认识，提高了学生感悟网络技术与传统农业相结合的意识，更推动了学生作为新时代的青年，应助力乡村振兴，将自己的力量投入到中国现代化建设中，同时推进了我院让学子深入推动乡村振兴的美好规划。（通讯员：周鑫 史佳琪）来源：中华网
