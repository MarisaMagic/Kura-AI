# 2023年7月31日，俄罗斯国防部长绍伊古表明，对于无人机袭击事件，俄方已加强防护并提高对乌克兰军事目标打击力度。（news3）

这已经是自7月以来，莫斯科第五次遭到无人机袭击。俄罗斯总统普京8月1日在克里姆林宫会见俄罗斯联邦委员会主席马特维延科。马特维延科向普京报告了目前俄罗斯政府为支持前线俄罗斯士兵所采取的措施。俄总统新闻秘书佩斯科夫表示，目前乌克兰发动的无人机袭击威胁确实存在， 俄方正在采取相应的应对措施。泽连斯基此前表态：正在准备新攻击据参考消息，路透社8月1日报道，俄罗斯首都莫斯科商业区一座高层建筑当天遭无人机袭击。这是该建筑在三天内遭到的第二次袭击。俄罗斯称这是乌克兰方面发动的未遂“恐怖袭击”。乌克兰总统顾问波多利亚克说，莫斯科可以预期将有更多无人机袭击和“更多战争”。乌克兰总统顾问波多利亚克在推特上写道：“莫斯科正在迅速适应一场全面战争。”据俄罗斯卫星社报道， 乌克兰总统泽连斯基在8月1日的晚间视频讲话中表示，乌克兰正在准备对俄罗斯领土发动新的攻击。
