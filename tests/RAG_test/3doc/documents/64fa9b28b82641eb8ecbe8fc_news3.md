# 2023年上半年，广东省公安厅交通管理局曝光了国省道、高速公路十大事故多发路段，其中包括茂名市、湛江市、河源市等地。（news3）

广西公安厅交警总队组织对全区范围内高速公路、普通国道、省道2020年上半年道路交通事故多发、造成人员死亡集中的路段进行排查,并对全区道路交通事故情况进行分析,梳理出2020年上半年道路交通事故多发10大路段。按照高速公路每20公里、普通国道、省道每10公里接报的事故情况统计,2020年上半年道路交通事故多发10大路段共造成49人死亡,其中9处位于普通国道。这些路段具体包括:1、国道358线桂平市境内1440公里100米至1450公里100米路段, 2020年上半年共发生道路交通事故25起,死亡6人。2、国道322线来宾市兴宾区境内1960公里至1970公里路段,2020年上半年共发生道路交通事故6起,死亡7人。3、靖西市信发连线9公里至19公里路段,2020年上半年共发生道路交通事故7起,死亡7人。4、国道321线梧州藤县境内287公里100米至297公里100米路段,2020年上半年共发生道路交通事故8起,死亡5人。5、国道323线贺州钟山县境内737公里750米至747公里750米路段,2020年上半年共发生道路交通事故6起,死亡5人。
