# 2023年7月26日，由中国驻伦敦旅游办事处、欧洲时报英国分社和中国尚图坊联合主办的“美丽中英”摄影大赛在英国伦敦启动，向全球摄影爱好者征集作品。（news1）

本次大赛作品征集截止日期为10月31日，遴选出的50份入围优秀作品将在主办方的社媒账号及元宇宙画廊中展示。比赛还将最后评出3名特等奖、9名二等奖、15名三等奖以及30名荣誉奖。(责任编辑：曹欣悦)
当地时间7月26日，由中国驻伦敦旅游办事处、欧洲时报英国分社和中国尚图坊联合主办的“美丽中英”摄影大赛，在中国驻英国大使馆文化处正式启动。该大赛旨在通过精美图片呈现新时代中国丰富多样的旅游资源、独具魅力的文化形态、生动感人的生活场景，以及近年来中英两国在多领域交流合作和民间友好的精彩故事。摄影大赛征集将于2023年10月31日结束。线下展览和颁奖典礼将于2024年初举行。大赛分为三个主题类别：美丽中国、文化中国和中英印象。
