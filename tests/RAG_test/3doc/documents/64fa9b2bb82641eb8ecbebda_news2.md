# 2021年8月8日，财政部和农业农村部针对黄淮、华北、东北等地受台风“杜苏芮”影响，农作物受灾、农业生产设施损毁情况，紧急下达农业生产防灾救灾资金7.32亿元。（news2）

包括上述拨款在内，财政部近日接连拨出多笔资金，支持各地防汛救灾。 针对黄淮、华北、东北等地受台风“杜苏芮”影响，农作物受灾、农业生产设施损毁情况，财政部、农业农村部8日紧急下达农业生产防灾救灾资金7.32亿元，支持北京、天津、河北、山西、内蒙古、吉林、黑龙江、浙江、福建9省(区、市)及北大荒农垦集团等，抓紧开展农业防汛救灾及灾后农业生产恢复等相关工作，对购买灾后农业生产恢复所需种子(苗)、化肥、农药等物资和作业服务，以及农业生产设施灾损修复等给予适当补助。(完) 【编辑:田博群】 更多精彩内容请进入国内新闻
8-9 20:02，正文： 中新社呼伦贝尔8月9日电 (记者 张林虎)记者9日从内蒙古自治区森林草原防灭火指挥部办公室了解到，内蒙古北部阿龙山、满归、根河等地近日相继发生多起雷电森林火灾，目前已投入灭火力量约5000人。
