# 近日，朗进科技表示，将以技术为先导，以满足客户需求为目标，以实现绿色节能、助力国家“双碳”目标为己任，不断推出更具有挑战性和优越性的整体温控解决方案。（news3）

“ESG新标杆企业奖”是在中国首席经济学家论坛、中央财经大学绿色金融国际研究院指导下，结合证券之星ESG相关算法、企业舆情公开信息、企业研报等多元信息，从有效性、可复制性、创新性、社会影响力等维度进行综合评估，进而评选出的奖项。此次获得“ESG新标杆企业奖”，也是对朗科科技在ESG领域贡献的肯定。2022年，是朗科科技迎来新发展机遇非常关键的转折之年，韶关市城市投资发展集团有限公司入资朗科科技成为第一大股东，朗科科技正式迎来了实控人——韶关市国资委，国资的注入与实控，使得公司的战略转型路径和方向越发清晰。在节能减排方面，朗科科技坚持绿色发展理念，将绿色低碳理念融入公司日常运营中，在促进自身节能减排的同时，公司深研存储前沿技术，助力我国数据存储领域实现绿色低碳、为实现我国数字经济的稳定发展提供坚实的安全保障，积极促成能源消费强度和总量双控(能耗双控)、从而实现节能降碳减污协同增效以及生态环境质量的持续改善。
