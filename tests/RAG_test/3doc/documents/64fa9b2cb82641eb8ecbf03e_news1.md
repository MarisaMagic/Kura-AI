# 2023年8月，湖北宜来高速鹤峰东项目中的关键工程，云南庄特大桥的建设进展顺利，工作人员正在进行三角区汇合段施工作业。（news1）

8月2日下午，随着最后一节重约72吨的钢梁吊装完成，由中铁大桥局承建的宜昌至来凤高速公路鹤峰东段溇水河大桥贯通。宜来高速公路是湖北省规划的“九纵五横三环”高速公路网中“横五”线的重要组成部分，线路起于宜昌宜都市，止于恩施州来凤县，全长187.7公里，总投资约303亿元，分为宜昌段、鹤峰东段、宣鹤段。地处武陵深山的宜来高速公路鹤峰东段穿越喀斯特岩溶地貌，全长38.5公里，桥隧比达65%，平均海拔超过千米，因此被称作鄂西“天路”，也被称为湖北修建难度极高的高速公路之一。经过多次探讨，建设者们决定在两边山头建起高约150米的扣缆塔，在此基础上用14根主缆索将两端相连，形成一个悬索桥的结构，然后进行钢拱肋安装及梁片吊装架设。大桥拱肋及桥面吊装施工完成后，扣缆塔及吊索等将被拆除。
