# 2023年7月26日，浙江省教育厅发布《浙江省教育厅关于实施初中学业水平考试全省统一命题的通知(征求意见稿)》，决定从2024年起，语文、数学、英语、科学、社会等5门学科由省级统一命题。（news2）

潮新闻客户端同步开通征求意见通道，帮助读者、用户向省教育厅传递对两项政策的意见。同时，记者梳理两项政策征求意见稿的要点，并请省教育厅基教处负责人进行解读。明年起中考全省统一命题根据教育部工作部署和浙江省实际，从2024年起，浙江初中学业水平考试实行“统一+分项”模式，全省初中毕业生均需参加。其中，语文（120分）、数学（120分）、英语（120分）、科学（160分）、道德与法治·历史与社会（下称“社会”，100分）等五门学科由省级统一命题，五科卷面总分为620分。体育与健康的考试方式、项目和标准等由各设区市教育局制定；考试时间不迟于5月底，分值在30至50分之间。六门学科均为全省统一考试科目，成绩计入高中阶段学校招生录取总分。分项是指，艺术、劳动学科暂不列入全省统一考试科目，可以按等级制列入考核，具体由各设区市自主实施。综合素质评价是高中段学校招生录取的重要参考，是否赋分计入录取总分也由各设区市自主决定。例如，有的设区市目前科学学科有实验操作环节，同样可以保留，计入该设区市中考总分。
