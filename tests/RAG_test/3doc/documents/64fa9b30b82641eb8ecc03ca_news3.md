# 2021年8月13日，美国夏威夷州毛伊岛的野火造成93人遇难，1.2万人口的拉海纳镇被完全烧毁。（news3）

当地时间8月10日，夏威夷拉海纳野火过后，遍地残骸。 夏威夷州毛伊郡11日夜间发布的最新灾情通报显示，截至当天21时，这场从8日燃烧至今的野火已造成至少80人罹难。此次野火重灾区、著名历史文化旅游胜地拉海纳镇依然处于封闭之中。由于可吸入有毒颗粒物的危险，官方要求人们不要靠近该区域。同时，一条离开拉海纳镇的高速公路已恢复开放。 此次野火爆发后，毛伊郡在当地体育馆、学校、社区中心和教堂等处设置了多个紧急避难所。11日，仍有1418名被疏散的民众临时生活在紧急避难所。 受干热天气和飓风“多拉”经过岛链带来的强风影响，有逾10万人口的夏威夷群岛第二大岛毛伊岛8日爆发野火并以“惊人速度”迅速蔓延。美国总统拜登宣布夏威夷州出现“重大灾难”，批准予以联邦支援。
