# 2023年8月9日，应急管理部部长王祥喜部署安排国家防总办公室、应急管理部等与中国气象局、水利部、自然资源部联合调度会商，研判雨情、汛情、地质灾害和6号台风“卡努”发展趋势，并安排部署重点地区防汛救灾工作。（news1）

举报/反馈
　　据应急管理部网站消息，7月30日上午，国家防总副总指挥、应急管理部部长王祥喜在国家应急指挥总部指挥大厅主持防汛专题视频会商调度，与自然资源部、水利部、中国气象局联合会商，点对点调度北京、天津、河北、山西、河南等重点省份，分析研判强降雨发展态势和影响，进一步安排部署重点地区防汛抢险救援工作。根据《国家防汛抗旱应急预案》有关规定，国家防总于7月30日9时针对上述省份启动防汛二级应急响应。来源: 同花顺7x24快讯举报/反馈
本文转自【中国新闻网】；中新网7月30日电 综合消息，中央气象台预计今明两天，北京、天津、河北、河南北部、山东西部及山西中东部等地仍将有强降雨；水利部将京津冀洪水防御应急响应提升至Ⅱ级；国家防总启动防汛二级应急响应；今年第6号台风“卡努”预计于8月2日在浙江沿海登陆，农业农村部部署防御工作；福建终止防台风应急响应与防暴雨应急响应，生产生活秩序正在有序恢复。
