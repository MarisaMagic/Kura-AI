# 2023年8月5日，市场监管总局在北京发布公告，对汛期维护市场价格秩序稳定提出“七不得”提示告诫。（news3）

不得虚假标价、虚假折价、虚假减价、低价诱骗高价结算、无正当理由不履行价格承诺。网络交易平台经营者不得利用技术手段等强制平台内经营者进行虚假的或者使人误解的价格标示。此外,《通知》明确,相关经营者不得违反法律法规规定,利用价格手段侵犯消费者和其他经营者合法权益,扰乱市场价格秩序。近日,多地纷纷发布提醒告诫书,保障洪涝地区重要民生商品和服务市场价格基本稳定。8月1日,涿州市市场监管局发布《价格行为提醒告诫书》提出,加强灾害天气期间生活必需品、防灾物资等重要商品和服务的市场价格的监督检查,发现管辖范围内的有关经营者实施价格违法违规行为的,将依法严肃查处;涉嫌犯罪的,移送公安机关处理。8月4,保定市市场监督管理局发布《关于规范汛情期间住宿行业价格行为的提醒告诫书》明确,汛情期间,保定市市场监管部门将对保定市内宾馆酒店(民宿)等住宿价格行为加强监管和舆情监测,对不正当价格行为依法从严查处,对性质恶劣、情节严重、社会影响较大的违法典型案件公开曝光。
