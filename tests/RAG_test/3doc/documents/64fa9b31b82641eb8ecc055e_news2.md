# 2023年8月2日，广西北部湾港首个铁路智慧调度中心在防城港码头投入使用，提供智慧平台保障海铁联运一体化发展。（news2）

据了解，今年西部陆海新通道海铁联运班列保持着强劲的增长态势，同比增长8%；开行量由2017年的178列到2023年预计突破9300列，增长52倍；2023年10月份，新通道班列累计开行突破30000列。每完成开行“10000”列的耗时不断缩短，由第一个“10000”列的1335天缩短至第三个“10000”列的403天，预计第四个“10000”列将缩短至365天内。新通道班列开行量的持续强劲增长，显示出其强大竞争优势和良好发展前景，为推动区域经济高质量发展，更好地服务和融入双循环新发展格局提供强劲引擎。据介绍，随着钦州自动化集装箱码头二期工程9号10号泊位通过竣工验收，北部湾港具备世界上最大的20万吨级集装箱船舶靠泊条件，相比原来传统码头，自动化码头的作业效率可提高约30%，操作人员可减少90％。北部湾港集团全力推进海铁联运一体化，自动化码头与钦州铁路集装箱中心站实现拆除围网、化外转内、合二为一，监管数据互通，并进一步创新运营作业模式，将短驳效率提高了约30%，在实现海铁联运“无缝衔接”上又迈进一大步。
