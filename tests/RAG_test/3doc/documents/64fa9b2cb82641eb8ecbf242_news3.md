# 2023年7月25日至26日，联合国审计委员会第77次例会在美国纽约联合国总部召开，由中国审计署审计长侯凯主持，会议期间，审计委员会的各位委员与联合国秘书长古特雷斯举行了会谈。（news3）

2023-06-30 10:27，正文：2023年6月29日，中共中央政治局委员、中央外办主任王毅在北京会见联合国常务副秘书长阿明娜。王毅说，作为创始会员国，中国始终坚定支持联合国事业。无论处在什么历史方位，无论发展到什么阶段，中国始终是世界和平的建设者、全球发展的贡献者、国际秩序的维护者。我们坚定支持联合国在国际事务中发挥核心作用，坚定倡导和践行真正的多边主义，坚定维护以联合国宪章宗旨原则为基础的国际关系基本准则。王毅表示，针对当今世界面临的和平、发展、安全、治理等赤字，习近平主席提出了全球发展倡议、全球安全倡议、全球文明倡议，响应了广大发展中国家最普遍最紧迫的愿望，也体现了中国作为最大发展中国家的担当。发展是我们共同的事业，中方愿同联合国各机构加强对接，形成合力，推动如期实现联合国2030年可持续发展议程。阿明娜表示，感谢中方一直以来对联合国事业的坚定支持，双方在维护和平、促进发展等领域开展了深入合作。
