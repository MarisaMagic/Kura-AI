# 2023年7月27日，刑侦鉴识专家李昌钰因1985年一起谋杀案中涉嫌伪造证据被美国联邦法官裁定负有责任，李昌钰对此表示失望并否认捏造证据。（news2）

但与此同时他也表示，美联储官员并未表现出耐心的意愿。来源：财联社 黄君芝返回搜狐，查看更多责任编辑：
2023-07-24 11:01，正文：原标题：华人神探李昌钰被指伪造证据据美联社报道，当地时间21日，美国联邦法官裁定，刑侦鉴识专家李昌钰在一起谋杀案中对伪造证据负有责任，或被判高额赔偿。据报道，这起谋杀案发生在1985年12月，一名名叫卡尔的退休司机被发现死在家中，时年18岁的伯奇和17岁的亨宁被判有罪。其中，伯奇因重罪谋杀罪被判55年徒刑，服刑30多年后，直到2019年法官下令重审才被释放，亨宁则在2018年获得缓刑。据介绍，当时，没有法医证据表明伯奇和亨宁与犯罪有关，他们的衣服上和车里都没有发现血迹，犯罪现场发现的头发和指纹也没有一项与二人相符。不过，检察官当时出示了李昌钰提供的证据，他在犯罪现场附近的一间浴室里发现了一条毛巾，并证实毛巾上的污渍就是血迹。
