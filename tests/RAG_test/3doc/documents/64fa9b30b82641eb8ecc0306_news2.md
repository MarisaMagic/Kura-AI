# 日前，外交部发言人反对日本政府在8月下旬至9月中旬期间启动福岛核污染水排海的计划。（news2）

2023年08月07日 16:27:00 来自北京市，正文：【环球网报道】8月7日，多家日本媒体爆料，日本政府计划最早于8月下旬开始福岛核污染水排海工作。据日本广播协会（NHK）晚些时候报道，日本首相岸田文雄7日回应称，“目前尚未对日程做任何决定”。日本时事通讯社等日媒7日报道，日本政府计划最早于8月下旬开始福岛核污染水排海工作。岸田文雄将于8月18日在美国举行的美日韩首脑峰会上向拜登和尹锡悦就排海工作进行说明，在回国后正式决定福岛核污染水排海日期。据NHK7日晚些时候报道，岸田文雄就此回应称，“此前曾多次表示预计将于今年春季到夏季期间开始排海，这一点没有改变”。但他还称，“目前就具体时间以及工作日程没有做任何决定”。关于日本强推核污染水排海计划，中国外交部发言人毛宁7月20日例行记者会上表示，日本政府近期就福岛核污染水排海问题开展全球公关，试图用专项基金堵住反对排海的日本民众之口，试图把国际原子能机构综合评估报告当作“通行证”，摆出排海势在必行的架势。
