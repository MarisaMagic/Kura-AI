# 2023年7月26日，浙江省教育厅发布《浙江省教育厅关于实施初中学业水平考试全省统一命题的通知(征求意见稿)》，决定从2024年起，语文、数学、英语、科学、社会等5门学科由省级统一命题。（news3）

原标题：全省统一命题？2024届中考有新消息！近日，朋友圈疯传的一张图引起了广大家长和学生的关注！一起来看看具体的情况！图片来源：姚江中学学校大会据了解，该图为姚江中学在学校大会公布的第三稿意见征求稿，不是终版考试安排，最终的安排以教育部通知为主！2024年中考全省统一命题已经是明确通知了，重点是全省命题后每个学科的分值、考试重点、各地考试安排等等会如何调整呢？根据图片的情况，明年中考考试分值及安排如下：根据第三稿意见征求稿：语文120分，数学120分，英语120分(含听力口语)社会思品120分，科学160分(卷面)以杭州市今年考试为例，如果按照此次调整，会有7大明显的变化：数学考试时间拉长120分钟；第一天数学和第二天英语时间变化，科学从早上调整到下午；早上开考时间推迟半小时；社会分值从 卷面50%的50分 到120分，开卷变 闭卷 ；卷面总分从 570变成640（不加体育）；24年、25年社会另出1套开卷考试卷，由各设区市教育局选用，26年开始，全省统一采取闭卷考试；命题依据：2022版新课程标准（不提供提醒、样卷）。
