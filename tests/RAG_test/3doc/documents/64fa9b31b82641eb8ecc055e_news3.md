# 2023年8月2日，广西北部湾港首个铁路智慧调度中心在防城港码头投入使用，提供智慧平台保障海铁联运一体化发展。（news3）

北部湾港集团全力推进海铁联运一体化，自动化码头与钦州铁路集装箱中心站实现拆除围网、化外转内、合二为一，监管数据互通，并进一步创新运营作业模式，将短驳效率提高了约30%，在实现海铁联运“无缝衔接”上又迈进一大步。今年，北部湾港与关丹港及摩拉港直航航线相继开通运营、“北部湾港—胡志明—东马”精品航线拓展升级、“两湾快航”实现内外贸同船运输，带来关丹港再生铝锭、文莱的海产品，并掀起马来西亚猫山王榴莲热。“一航线一中心”的模式，实现了多式联运“快速衔接、高效通关”，物流与贸易合作展现新景象。目前，北部湾港开通内外贸集装箱航线76条（2017年42条），其中外贸集装箱航线48条（东盟及RCEP航线共36条，远洋航线6条），内贸集装箱航线28条，辐射范围涵盖100多个国家和地区的200多个港口。钦州港发运到新加坡港每周7班、泰国林查班港每周5班、到马来西亚巴生港每周4班、到越南胡志明港每周3班，直航航线覆盖东南亚等地区主要港口。
