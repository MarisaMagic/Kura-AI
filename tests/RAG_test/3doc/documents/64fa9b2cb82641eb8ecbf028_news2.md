# 2023年8月10日，首都医科大学附属北京天坛医院神经外科专家团队在西藏拉萨为西藏自治区第二人民医院推进神经外科学科建设。（news2）

随着2019年西藏自治区第二人民医院建立“赵继宗院士西藏神经外科技术指导中心”以来,赵继宗院士专家团队定期到西藏自治区第二人民医院驻地坐诊,指导一线临床工作,提高临床救治能力,进行学术交流,帮助提升学科建设,整体带动西藏神经外科建设。赵继宗院士(左一)查看患者的CT片(8月10日摄)。新华社记者 张汝锋 摄赵继宗院士表示,随着多方力量努力,西藏神经外科在人才培养、医疗水平、医院学科建设等方面有了长足的进步。此外专家团队通过座谈会、远程诊疗、义诊、进藏开展手术等方式让当地医护人员学习到先进经验,让西藏当地骨干医生到天坛医院锻炼学习,开展全方位帮扶,培养本地人才,让高原群众享受更优质的医疗资源。赵继宗院士(右一)在西藏自治区第二人民医院为患者义诊(8月10日摄)。新华社记者 张汝锋 摄“在各方关心帮助下,近年来,
