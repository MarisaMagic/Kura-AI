# 2023年8月1日，由五矿二十三冶投资建设的青海省察汗诺互通转体桥成功完成转体。（news1）

(完) 【编辑:李岩】 更多精彩内容请进入社会新闻
7-19 21:12，正文： 图为航拍施工现场。青海交控集团 供图 中新网西宁7月19日电 (记者 张添福)青海交控集团19日发布消息，7月18日16时，由青海省路桥集团承建的西察高速察汗诺互通上跨青藏铁路转体桥现浇梁混凝土浇筑全部顺利完成。 该转体桥T构跨度为160米，转体重量12000吨，位于海拔3800米的乌兰县铜普镇察汗诺村，创西北地区高速公路桥梁工程中跨铁路转体桥跨度最大、海拔最高、转体重量最大三项纪录。 西察高速察汗诺互通转体桥是青海省西海(海晏)至察汗诺高速公路的重要控制性工程之一，西察高速在此通过察汗诺枢纽互通立交跨青藏铁路与茶德高速相接。 互通转体桥由南向北分别上跨青藏铁路上行线和下行线，箱梁左、右两幅采用分段现浇施工工艺，在梁体浇筑施工完成后，两幅桥体将同时进行逆时针转体65度，转体完成后进行现浇合拢段施工。
