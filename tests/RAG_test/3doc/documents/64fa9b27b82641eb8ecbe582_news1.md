# 2023年7月21日，菲律宾火山地震研究所在马荣火山顶部火山口观测到持续28秒的短时熔岩喷射。（news1）

菲律宾火山地震研究所还发布了一段视频，显示了26日晚马荣火山缓慢流出岩浆的情景。截至26日，马荣火山已经连续15天有岩浆缓慢喷出。另据菲律宾国家减灾委消息，马荣火山活动持续已经造成超过4万人受影响。目前仍有2万余人居住在28个安置中心内。马荣火山的目前仍然维持3级警戒。（总台记者 黄铮铮）（来源：央视新闻客户端）举报/反馈
新华社北京6月12日电菲律宾马荣火山11日夜间喷出岩浆，或为剧烈喷发前兆，附近数以千计居民保持高度警惕，随时准备撤离。据美联社报道，马荣火山11日晚持续数小时喷出岩浆，流入东南山沟。马荣火山位于菲律宾东北部阿尔拜省。当晚，该省首府黎牙实比一些餐厅和酒吧的顾客纷纷来到户外，拍摄14公里外火山喷发的壮观景象。2018年1月23日，在菲律宾阿尔拜省，马荣火山喷发出火山灰。
