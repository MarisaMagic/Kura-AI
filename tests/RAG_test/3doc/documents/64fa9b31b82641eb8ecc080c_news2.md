# 2023年8月9日，应急管理部部长王祥喜部署安排国家防总办公室、应急管理部等与中国气象局、水利部、自然资源部联合调度会商，研判雨情、汛情、地质灾害和6号台风“卡努”发展趋势，并安排部署重点地区防汛救灾工作。（news2）

本轮降水与前期出现暴雨洪涝灾害的地区重叠，要特别防范农田渍涝、中小河流洪水、山洪、地质灾害。
2023-08-10 17:00:00，正文：央视网消息：记者8月10日从应急管理部获悉，2023年第6号台风“卡努”预计于近期移入我国东北地区。国家防总已于8月9日18时针对辽宁、山东启动防汛防台风四级应急响应。8月10日上午，国家防总办公室、应急管理部继续与中国气象局、水利部等部门进行防汛专题会商调度，研判雨情、水情、灾情和6号台风“卡努”发展趋势，安排部署重点地区防汛救灾工作。会商研判指出，目前，海河流域的汛情、险情、灾情总体平稳，洪水正在过境天津，防汛抗洪压力仍然较大。当前，国家防总维持对天津的防汛二级应急响应，对北京、河北、吉林、黑龙江维持防汛三级应急响应。根据气象部门预测，台风“卡努”预计8月11日夜间至12日凌晨移入我国境内。
