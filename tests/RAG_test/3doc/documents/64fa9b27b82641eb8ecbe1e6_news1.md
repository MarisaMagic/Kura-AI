# 2023年8月11日，中南大学湘雅三医院眼科副主任医师曹燕娜在接受人民网记者采访时指出，由于暑期孩子们过度使用电子产品等原因，干眼症症状会越明显。（news1）

全國各地中小學生紛紛開啟暑假模式。孩子是放假了,可孩子們的眼睛卻更“忙”了,看書、看電視、看手機.這也導致一些孩子的眼部健康亮起了紅燈。“進入7月,眼科門診干眼症患兒一下子多了起來。如今,干眼症患者群體正在從成人擴展至學齡兒童,兒童患者在門診中佔了近1/3。”黑龍江省醫學會小兒眼底病學組委員、哈爾濱醫科大學碩士研究生導師、教授周丹對科技日報記者說。好發於成人的干眼症,怎麼還“盯”上了孩子呢?干眼症不再是成年人“專利”干眼症也被稱為角結膜干燥症,它是由於淚液分泌不足、淚液蒸發過快過多、淚液成分異常等因素,導致淚膜的穩定性降低,而出現的眼部不適、眼表病變。干眼症的典型症狀包括眼睛干澀、疲勞、異物感,
