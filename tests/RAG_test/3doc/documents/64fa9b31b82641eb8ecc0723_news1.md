# 2023年7月31日晚，国家防总办公室、应急管理部加密研判会商，在北京、天津、河北等地研判海河流域暴雨洪涝灾害，安排部署防汛抗洪抢险救灾工作。（news1）

7月28日，国家防总副总指挥、水利部部长李国英主持专题会商会，与北京、天津、河北、山西、山东、河南等省市和海河水利委员会视频连线，重点安排部署海河流域暴雨洪水防御工作，针对6省市启动洪水防御Ⅲ级应急响应，派出7个工作组赴海河流域各地及南水北调中线工程沿线协助指导防御工作，全力应对暴雨洪水。李国英部长于29日率水利部工作组赴京津冀检查指导北运河洪水防御工作。水利部副部长刘伟平每日主持会商，滚动分析研判台风暴雨洪水形势，细化实化防范应对措施。水利部及时发布洪水橙色预警，每日“一省一单”靶向预警，督促指导地方做好水库、在建工程安全度汛及中小河流洪水、山洪灾害防御及蓄滞洪区运用准备等工作。根据汛情发展态势，水利部于7月30日12时将针对北京、天津、河北的洪水防御应急响应提升至Ⅱ级，并向3省市水利部门和海河水利委员会发出通知，对各项防御工作进一步安排部署。
