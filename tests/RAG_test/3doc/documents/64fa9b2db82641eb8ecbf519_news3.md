# 2023年7月19日，由中铁十局参与承建的中泰铁路一期工程3-1标段在泰国曼谷签约，中铁十局与泰国国家铁路局等相关方共同签约。（news3）

中国企业平高集团与泰国企业合作参与工厂变电站的总包工程，仅用6个月就顺利完工，刷新了泰国当地变电站总包工程工期的记录。中国的高质量产品、快速的履约速度和积极的服务，获得当地好评，并助力中国新能源企业在泰国扎根、服务全球。随着共建“一带一路”推进，未来的中泰电力合作将进一步深化，并给各方带来更多的发展机遇。今年7月，中国企业设计生产的供电设备顺利完成在泰国宋卡府丹诺变电站的安装和试验，这是中国电力企业在泰国交付的第一台混合式气体绝缘开关，代表着中国的电力装备产品质量和履约能力得到泰国电力核心市场的认可。泰国商业部高级贸易专员蓬皮表示，中国连续10年成为泰国最大贸易伙伴，2022年双边贸易额达1350亿美元。泰中两国经贸合作领域广泛、合作程度深厚，泰方希望与中方在数字经济、绿色发展、新能源等领域开展更多合作。随着中国电力企业积极参与在泰国投资建设和泰国电力网络的发展，泰中能源领域合作将实现更大发展，推动共建“一带一路”取得更多成果。举报/反馈
