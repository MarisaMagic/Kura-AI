# 欧米茄推出了一款新的海马系列300米潜水表“金墨黑”，这款腕表采用了全新的配色和激光技术，表壳直径43.5毫米，采用黑色氧化锆陶瓷和Sedna 18K金制成。（news2）

1巧遇绿马表主：ShallWeFuck精彩内容：上周末出差，在大兴机场随便逛的时候发现了欧米茄的专柜就进店试戴，之前一直钟情于海马系列300米潜水表黑盘款，但眼神一晃，发现在隔壁柜台中有一枚低调的海马系列300米潜水表绿盘款安静地躺在柜台中，立刻被吸引。试戴之后发现这抹绿低调又耐看，毫不犹豫直接拿下。经典的外观设计，盘面上的波浪纹就像后半夜的深海，借着点点星光，翻起绿色的层层波浪。8800机芯很可靠，背透设计可以看到机芯的运转，同时拥有强大的防磁能力，很适合日常佩戴。2不惑之年入手海马表主：倔强浪子精彩内容：作为一个007电影的骨灰级影迷。从第一次在007电影《黄金眼》中看到海马系列300腕表，就成了欧米茄的粉丝。如今终于在不惑之年拥有了欧米茄海马系列300米潜水表007版。在入手之前我仔细研究了一下欧米茄的所有系列，还是觉得海马系列比较适合自己。
