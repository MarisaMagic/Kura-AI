# 2023年7月31日，株洲市交通运输局查处了三起典型案例，包括易建文无证驾驶出租车、株洲欣达货运有限责任公司雇佣无证驾驶员何海龙以及陈兵擅自改装运输车辆。（news2）

据统计，12月7日—9日，全市共查纠违法行为2974起，其中，驾乘摩托车和电动车自行车不戴头盔1112起，酒驾醉驾36起，无证驾驶37起，超载71起，超员4起，其他1714起。湘潭公安交警针对近期天气变化、交通流量和事故规律特点，结合务工人员集中出行规律，加强早晚重点时段的勤务部署，加大对务工人员集中出行和乘坐车辆交通违法行为的查纠管控和查纠力度，紧盯“两客一危一货一面”、7至9座小型面包车、电动自行车等重点车辆，科学配置警力，在城区、国省道、农村重点路段开展设卡检查，严查无牌无证、酒驾醉驾、闯红灯、“三超一疲劳”、违停乱停等交通违法行为，通过加大路面管控力度，切实提高了事故预防工作的针对性、有效性。持续推进“戴帽工程”专项整治行动。对摩托车、电动车无牌无证、戴安全头盔、违法载人、逆行、闯红灯、非法加装遮阳伞等交通违法行为进行文明劝导和依法查处，提升广大交通参与者交通安全意识和自我保护意识。
