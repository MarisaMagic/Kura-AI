# 2023年7月27日，刑侦鉴识专家李昌钰因1985年一起谋杀案中涉嫌伪造证据被美国联邦法官裁定负有责任，李昌钰对此表示失望并否认捏造证据。（news3）

直到当日中午12时许，被害人的儿子因为一直打不通母亲电话，便从县城赶回家中查看情况。
2023-07-26，正文：李昌钰回应被指伪造证据！一世盛名可能要遭重创李昌钰2020年曾为自己在调查中的行为进行了辩护。李昌钰回应被指伪造证据，“在我57年的职业生涯中，我调查了8000多起案件，但从未被指控有任何不当行为或故意作伪证。”有“神探”之称的刑事鉴证专家李昌钰，一世盛名可能要遭重创。值得注意的是，李昌钰已经85岁了。作为出生于江苏如皋、定居美国的美籍华人，他在台湾中央警察学院就读时就展现出了杰出的破案天赋。因侦破金门岛军饷盗窃案而一举成名，随后又陆续在美国破获多起重大案件，赢得“中国侦探”称号，名声全球。美国法官21日判决，旅美刑事鉴识专家李昌钰针对1985年一起谋杀案“伪造证据”负有责任，导致康涅狄格州2名没有犯下谋杀罪的男子入狱数十年。李昌钰有支付损害赔偿的责任，金额将由陪审团决定。
