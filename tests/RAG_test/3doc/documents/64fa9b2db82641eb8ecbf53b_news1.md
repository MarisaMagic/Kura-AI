# 2023年7月20日，巴西圣保罗州，巴西航空工业公司及其子公司EVE公司宣布将建造“飞行车”工厂，生产电动垂直起降飞行器。（news1）

双方现场签署了首批 100 架 AE200 采购协议。沃飞长空称，此次与华龙航空达成合作，标志着国内电动垂直起降飞行器（eVTOL）与公务航空领域的首次创新联合。双方后续将推进 eVTOL 持续适航方面标准审定，eVTOL 垂直起降机场建设、航线运营等领域的进展。IT之家注意到，去年 11 月，AE200 电动垂直起降航空器（eVTOL）已正式获得型号合格证（TC）申请的受理。这是中国民用航空局颁发的中国首张有人驾驶载人电动垂直起降航空器 TC 受理申请通知书，依据中国民用航空局最新颁发的 AP-21-AA-2022-11《型号合格审定程序》，AE200 电动垂直起降航空器型号合格审定工作正式启航。AE200 电动垂直起降航空器获得中国民用航空局颁发的型号合格证（TC）后，可用于空中游览服务等，后续扩展型号可用于航空医疗救护、航空物流、应急救援、空中执法等多样化用途。广告声明：文内含有的对外跳转链接（包括不限于超链接、二维码、口令等形式），用于传递更多信息，节省甄选时间，结果仅供参考，IT之家所有文章均包含本声明。
