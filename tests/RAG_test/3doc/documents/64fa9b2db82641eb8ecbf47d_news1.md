# 2023年8月17日，北京世界机器人大会上，中国电子学会副理事长兼秘书长陈英发布了《中国机器人技术与产业发展报告（2023年）》。（news1）

本届大会拟发布《中国机器人技术与产业发展报告（2023年）》，机器人十大前沿技术（2023-2024），2023世界机器人大会论文集等成果。2023世界机器人大会“投创之星”，2023世界机器人大赛十大技术创新成果，机器人产业发展相关政策等也将在大会期间陆续发布。北京市经济和信息化局副局长苏国斌透露，北京市经济和信息化局研究制定了北京市促进机器人产业创新发展若干措施，以解决北京市机器人产业发展的主要问题为导向，计划在机器人大会上正式发布。本届大会将继续召开博览会，140余家国内外机器人企业携近600件展品亮相展会，其中40家企业首次参展，50余款新品首发，30余家关键零部件企业展示最新攻关成果。在总面积达4.5万平方米的展馆内，将首次全馆打造“机器人+”制造业、农业、商贸物流、医疗健康、商业社区服务、安全应急和极限环境应用等10大应用场景板块。
