# 2023年8月14日，湖北建始县举办了县委人才工作会暨校地合作推进会，全省内外的10余所高校（科研院所）专家教授和相关用人单位参与，建始县委书记张渊平出席并致辞。（news2）

李青对济阳区对学校发展的支持和帮助表示感谢，介绍了学校相关工作情况，他表示，学校将继续在人才培养、技术支撑等方面发挥助力作用，希望济阳区对学校发展继续给予支持帮助。学校也将进一步聚焦校地双方共同需求，着力提升学校社会服务能力，继续推进校地双方合作交流，努力实现校地共赢。会上，山东建筑大学团委副书记杨菁、共青团济阳区委书记王璐为“校地共建人才培养基地”揭牌并签订共青团校地共建共推五项行动合作协议。下一步，山东建筑大学与济阳区将继续坚持资源共享、优势互补、学用结合、互利共赢的原则，着力推动“校地共建人才培养基地”的人才交流、返家乡实习实践活动等，共同打造校地合作的典范与标杆。招生就业工作处副处长毛有虎、管理工程学院党委副书记袁法涛等同志参加上述活动。
