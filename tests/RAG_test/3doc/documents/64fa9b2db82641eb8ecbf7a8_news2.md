# 2021年7月22日至28日，德州学院经济管理学院实践团赴山东省威海市郐家村开展以“电商助农”为主题的大学生暑期“三下乡”社会实践活动，通过网络电商直播帮助村民销售编织簸箕。（news2）

面对当地电商人才匮乏的困境，团队认为培养当地村民的“新农人”意识至关重要。实践团走家串户为村民开展电商基础知识宣讲，帮助想要参与直播的村民开通账号并现场试播，鼓励大家利用农闲时间在网络平台推广家乡的好山好水好产品。在农户家中，实践团成员当起了助播。“爷爷，对着镜头笑一笑，让大家知道我们咸宜的好山好水好腊肉。”2021级电子商务专业的李娇姚指导当地老人开通了抖音账号，让闲暇在家的老人做起了家乡的“代言人”。团队成员体验采茶过程。重庆商务职业学院供图此外，在咸宜镇民心茶叶专业合作社，实践团参观了标准化的生产车间，物流管理专业的成员现场体验了茶叶分装过程，电子商务专业的成员前往高山“林间茶”种植基地拍摄照片，并制作宣传推广图册。整个实践过程中，不同专业的学生锻炼了专业知识，也为企业解决了实实在在的需求。
