# 2023年8月，华特迪士尼公司决定在其流媒体平台迪士尼+上不播放与土耳其“国父”穆斯塔法·凯末尔·阿塔图尔克相关的《阿塔图尔克》系列剧集，引发土耳其方面的批评。（news2）

报道称，今年4月底，土耳其总统埃尔多安曾宣布，代号为阿布·侯赛因·库拉希的“伊斯兰国”组织头目，在土耳其国家情报局于叙利亚的一次行动中被“消灭”。据土耳其媒体报道，阿布·侯赛因·库拉希于4月29日深夜在叙利亚北部城镇詹代里斯被打死。双方交火持续约一个小时，随后当地居民听到一声巨大的爆炸声。报道称，“伊斯兰国”组织发言人指责“解放叙利亚”联盟为安卡拉工作并杀害了阿布·侯赛因·侯赛尼·库拉希。发言人还说，“解放叙利亚”联盟的士兵将其遗体移交给了土耳其政府。“伊斯兰国”组织的发言人3日还宣布，该组织新的头目是阿比·哈夫斯·哈希米·库拉希。
