# 2023年7月31日，中华人民共和国国防部在北京人民大会堂举行招待会，庆祝中国人民解放军建军96周年，中央军委委员、国务委员兼国防部长李尚福在会上致辞。（news3）

招待会向来宾展示了《为了和平 命运与共——维护世界和平的中国军队》系列图片，播放了《我在》等专题片，充分展示中国军队维护世界和平稳定、履行大国军队国际责任的精神风貌。招待会气氛热烈友好，来宾纷纷祝贺中国人民解放军建军96周年，高度赞赏新时代中国国防和军队建设成就，积极评价中国军队为维护世界和平所做贡献。（中国驻印度大使馆网站）【责任编辑：董静】
近日，我驻多国使馆及海外维和部队举行招待会等活动，热烈庆祝中国人民解放军建军96周年。中国驻英国大使馆举行的招待会上，各国来宾高度赞赏中国国防和军队现代化建设成就，希望进一步发展对华关系，拓展防务领域交流合作。在中国驻新加坡、菲律宾、刚果（布）、尼泊尔大使馆举行的招待会上，来宾们对中国人民解放军建军96周年表示祝贺，高度赞赏中国军队为维护世界和平与地区安全稳定所发挥的积极作用。
