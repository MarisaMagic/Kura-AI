# 2023年8月17日，北京世界机器人大会上，中国电子学会副理事长兼秘书长陈英发布了《中国机器人技术与产业发展报告（2023年）》。（news2）

本文源自：金融界资讯举报/反馈
中国青年报客户端讯（中青报·中青网记者 尹希宁 实习生 陈智敏）8月16日至22日，一场属于全球机器人的行业盛会——2023世界机器人大会将在京召开。据了解，本届大会以“开放创新 聚享未来”为主题，由6场主论坛、近30场专题论坛及配套活动组成。大会将邀请320余位国际组织代表、知名科学家、企业家代表参会，围绕机器人开放合作、技术趋势、产业应用、生态建设发表主旨报告、开展高峰对话。中国电子学会副理事长兼秘书长陈英表示，世界机器人大会搭建国际交往合作平台，致力于成为产业推动加速器、技术引领风向标，在产业化、专业化、国际化、前沿性等维度全面提质，旨在呈现一场覆盖“政、产、学、研、金、服、用”等各方面的全球机器人行业盛会。本届大会拟发布《中国机器人技术与产业发展报告（2023年）》，机器人十大前沿技术（2023-2024），2023世界机器人大会论文集等成果。
