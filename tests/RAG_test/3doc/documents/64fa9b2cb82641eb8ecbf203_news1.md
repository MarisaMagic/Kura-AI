# 2021年7月24日，韩国蔚山市一家残疾人福利设施报告收到可疑国际邮包，部分打开包裹的人出现身体不适。（news1）

蔚山一家残疾人福利设施20日收到包裹，3名员工打开后出现头晕呼吸困难等症状。首尔市、济州道等多地接到类似报警。韩国警方及军方21日接警后出动，首尔市中央邮局大楼疏散约1700人，包裹内没有发现危险物品。韩国国防22日发布调查结果，称这些包裹疑似网络刷单邮件，不含有毒物品，异味因粘合剂变质产生。报道称，韩国蔚山市一间福利院机构员工表示，20日在打开来自台湾的不明国际包裹后出现呼吸困难、晕眩等症状。济州、大田、首尔各地21日也陆续接获相关通报。韩国多次发送公共安全警报，呼吁韩国民众收到来路不明的国际包裹时不要开封，并立即通报警方和消防单位。报道还提到，因出现可疑包裹，位于明洞闹市区的首尔中央邮局因疏散大楼内1700多人，所幸这些可疑包裹实际并未造成任何人员伤亡。
