# 2022年7月26日，中国少年儿童文化艺术基金会回应部分培训机构冒名参加“致敬英雄”全国青少年文化艺术创作主题教育竞赛并向家长收费的问题，强调该竞赛坚持公益性，未授权任何机构和个人以竞赛名义收取费用。（news3）

是不是各种兴趣培训班的“黄金假期”？为孩子报班的时候，作为家长的您是否考察过培训机构的情况？近日，长沙市雨花区人民法院公开审理的被告人曾某慧诈骗22名家长60万元择校费一案令人深思！利用家长政策认知盲区赚“答谢红包”曾某慧在长沙开办了两所培训机构，之前运营良好。为了扩大影响力，方便培训机构的持续招生，曾某慧接受了一些家长的入学请托，帮助协调孩子小学入学问题。曾某慧对教育相关政策比较了解，接触中发现了许多家长的“认知盲区”，例如以为户口或者房产及社保不在长沙本地，就没有就近入学资格。而实际上，国家九年制义务教育规定每个孩子都可以入学，只是就读学校位置不同。所以，曾某慧利用这个信息差，蒙骗了诸多“焦虑的家长”。家长们会给她发红包或者请客吃饭作为答谢，她的名声在家长群里逐渐传开。
