# 2019年6月，柬埔寨少数民族妇女的16岁儿子杜丹在学校突然感到心脏不舒服，后被确诊患有先心病，随后成为柬中医疗合作项目的救助对象，前往中国云南省阜外心血管病医院进行治疗。（news3）

新华社发(凯乔 摄)新华社万象6月23日电通讯:感谢中国医生给了孩子正常生活的机会——记中国医疗组在老挝开展先心病儿童救助行动新华社记者章建华“感谢中国医疗组给她一个像正常孩子一样生活的机会,相信中国医疗专家的帮助会改变女儿的命运。”西维莱·万纳冯是一名6岁先心病患儿的母亲。日前,万纳冯的女儿在“中国-老挝先天性心脏病联合筛查和治疗”医疗合作项目中接受了中国医疗组的介入治疗并顺利出院。6月17日,在老挝北部琅勃拉邦,中国医疗组对当地儿童进行先心病免费筛查。新华社发(凯乔 摄)6月中下旬,在中国民间组织国际交流促进会的协助下,此次医疗合作项目由中国医学科学院阜外医院、云南省阜外心血管病医院、中华慈善总会和云南省政府新闻办在老挝联合开展。中国医疗组以先进的技术和设备,在老挝孟赛、琅勃拉邦、万象等地,对近6000名3岁至18岁的老挝中小学和幼儿园学生进行了先心病免费筛查。
