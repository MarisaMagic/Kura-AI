# 2021年7月22日至28日，德州学院经济管理学院实践团赴山东省威海市郐家村开展以“电商助农”为主题的大学生暑期“三下乡”社会实践活动，通过网络电商直播帮助村民销售编织簸箕。（news1）

主播进行时（北京）科技有限公司作为本次活动的协办单位，对活动提供了大力支持和宣传推广。在8月7日的直播活动中，北京财贸职业学院“千人百村”暑期社会实践团队邀请学校老师到现场指导，并搭建专业的直播间。本场直播由北京财贸职业学院的学生为主持人，村民们依次进入直播间介绍镇域好物，每个村民在直播间里都侃侃而谈，认真的为观众讲解农产品的种植方式、文创产品的优点及特点，一一回复观众提出的问题。幽默的语言、详细的介绍引得屏幕前消费者纷纷下单、争相购买。本次直播活动的开展，多维度展现了大兴庄镇当季特色农产品、推介了好景好物，同时也通过开展电商直播技能培训，进一步挖掘了镇域直播达人和新农人，一同助力乡村振兴。下一步，大兴庄镇将利用镇村播学院平台继续把镇域群众的视野开阔起来，让镇域群众从“埋头种地”到“网上吆喝”，促进镇域特色农产品走向更广阔的空间，让电商直播赋予乡村振兴“新动能”。
