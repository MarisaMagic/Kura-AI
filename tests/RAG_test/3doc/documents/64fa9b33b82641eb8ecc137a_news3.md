# 2023年8月13日，在尼日尔首都尼亚美，尼日利亚伊斯兰高级学者代表团与尼日尔政变领导人阿卜杜拉赫曼·奇亚尼会面后，尼日尔军方表示愿通过外交途径解决当前问题，缓和与西非国家经济共同体的对峙局面。（news3）

然而据报道，以阿卜杜拉赫曼·奇亚尼将军为首的政变领导人拒绝了西共体、美国和其他国家的外交努力，引发了对贫困的萨赫勒地区将进一步陷入冲突的担忧。报道称，西共体议会12日举行会议，讨论在尼日尔采取进一步行动的问题。该发言人表示，尽管没有作出决定，但议会成立了一个委员会，计划会见尼日利亚总统提努布，以获得他的许可前往尼日尔。根据尼日利亚总统府消息人士的说法，一群尼日利亚知名伊斯兰学者也与提努布会面，以获得他的批准，提努布同意了他们的请求。他们的计划是到尼日尔会见当地宗教人士，以化解外交僵局。法新社援引消息人士的话表示：“宗教人士到尼亚美是要向军政府领导人解释，尼日利亚不会与尼日尔作战，有关尼日尔的决定并不是尼日利亚的想法，而是作为地区组织的西共体作出的。”据报道，在尼日利亚，一些议员和政治家在参议院提出，总统提努布应当重新考虑西共体军事干预尼日尔的做法。尼日利亚北部与尼日尔有着传统的贸易和社会联系，在文化、宗教和语言方面关系亲密。
