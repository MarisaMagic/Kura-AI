# 2023年7月21日，菲律宾火山地震研究所在马荣火山顶部火山口观测到持续28秒的短时熔岩喷射。（news2）

马荣火山高2463米，以“完美圆锥形”山体知名，是菲律宾最活跃的火山。最近一次喷发在2018年，迫使数万人逃离家园。（袁原）catalogs:115955;contentid:11467762;publishdate:2023-06-12;author:李丁丁;file:1686563841428-c8d81c57-1b66-455c-aaee-2fc566f5214c;source:29;from:新华网;timestamp:2023-06-1217:57:18;[责任编辑: ]
中新社马尼拉10月21日电　（张兴龙　蒋雨峰）菲律宾火山地震研究所21日8时发布的消息显示，在过去24小时，马荣火山顶部火山口出现两次短暂熔岩喷发，并伴有地震和次声信号。据菲火山地震研究所通报，当前马荣火山口仍在缓慢喷出岩浆，岩浆顺山体而下，最长一处达3.4公里。在过去24小时里，该所还在马荣火山录得31次火山地震、1次火山碎屑密度流以及87次落石事件。菲火山地震研究所指出，当前马荣火山喷发警戒级别维持在三级，意味着其仍处于“相对较高的动荡水平”，有可能在未来几周甚至几天内发生“危险喷发”。
