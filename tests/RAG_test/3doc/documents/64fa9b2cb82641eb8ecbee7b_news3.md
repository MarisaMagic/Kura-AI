# 2023年7月27日，由于强台风“杜苏芮”的影响，福建厦门、漳州、泉州及广东汕头等地启动了防台风Ⅰ级应急响应，实施了'三停一休'和'五停'等措施。（news3）

中央气象台消息，27日12时，台风“杜苏芮”距离福建省厦门市南偏东方向约415公里，中心附近最大风力15级（ 50米/秒，约180公里/小时，强台风级），“杜苏芮”将以每小时15公里左右的速度向北偏西方向移动，强度有所增强。26日傍晚至27日上午，漳州市、泉州市、厦门市陆续发布“三停一休”动员令。漳州市人民政府防汛抗旱指挥部7月26日18时起提升防台风应急响应至Ⅰ级，并于26日发布漳州市防汛防台风紧急动员令：7月27日中午12时起至7月29日中午12时，在全市范围内实行“三停一休”，即停工（业）、停产、停课、休市，动员员工提前下班回家，尽量做到人不出门、车不上路。泉州市人民政府防汛抗旱指挥部于7月27日8时提升防台风应急响应为Ⅰ级，并发布防御台风动员令：7月27日18时起至7月29日12时，全市实行“三停一休”，即停工(业)、停产、停课、休市。
