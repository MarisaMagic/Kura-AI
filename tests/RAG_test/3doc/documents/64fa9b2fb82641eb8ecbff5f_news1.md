# 2023年8月14日，湖北十堰市公安局茅箭区分局民警在贵州省六盘水市的一家电影院成功抓获涉诈嫌疑人何某，何某当时正在观看电影《孤注一掷》。（news1）

8月14日，涉诈嫌疑人何某正在贵州六盘水一电影院里观看《孤注一掷》，湖北十堰茅箭区公安局民警突然到来，成功将其抓获。更让人意料未及的是，何某的丈夫邓某也是涉诈人员，民警于当日21时将其抓获。图源：网络据十堰警方调查，何某的银行卡在今年6月有异常转账交易。其明知转账资金为电信网络诈骗所得赃款，但在巨大的利益诱惑下，她仍将自己名下的银行卡出借给电诈团伙，并告知对方自己的支付宝及银行卡密码。今年6月，十堰市某辖区居民高某被电信诈骗70000元，这笔钱就转到何某的银行卡中。随后何某将21000元取现交给涉诈人员，剩下的49000元通过支付宝手机银行转给涉诈人员。何某在交代犯罪事实时表示，《孤注一掷》最近在社交媒体上很火，她就也想来看看，“看电影的时候我就有点担心，没想到真被抓了。”图源：平安十堰涉诈嫌疑人去电影院看《孤注一掷》被抓的消息传出后，相关词条立刻上了网络热搜榜。
