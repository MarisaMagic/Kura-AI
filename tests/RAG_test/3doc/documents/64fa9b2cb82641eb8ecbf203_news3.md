# 2021年7月24日，韩国蔚山市一家残疾人福利设施报告收到可疑国际邮包，部分打开包裹的人出现身体不适。（news3）

截至24日上午5时，有关部门共接到2141起收到可疑国际包裹的报警，其中有1462起是误报或咨询。报道说，韩国国务调整室就蔚山市第一起报警表示，消防部门和警方等初步调查机构回收涉案包裹并对其进行第一次检查，但未检出化学、生物学、放射性相关物质。之后，涉案包裹交由国防科学研究院进行缜密检查，也未检出危险物质。该设施3名负责人在打开涉案包裹后出现头晕、呼吸困难症状，已于22日出院。此外，报道还说，韩警方和消防部门还对回收的679起不明包裹进行检查，均未发现化学物质。据悉，韩政府不排除涉案包裹与“刷单骗局”有关的可能性。国务调整室表示，目前暂无证据表明可疑国际包裹与恐怖袭击有关，但反恐相关机构仍保持戒备以防万一，并提醒民众收到来源不明的国际包裹时立即向警方和消防部门等有关机构报告。
