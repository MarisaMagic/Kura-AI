# 2023年7月28日晚，湖北省第十六届中学生运动会在鄂州国际会展中心举行开幕式，全省18支代表团参加。（news3）

文体展演 极目新闻记者赵德龙 摄据了解，为筹办本次开幕式，前后20余所学校参加演出，经过80多天紧张排练，1118位台前幕后演职人员辛勤付出，最终为观众呈现出一场视听盛宴。“本次开幕式整体效果达到了预期水平，全体演职人员连续排练2个多月，克服了种种困难，希望大家继续关注我们闭幕式的演出。”省中运会开幕式总导演李翔说。
2023-07-29 16:14，正文：荆楚网（湖北日报）讯（记者林杉 通讯员张思）绿色教育，金色童年。中法武汉生态示范城第二小学位于蔡甸区东大门新天村。学校秉承“打造成长绿洲，成就绿色梦想”的学校精神，坚持以德立校、全面育人的办学思想，以培养学生全面发展为目标，以提升教师整体素养为核心，不断探索绿色德育课程化、绿色课堂模式化、绿色管理线条化的工作路径。
