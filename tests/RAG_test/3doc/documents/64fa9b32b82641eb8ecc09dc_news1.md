# 2023年8月，日本政府计划在福岛核污染水排海日期，最快可能在8月底开始，福岛县津岛居民三瓶春江对此表示不满。（news1）

消息人士透露，日本政府最早可能在8月22日宣布福岛核污染水排海日期。 资料图：日本首相岸田文雄。 据报道，当地时间18日，正在美国访问的岸田对记者表示，他将在返回日本后于日本时间20日前往福岛，并视察福岛第一核电站。 日本《朝日新闻》援引多名日本政府消息人士的话称，岸田计划在21日与日本全国渔业联合会(全渔联)和福岛县渔业联合会(福岛渔联)的干部会面，届时他将就福岛核污染水的安全问题进行说明。 资料图：福岛第一核电站。 报道称，会面后，日本政府可能会在22日召开内阁会议，并宣布福岛核污染水的排放日期。 日本政府曾于2015年向福岛渔业人员保证，在未获相关人员理解前，不会进行核污染水排海行动。2023年7月14日，日本经济产业相西村康稔向全渔联会长坂本雅信和福岛渔联会长野崎哲寻求理解时，二人均表示，反对福岛核污染水排海的立场没有改变。
