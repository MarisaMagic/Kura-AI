# 2023年8月，湖北宜来高速鹤峰东项目中的关键工程，云南庄特大桥的建设进展顺利，工作人员正在进行三角区汇合段施工作业。（news2）

要结合实际加紧谋划灾后重建项目，加强水路科学规划，健全防洪工程体系，完善农村基础设施，各方携手共建更加美好的家园。　　副市长李文海、谢元参加。（记者 米哲 周志强）举报/反馈
文、图/羊城晚报全媒体记者 李程 通讯员 清花高速历经24个小时连续奋战，7月8日晚，清花高速项目关键控制性工程——北江特大桥首个主墩承台第一次浇筑顺利完成，此次共浇筑混凝土2380.2立方米，预计本月底完成后续浇筑任务。清花高速项目是广东省高速公路规划网中的重要组成部分，同时也是广东省“十四五”规划重大交通基础设施的重点建设项目。北江特大桥全长1440米，为主跨360米的双索面混凝土四塔斜拉桥，主塔塔身形似“钻石”，塔冠宛若“凤凰尾翼”，是清花高速项目的控制性工程之一，建成后将成为清远市的新地标。据悉，为针对北江特大桥主墩大体积混凝土温控方案，清花高速项目专门组织专家论证，多次召开施工专题会和技术交底会，科学布局，谋定后动。
