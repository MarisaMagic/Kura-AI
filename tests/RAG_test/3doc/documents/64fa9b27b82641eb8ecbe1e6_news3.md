# 2023年8月11日，中南大学湘雅三医院眼科副主任医师曹燕娜在接受人民网记者采访时指出，由于暑期孩子们过度使用电子产品等原因，干眼症症状会越明显。（news3）

还可能与环境因素有关。例如长期待在空调房里,也会使眼睛里的水分蒸发得更快,加重泪液流失,出现干眼的症状。如何判断小朋友是否有干眼症?长沙爱尔眼科医院角膜与眼表病专科主任李宽舒博士表示,当孩子眼睛有不舒服的症状时,他们往往不善于或不会准确表达,因此家长往往很难发现孩子眼健康异常的情况。如果孩子出现以下行为,应考虑孩子是否存在干眼症:1频繁揉眼、眯眼或眼睛发红;2不愿到对他眼睛有刺激性的场合去。若有这些表现时,需要警惕孩子是否患干眼症等眼部问题,此时应及时带孩子到医院检查就诊。(文/李倩)",
