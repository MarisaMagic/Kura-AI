# 2023年7月24日，湖南天心种业有限公司再次通过农业农村部办公厅的核验，延续了国家生猪核心育种场资质，成为省内唯一一家通过核验的国家级生猪核心育种场。（news2）

生产规模为1200头,为湖南省一级原种繁殖场。验收组在考察后表示,湖南大齐牧业有限公司的繁育设施完善、技术力量强、种猪来源清楚、种质水平高、系谱档案较齐全,符合种猪一级扩繁场换证条件和要求,通过换证验收。同时,验收组还就岳塘区今后开展种猪生产性能测定工作、加强种猪选育、提高种猪生产性能等方面提出了意见和建议。
