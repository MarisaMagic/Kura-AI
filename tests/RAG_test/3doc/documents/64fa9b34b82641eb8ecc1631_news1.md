# 2023年7月24日，湖南天心种业有限公司再次通过农业农村部办公厅的核验，延续了国家生猪核心育种场资质，成为省内唯一一家通过核验的国家级生猪核心育种场。（news1）

并对全区进一步规范种猪生产经营工作进行指导。验收组一行实地考察了位于荷塘乡的湖南大齐牧业有限公司种猪场,详细了解了该场的选址布局、栏舍建设、防疫条件和粪污设施建设情况,听取了该企业的情况汇报,并查阅了种猪场系谱档案等有关资料。湖南大齐牧业公司是岳塘辖区内唯一一家种猪生产企业,该公司占地120亩,现饲养优良的大约克、杜洛克、长白三个品种种猪,生产规模为1200头,为湖南省一级原种繁殖场。验收组在考察后表示,湖南大齐牧业有限公司的繁育设施完善、技术力量强、种猪来源清楚、种质水平高、系谱档案较齐全,符合种猪一级扩繁场换证条件和要求,通过换证验收。同时,验收组还就岳塘区今后开展种猪生产性能测定工作、加强种猪选育、提高种猪生产性能等方面提出了意见和建议。
