# 欧米茄推出了一款新的海马系列300米潜水表“金墨黑”，这款腕表采用了全新的配色和激光技术，表壳直径43.5毫米，采用黑色氧化锆陶瓷和Sedna 18K金制成。（news3）

一直以来终身保留一枚海马腕表，也是我的目标之一，所以又入了一枚海马系列300米潜水表黑盘款。因为玩过无数的腕表以后，我发现，欧米茄是一个值得信赖的品牌，有历史情怀，是一个专心于技术的好品牌。4我心目中的白月光表主：调皮的八戒精彩内容：这两年陆陆续续的买了好几枚腕表，正装表和休闲表都有了，唯独缺少一枚潜水表。前前后后也看了很多表款，偶然看到这枚欧米茄海洋宇宙600米至臻天文台表，白色表盘很吸睛，夏天佩戴也比较清爽，防水深度达60个大气压，日常足够用，我手腕偏细，这枚表盘39.5毫米上手正合适。佩戴一段时间后，不得不说欧米茄的机芯走时真的不错。5本命年入手海马表主：道壹、精彩内容：最近一直想买一枚腕表，看来看去，最后看中了欧米茄的海马系列。我弟弟有一枚海马系列300米潜水表，借来试戴发现感觉还不错。后来去专柜看表的时候被海马系列600米潜水表吸引，尤其是四分之一橙很有个性和特点。
