# 近期，上汽集团官方发布，旗下高端新能源车型飞凡R7搭载了由均普智能研发定制与交付的国内首批量产的4D成像雷达，年产能60万颗。（news1）

2022年，多款激光雷达量产车型重磅发布，激光雷达进入普及元年。随着国内外造车新势力智能驾驶系统纷纷启用激光雷达方案，全球汽车行业对于激光雷达的产能需求骤然攀升。均普智能（688306）方面透露，其即将为世界500强的汽车一级零部件供应商交付一条激光雷达装配与检测产线，投产后将年产100万颗激光雷达。据了解，均普智能此条激光雷达产线配备了自主研发的工业数字化软件（piaLineController），通过采集、管理、分析产线工艺和制造数据，实现全球范围内客户工厂的生产透明度和可追溯性，大大提升产线效率及产品质量。“该条产线整个生产全过程只需一人管理与操作，产线在5分钟内可完成自动换型。”均普智能相关人士透露。今年7月，图达通激光雷达Falcon第10000台下线，这是全球首批真正实现量产上车的高性能激光雷达。图达通这条年产能10万台的激光雷达产线也是由均普智能交付完成。目前全球范围内智能驾驶拥有两种技术路径，“弱感知+超强智能”与“强感知+强智能”，其明显差距之一在于是否使用激光雷达。
