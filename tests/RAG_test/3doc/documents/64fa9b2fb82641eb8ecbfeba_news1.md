# 2023年8月14日，湖北建始县举办了县委人才工作会暨校地合作推进会，全省内外的10余所高校（科研院所）专家教授和相关用人单位参与，建始县委书记张渊平出席并致辞。（news1）

省领导李殿勋、吴桂英、谢卫江、周海兵，江西省领导任珠峰、史文斌参加会见。
来源：湖北日报 | 2023年07月28日 11:03:47，正文： 湖北日报讯 （记者张辉、通讯员郑轩）7月27日，湖北省政协召开“建设湖北东湖科学城 打造原始创新策源地”月度专题协商会。湖北省政协主席孙伟主持会议并讲话，副省长邵新宇出席并讲话。会上，省政协副主席杨玉华作主题发言。省直有关部门通报相关情况。梁鸣、熊志红、袁志明、曹淑云、杨道虹、曾军围绕持续打造原始创新策源地、发挥东湖科学城在全省协同创新中的引领作用、强化高质量科技供给、发挥高水平研究型大学作用、加强湖北实验室建设、发挥科技领军企业引领作用等协商建言。黄海军、张焕明、刘江东、周茂华现场提问，有关部门作回应。孙伟说，党的十八大以来，习近平总书记5次考察湖北、3次莅临光谷，作了一系列重要讲话和指示批示，并赋予湖北加快建设科技强省的重大使命任务。
