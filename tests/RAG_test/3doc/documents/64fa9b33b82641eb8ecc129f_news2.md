# 2023年8月10日，美国司法部特别检察官办公室向华盛顿联邦法院提议，自2024年1月2日开始审理前总统特朗普涉嫌试图推翻大选结果案。（news2）

丘特坎“绝无可能”让他在这一关乎“言论自由和公正选举的荒唐案件”中获得“公正审判”。美国司法部特别检察官杰克·史密斯8月1日公开起诉书称,特朗普因涉嫌试图推翻2020年美国大选结果受到刑事指控。据美媒报道,特朗普在2024年大选年将面临“繁忙的法庭行程”。明年3月25日,特朗普涉嫌向艳星支付“封口费”案将在纽约开庭审理。明年5月20日,特朗普“不当处理涉密文件”案将在佛罗里达开庭审理。此外,特朗普本月24日就试图推翻2020年大选佐治亚州结果一案向佐治亚州富尔顿县监狱自首。原标题:特朗普涉嫌试图推翻大选结果案将于明年3月4日开庭编辑:吴思责编:廖异审核:冯飞【免责声明】上游新闻客户端未标有“来源:上游新闻”或“上游新闻LOGO、水印的文字、图片、音频、视频”等稿件均为转载稿。如转载稿涉及版权等问题,请联系上游。举报
