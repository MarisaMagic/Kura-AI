# 2023年7月26日，日本政府的数据显示，日本人口连续14年下降，而外国居民数量却再创新高。（news2）

2023-07-26 14:31:31，正文：【环球网报道 见习记者 赵博元】据日本共同社26日报道，日本总务省当天公布的最新人口调查统计数据显示，不包括在日本居住的外国人，2022年日本国民人口相比前一年减少80.1万人，为1.22423亿人，这是自1968年日本人口调查统计以来最大降幅，以及首次出现所有47个都道府县人口均减少的情况。日本本州神奈川县横滨市本町购物区图源：视觉中国 报道称，截止2022年，日本已连续14年出现人口下降情况。共同社称，这一趋势表明，日本迫切需要制定措施，解决出生率下降的问题，并改善青年和妇女的就业机会。该最新人口调查统计报告显示，日本14岁及以下人口占日本总人口的11.82%，较去年下降0.18个百分点，65岁及以上人口较去年增加0.15个百分点占总人口的29.15%。年龄在15岁至64岁之间的人口，上升0.03个百分点，占总人口的59.03%。据报道，日本最新的人口调查统计报告显示，在日外国人人口三年来首次增加约28.9万人，达到299.3万人。报道称，这是因为疫情过后相对放松的边境管制促进了国际学生和技术实习生的回流。
