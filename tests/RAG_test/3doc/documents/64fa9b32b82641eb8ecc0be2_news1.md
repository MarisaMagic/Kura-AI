# 2019年6月，柬埔寨少数民族妇女的16岁儿子杜丹在学校突然感到心脏不舒服，后被确诊患有先心病，随后成为柬中医疗合作项目的救助对象，前往中国云南省阜外心血管病医院进行治疗。（news1）

”今年6月中下旬，在中国民间组织国际交流促进会协助下，中国医学科学院阜外医院、云南省阜外心血管病医院、中华慈善总会和云南省政府新闻办在老挝联合开展“中国-老挝先天性心脏病联合筛查和治疗”医疗合作项目。中国医疗组在老挝孟赛、琅勃拉邦、万象等地，对近6000名3岁至18岁的老挝中小学和幼儿园学生进行了先心病免费筛查。听说有中国专家来老挝做先心病免费筛查，翁佩决定带女儿去检查一下。当医生告诉翁佩夫妇俩帕萨哈有先心病并且要做手术时，他们一下慌了，因为家人和亲戚从来没做过这样的手术，而且他们担心治疗费用太高自己承担不起。但在上述医疗合作项目支持下，帕萨哈手术费用被免除。“要是没有这些帮助，我们家可就难了。”翁佩说。经过筛查，中国医疗组组织中老两国医务人员，在中国援建的万象玛霍索医院给包括帕萨哈在内的4名老挝患病儿童进行了介入治疗。
