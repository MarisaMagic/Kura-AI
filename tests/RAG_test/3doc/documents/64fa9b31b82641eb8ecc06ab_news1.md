# 2023年7月25日，贵州省应急管理厅在主题教育开展的背景下，做了深度的调查研究，推动解决应急管理突出问题，加强了生产经营单位全员安全生产责任制工作，提升了安全防范能力水平，同时还开展了“解剖式”调研，强化了正风肃纪，推动了作风转变。（news1）

省政协主席刘晓凯带队，副主席赵德明、任湘生，住黔全国政协委员蒙启良、左定超、黄家培，省政协秘书长熊德威一同参加调研。调研组认为，近年来，省应急管理厅贯彻落实省委、省政府决策部署，把安全生产和防灾减灾摆在突出位置，做了许多卓有成效的工作。要清醒认识我省当前安全生产隐患依然大量存在的严峻形势，强化安全生产责任制落实，强化省情和规律性认识，强化统筹协调，强化基层基础，强化安全意识教育，把开展安全生产“打非治违”专项行动同贯彻落实安全生产十五条措施紧密结合起来，抓好国务院安委会督导帮扶组反馈问题整改落实，做好当前防汛救灾工作，确保全省大局安全稳定，为高质量发展营造良好环境。部分省政协委员参加调研。
