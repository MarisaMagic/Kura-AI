# 2023年7月25日，江门海关通过“江关普法”品牌集群联动帮助江门优质食品农产品产业“强链”“补链”，并且在6月下旬对开平重点特色食品企业进行了专题普法活动。（news1）

近年来，在海关的指导和各项便利措施下，我们在出口方面有了显著的提升，例如预包装生鲜食品出口额较去年增长近4倍。”据了解，文锦渡口岸是供港鲜活产品的主要通道，被香港同胞亲切地称为“绿色生命线”。据统计，今年1至7月，经文锦渡海关监管出口的供港鲜活产品达81.4万吨，货值达139.5亿元。文锦渡海关法规科科长焦健说：“海关与供港鲜活产品出口企业，都是这条‘绿色生命线’上的一个个细胞，共同肩负着保障香港民生的使命。因此，我们开展这期送法进企业活动，目的就是为了解决企业通关的各类疑难问题，使供港鲜活产品通关更高效、更顺利。”自“八五”普法实施以来，深圳海关持续加强普法讲师团队伍建设，持续提升法治海关建设的能力，通过普法进企业、进行业，积极服务“一带一路”、产业链供应链优化升级、外贸创新发展及“三智”国际合作等方面法律法规的宣传，加大对海关出台和实施的各项政策法规的宣传力度，助力关区进出口企业依法合规经营。
