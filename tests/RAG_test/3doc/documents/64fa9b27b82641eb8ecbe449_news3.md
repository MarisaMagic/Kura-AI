# 2023年7月20日，北京举行东南亚孔子学院联席会议，向马来西亚、泰国、印度尼西亚、新加坡的五所新建孔子学院授牌。（news3）

雅加达汉语教学中心负责人菲利浦表示,孔子学院设立后,随着教学内容更加多样化,中心将有更好的发展。据介绍,印尼教育部还批准在玛琅国立大学和万隆玛拉拿达基督教大学设立另外两所孔子学院,由广西师范大学与河北师范大学参与共同建设。“孔子学院”项目是中国“汉语桥工程”九大项目之一,其宗旨是增进世界人民对中国语言和文化的了解,推动中国与外国友好关系发展,促进世界多元文化发展。责编:王玉西
中新社雅加达8月9日电 (记者 李志全)中国河南嵩山少林寺印尼交流会暨少林功夫习传基地揭牌仪式9日在位于雅加达的印尼阿拉扎大学孔子学院举行，并为师生们带来了精彩的少林功夫表演。8月9日，中国河南嵩山少林寺印尼交流会暨少林功夫习传基地揭牌仪在雅加达举行。中新社记者 李志全 摄河南嵩山少林寺法师释延恂表示，嵩山少林寺在全球多个国家设立少林文化中心，旨在让世界人民通过少林功夫强身健体并了解少林文化。
