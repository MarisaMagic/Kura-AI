# 2021年7月24日，韩国蔚山市一家残疾人福利设施报告收到可疑国际邮包，部分打开包裹的人出现身体不适。（news2）

韩联社说，韩国国务调整室24日发布新闻稿称，反恐中心近期与有关机构就可疑国际包裹是否与恐袭有关进行了联合分析，并得出上述结论。国务调整室表示，考虑到未接到恐袭相关情报，并且有关事件并未造成人员伤亡，反恐中心研判，涉案国际包裹与恐袭无关。韩方情报侦查部门正与国际刑警组织等海外机构联合开展调查。报道提及，此前，韩国蔚山市一家残疾人福利设施本月20日首次报告收到疑似含有毒气体的包裹，随后持续5天出现类似报告。截至24日上午5时，有关部门共接到2141起收到可疑国际包裹的报警，其中有1462起是误报或咨询。报道说，韩国国务调整室就蔚山市第一起报警表示，消防部门和警方等初步调查机构回收涉案包裹并对其进行第一次检查，但未检出化学、生物学、放射性相关物质。之后，涉案包裹交由国防科学研究院进行缜密检查，也未检出危险物质。该设施3名负责人在打开涉案包裹后出现头晕、呼吸困难症状，已于22日出院。
