# 2023年8月3日，沙特阿拉伯航空公司联合沙特航空连通计划新开吉达至北京直飞航班，打通了中国北部与沙特的直达航线。（news2）

8-7 21:32，正文： 中新网北京8月7日电 记者7日获悉，沙特阿拉伯国营载旗航空公司 — 沙特阿拉伯航空公司联合沙特航空连通计划(ACP)，现已新开吉达 — 北京直飞航班。此举将进一步加强沙特与中国之间的双边关系，充分体现了双方深化合作的坚定承诺。 新航线于当地时间2023年8月3日正式开通，首航航班由吉达直飞北京。该航线的开通将促进双边旅游业协同发展。 作为2023年开通的第九条新国际航线，这一新增的战略性航线与沙特“2030年愿景”相一致，该愿景旨在到2030年实现每年游客总数达到1亿人次的目标。 沙特航空连通计划预计将于2023年下半年或2024年上半年开通更多往返沙特的航线，进一步拓展其航空网络，提升国际航空通达性。这一扩张在国际航空运输协会(IATA)对沙特阿拉伯全球航空连通性的评级从2019年的第27位跃升至2022年的第13位中也有所体现。 中国是沙特航空连通计划的优先发展市场。
