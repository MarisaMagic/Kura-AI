# 2023年8月1日，由五矿二十三冶投资建设的青海省察汗诺互通转体桥成功完成转体。（news2）

从空中俯瞰，总体设计走向和线型，如同一个巨大的'如意结'。”中交一公局集团青海乐化高速项目经理王震雄介绍说，全长1378米的斜沟5号特大桥，左右两幅各拥有12套连续刚构，最高墩达91米，纵坡达到3.9%，连续超高横坡为4%，最小转弯曲线半径仅为400米，几乎均达到行业设计极限，为典型的“大纵坡、高横坡、小半径”桥梁。记者了解到，施工期间，项目先后获得96项发明专利、实用新型专利、省级工法及QC等科研成果。据了解，乐化高速全线2024年建成通车后，将实现区域高速成网，对推动青海海东市域乐都、化隆、民和、循化等各县区的互联互通、改善沿线地区交通条件、增强辐射能力、促进瞿昙寺等地方旅游发展具有重要意义。(完)
，正文：中新网荆门8月15日电(高仕红 古建敖) 由中铁十一局集团承建的沪渝蓉高铁跨浩吉铁路首座转体桥15日实现转体。
