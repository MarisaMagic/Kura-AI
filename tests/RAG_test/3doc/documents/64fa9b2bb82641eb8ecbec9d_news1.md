# 2023年7月24日，2023中国杏花村国际酒业博览会暨“汾清天下·杏花村汾酒专业镇全国行”新闻发布会在北京举行，吕梁市委常委、副市长刘晋萍宣布，8月19日到21日，该博览会将在山西吕梁市汾阳举办。（news1）

展出现场吸引了众多媒体记者和观众驻足观看，大家或拍照打卡，或合影留念，直观感受了汾阳清香型白酒的魅力和强劲的城市发展脉搏。吕梁市委常委、副市长刘晋萍，山西省工信厅总工程师高向阳，中国酒业协会秘书长何勇，汾酒集团党委专职副书记、副董事长李振寰，汾阳市委副书记、市长贾永祥共同启动汾阳产业工人肖像艺术公益展，并和出席2023中国杏花村国际酒业博览会暨汾清天下·杏花村汾酒专业镇全国行推介活动的与会人员共同观看了展览。
