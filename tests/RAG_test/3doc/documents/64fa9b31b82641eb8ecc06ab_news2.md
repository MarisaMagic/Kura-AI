# 2023年7月25日，贵州省应急管理厅在主题教育开展的背景下，做了深度的调查研究，推动解决应急管理突出问题，加强了生产经营单位全员安全生产责任制工作，提升了安全防范能力水平，同时还开展了“解剖式”调研，强化了正风肃纪，推动了作风转变。（news2）

举报/反馈
11月26日至28日,应急管理部部长王祥喜率队赴江苏省调研安全生产治本攻坚工作和国家综合性消防救援队伍第二批主题教育开展情况。他强调,要坚持以习近平新时代中国特色社会主义思想为指导,深入学习贯彻习近平总书记关于安全生产的重要论述,把主题教育与贯彻落实党中央决策部署结合起来,聚焦制约安全生产的重点难点问题开展排查整治和治本攻坚,有效防范化解重大风险,有力应对处置各类灾害事故。调研期间,王祥喜与江苏省委书记信长星、省长许昆林就安全生产和应急管理工作交换了意见。江苏省委常委、常务副省长马欣参加调研。在南京,调研组实地查看了扬子石化、江苏中旗科技等化工企业安全风险管控与预警平台建设、自动化控制和重大危险源管理工作,调研了城市安全风险综合监测预警平台建设运行等情况,深入街道了解基层应急管理能力建设情况。在徐州,实地调研了徐工集团、协鑫科技等企业隐患排查整治、新风险管控工作,
