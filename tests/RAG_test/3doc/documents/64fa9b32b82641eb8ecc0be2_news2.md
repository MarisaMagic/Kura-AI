# 2019年6月，柬埔寨少数民族妇女的16岁儿子杜丹在学校突然感到心脏不舒服，后被确诊患有先心病，随后成为柬中医疗合作项目的救助对象，前往中国云南省阜外心血管病医院进行治疗。（news2）

帕萨哈是“中国-老挝先天性心脏病联合筛查和治疗”医疗合作项目的受益患儿之一。帕萨哈生活在老挝北部城镇孟赛，爱运动，最喜欢打羽毛球。她回忆说：“手术前，我一动就累，跑一会儿就喘，有时还头疼，人很烦躁。”帕萨哈的父亲翁佩·苏利亚告诉新华社记者，女儿从小就性格乐观，爱运动，但特别容易累。翁佩常常要求孩子们写完作业后帮助家里做家务。“每当我叫帕萨哈帮忙时，她总说累。她和小朋友们玩一会儿就喘不上气。那时候，我没意识到她心脏有问题。”今年6月中下旬，在中国民间组织国际交流促进会协助下，中国医学科学院阜外医院、云南省阜外心血管病医院、中华慈善总会和云南省政府新闻办在老挝联合开展“中国-老挝先天性心脏病联合筛查和治疗”医疗合作项目。中国医疗组在老挝孟赛、琅勃拉邦、万象等地，对近6000名3岁至18岁的老挝中小学和幼儿园学生进行了先心病免费筛查。
