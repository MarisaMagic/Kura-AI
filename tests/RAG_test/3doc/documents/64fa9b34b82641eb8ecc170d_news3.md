# 2023年8月1日，由五矿二十三冶投资建设的青海省察汗诺互通转体桥成功完成转体。（news3）

据了解，乐化高速全线2024年建成通车后，将实现区域高速成网，对推动青海海东市域乐都、化隆、民和、循化等各县区的互联互通、改善沿线地区交通条件、增强辐射能力、促进瞿昙寺等地方旅游发展具有重要意义。(完)
，正文：中新网荆门8月15日电(高仕红 古建敖) 由中铁十一局集团承建的沪渝蓉高铁跨浩吉铁路首座转体桥15日实现转体。当日，在2套500吨自动连续张拉千斤顶的牵引下，历时85分钟，桥梁成功实现顺时针88°转体，横跨于运营繁忙的浩吉铁路上空。其成功转体，为沪渝蓉高铁后续架梁和铺轨施工奠定了基础。据施工方中铁十一局集团公司沪渝蓉高铁武宜段站前五标项目经理李明介绍，沪渝蓉高铁跨浩吉铁路特大桥50号墩转体T构重达6325吨，转体角度88°，是目前沪渝蓉高铁转体角度最大的转体桥。
