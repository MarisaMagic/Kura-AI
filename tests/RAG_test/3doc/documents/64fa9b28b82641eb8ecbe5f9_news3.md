# 2023年7月28日，安徽省网信办通报整治网络“自媒体”乱象情况，公布典型案例，共清理违规信息4万余条，依法处置违法违规“自媒体”账号2.7万余个，受理处置公众举报投诉6000余条，依法约谈违规“自媒体”平台账号责任人298人次。（news3）

举报/反馈
国家网信办8月1日通报，国家网信办近期深入推进“清朗·优化营商网络环境保护企业合法权益”专项行动，部署指导地方网信办积极受理处置涉企业、企业家的不法信息，督促微信、微博、抖音等网站平台快速核查处置涉企投诉举报。截至目前，重点网站平台清理涉企虚假不实等信息8.6万余条，依法依约处置账号8425个。通报称，网信部门依法严肃查处“全球电动车联盟”“电动车联盟网”“电动车717”“铑枪”等账号持续发布并集纳电动车企业、金融机构等负面信息，要挟相关企业与其开展高额商业合作的问题；查处“拉上窗帘”“网易航空”“基建不倒翁”“谭祖亮科技”等账号捏造、传播虚假不实信息，恶意抹黑攻击国产大飞机C919等违规行为，以及“新铁流”“铁君”“后视镜里de未来”“航空微读”等账号蹭炒涉企热点事件、传播涉企不实信息的问题。
