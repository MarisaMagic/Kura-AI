# 2023年7月20日，巴西圣保罗州，巴西航空工业公司及其子公司EVE公司宣布将建造“飞行车”工厂，生产电动垂直起降飞行器。（news3）

预计，这款飞行汽车将为阿莱夫航空带来7.5亿美元的收入，约合人民币54亿元。 今年7月，Model A垂直起降飞行汽车正式通过了美国联邦航空管理局的批准，预计将在2025年正式上市。这款飞行汽车采用了独特的设计风格，车身上方采用了前所未有的网状结构，驾驶座舱位于车身中央，四个轮子采用了封闭式设计，看起来科幻感十足。 值得一提的是，这款飞行汽车并没有采用外露式螺旋桨，而是将螺旋桨隐藏在网状车身内。四个螺旋桨分别安装在车身四角，结构简单。在起飞后，飞行汽车将以横向姿态前进，并采用特别设计的“旋转式万向节机舱”来保持稳定。 阿莱夫航空尚未公布该款飞行汽车的其他信息，但据外媒公布的数据，该车陆地续航里程为322公里，飞行续航里程为177公里。目前，包括吉利、小鹏、广汽在内的国产汽车厂商也在积极研制自己的飞行汽车，预计这些飞行汽车将在不久的将来出现在空中。本文属于原创文章，如若转载，请注明来源：马斯克的Model A飞行汽车预定量突破2500 218万起步https://news.zol.
