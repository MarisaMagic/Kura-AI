# 2023年8月10日，美国司法部特别检察官办公室向华盛顿联邦法院提议，自2024年1月2日开始审理前总统特朗普涉嫌试图推翻大选结果案。（news3）

(中央纪委国家监委驻中国进出口银行纪检监察组、湖北省纪委监委) 【编辑:田博群】 更多精彩内容请进入国内新闻
7-27 16:24，正文： 中新网7月27日电 综合美媒报道,当地时间26日，美国前总统特朗普表示，他将出庭作证，会在一场“世纪审判”上 “玩得开心”。此前，特朗普已被美国司法部告知其为2020年大选相关刑事调查目标。 资料图：美国前总统特朗普。 据彭博社报道，特朗普26日在他的社交媒体平台上表示，“我们将在法庭上与所有那些说总统选举结果没有被操纵和窃取的人一起玩得开心”，并表示这将是一场 “世纪审判”。 特朗普当天在另一条帖子中再次声称，自己是“检察官不当行为”以及美国司法部干预2024年大选的受害者。 据美国有线电视新闻网(CNN)此前报道，21日，美国佛罗里达州联邦地区法官艾琳·坎农宣布，特朗普的“密件案”庭审工作将于2024年5月20日开始，并将持续两周的时间。案件同样由美国司法部负责，特朗普在该案中不认罪。
