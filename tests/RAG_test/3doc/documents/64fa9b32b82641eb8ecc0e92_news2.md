# 近期，上汽集团官方发布，旗下高端新能源车型飞凡R7搭载了由均普智能研发定制与交付的国内首批量产的4D成像雷达，年产能60万颗。（news2）

此外，日本原子能规制委员会审查实施计划后，要求执行单位出示作业人员防辐射的具体措施，回收作业何时能够获批，尚无法预计。
据悉，均普智能在自动驾驶毫米波雷达、激光雷达、线控制动、线控转型等相关领域，为图达通、博世华域等知名智能驾驶及Tier1提供智能装配与检测生产设备和服务。2022年上半年，均普智能为图达通交付了年产能10万颗激光雷达产线，这是全球高性能激光雷达首次大规模量产；2022年9月公司定制长城魏牌的纯固态激光雷达产线，年产能100万颗激光雷达；2022年11月与博世华域合作研发制造线控转向系统等。
2022年，多款激光雷达量产车型重磅发布，激光雷达进入普及元年。随着国内外造车新势力智能驾驶系统纷纷启用激光雷达方案，全球汽车行业对于激光雷达的产能需求骤然攀升。均普智能（688306）方面透露，其即将为世界500强的汽车一级零部件供应商交付一条激光雷达装配与检测产线，投产后将年产100万颗激光雷达。
