# 2023年7月25日，江门海关通过“江关普法”品牌集群联动帮助江门优质食品农产品产业“强链”“补链”，并且在6月下旬对开平重点特色食品企业进行了专题普法活动。（news3）

绍兴市长施惠芳表示，绍兴将做深产业集群文章、“两链”融合文章、产业平台文章、企业梯队文章，为勇闯中国式现代化市域实践新路子，提供更加坚实、更可持续、更富优势的支撑。来源：中国青年报客户端
，正文：【来源：宝鸡市监局_监管动态】为进一步丰富“你点我检”活动内容，营造安全放心的消费环境，8月8日，麟游县市场监管局利用食品安全综合检测车开展“送检上门”服务活动，为市民现场提供食品快速检测和计量检定服务。活动现场设立快检服务站，为群众免费检测食用农产品中农兽药残留问题，免费检定血压计、压力表及中小型衡器，让群众“零距离”“沉浸式”了解和感受食品快检流程和计量检定过程；工作人员通过发放科普宣传手册、现场讲解等方式，宣传食品安全和计量知识，解答群众疑问。广告 他只是个小司机，伺候的却是一个富太太，小人物一步步平步青云扶摇直上！ ×本次活动为市民快速检测果蔬等农产品共36批次，结果全部合格；共检定血压计6台、小型电子计价秤15台。
