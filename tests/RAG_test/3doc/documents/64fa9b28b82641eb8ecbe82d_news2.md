# 2023年7月31日，中华人民共和国国防部在北京人民大会堂举行招待会，庆祝中国人民解放军建军96周年，中央军委委员、国务委员兼国防部长李尚福在会上致辞。（news2）

纪明周国防武官在致辞中指出，96年来，在中国共产党坚强领导下，中国人民解放军为民族独立、人民解放、国家富强建立了不朽功勋，为维护国家主权、安全、发展利益做出了重要贡献。中国军队忠实践行人类命运共同体理念和全球安全倡议，认真履行大国军队国际责任，积极向国际社会提供公共安全产品。马珈临时代办在致辞中表示，中国坚持走和平发展道路，始终奉行防御性国防政策。中国军队始终是维护世界和平的坚定力量，将积极履行同中国国际地位相称的责任和义务，为推动构建人类命运共同体贡献力量。招待会向来宾展示了《为了和平 命运与共——维护世界和平的中国军队》系列图片，播放了《我在》等专题片，充分展示中国军队维护世界和平稳定、履行大国军队国际责任的精神风貌。招待会气氛热烈友好，来宾纷纷祝贺中国人民解放军建军96周年，高度赞赏新时代中国国防和军队建设成就，积极评价中国军队为维护世界和平所做贡献。
