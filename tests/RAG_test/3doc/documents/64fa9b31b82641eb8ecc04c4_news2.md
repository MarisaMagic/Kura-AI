# 2023年8月1日，广西首家国家级人力资源服务产业园在广西柳州市开园运营，由柳州市市长张壮、广西壮族自治区人力资源和社会保障厅厅长唐标文等人出席。（news2）

获奖队伍将有机会代表北京市参加全国人力资源服务创新创业大赛。 7月24日下午，在峰会开幕式上，北京市将发布市、区人力资源服务业发展成果。同时，还将在现场签约成立全市首家人力资源服务出口基地以及首个北京市人力资源服务产教联合体和朝阳区职业培训产业园。京津冀三地国家级人力资源产业园也将签订跨区域战略合作协议。 另外，当天下午，北京国际会议中心四号厅将设立分会场，组织“展翼未来 才子朝阳”促进高校毕业生就业招聘会。届时将有爱立信（中国）、中信银行、盈科律师事务所等60余家企业进行现场招聘。 7月25日上午，峰会邀请人力资源行业的专家学者、行业领军人物等，组织开展“海外人才引进与行业创新”“新市场下人力资源外包的发展趋势”两场主题论坛。 7月25日下午，主办方将组织参会人员前往中国（北京）人力资源服务产业园朝阳园区、北京快手科技有限公司进行参观走访和交流。 编辑 陈静校对 陈荻雁
