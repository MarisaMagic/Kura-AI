# 2023年8月11日，第6号台风“卡努”进入朝鲜西南部地区，预计将以每小时15公里的速度向西北方向移动，强度逐渐减弱，11日夜间将移入我国辽宁省境内。（news3）

2023-08-11 11:37，正文：8月11日，辽宁省气象台发布消息，今年第6号台风“卡努”（热带风暴级）8月11日5时位于朝鲜南部，即北纬38.5度、东经126.3度，中心最低气压为994百帕，中心附近最大风力有8级（18米/秒）。而10日10时在韩国庆尚南道沿海登陆时，其中心附近最大风力有10级（28米/秒），这意味着“卡努”动能呈衰退之势。气象部门预计，“卡努”将以每小时15到20公里的速度向西北方向移动，强度逐渐减弱，沿朝鲜半岛西侧北上，12日早晨到上午移入我省丹东地区，以后逐渐变性为温带气旋。未来24小时台风路径预报。受6号台风“卡努”影响，预计11日丹东地区及清原、本溪县、桓仁有中雨，宽甸局部大雨。12日白天，大连、葫芦岛地区有小雨到中雨，其他地区有阵雨或雷阵雨。
