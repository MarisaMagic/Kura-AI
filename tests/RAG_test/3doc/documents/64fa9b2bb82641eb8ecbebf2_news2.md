# 2023年8月10日，国家发改委宣布自8月9日24时起，国内汽、柴油价格每吨分别提高240元、230元，北京92号汽油价格破8元。（news2）

zol.com.cn/827/8279056.html
，正文：近期，油价持续攀升，创下4月以来新高，连续六周上涨，创下一年多来最长连涨纪录。据预测，本周三（8月9日）24时，国内油价将迎来年内第16轮调整，这也将是今年第8次上调，92号汽油价格有望再次突破8元大关，这将进一步增加汽车车主的出行成本。 据相关机构测算，截至8月7日的第8个工作日，参考原油变化率为5.24%，预计汽柴油上调235元/吨，折合每升上涨0.18-0.20元。今年以来，国内成品油已经经历了15轮调价，汽柴油价格累计上调0.22~0.3元/升。按照此次价格上调实施，2023年成品油调价将呈现“8涨6跌2搁浅”的格局。 在国际油价方面，沙特决定将从7月开始的日均100万桶的自愿减产石油措施延长至9月底，预计9月份石油日产量将在900万桶左右。这是沙特在今年7月将日均100万桶的自愿减产石油措施延长至8月后的第二次延长。
