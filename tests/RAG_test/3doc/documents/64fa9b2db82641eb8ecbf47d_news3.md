# 2023年8月17日，北京世界机器人大会上，中国电子学会副理事长兼秘书长陈英发布了《中国机器人技术与产业发展报告（2023年）》。（news3）

本届大会以“开放创新 聚享未来”为主题，由北京市人民政府、工业和信息化部、中国科学技术协会主办，中国电子学会、北京市经济和信息化局、北京经济技术开发区管委会承办。中国电子学会副理事长兼秘书长陈英介绍了2023世界机器人大会筹备情况以及本届大会的突出亮点。北京市经济和信息化局副局长苏国斌、中国科学技术协会科学技术创新部副部长许光洪、工业和信息化部装备工业一司副司长汪宏依次发表讲话。北京经济技术开发区管委会副主任刘力主持发布会。据介绍，2023世界机器人大会得到25家国际机构支持。
