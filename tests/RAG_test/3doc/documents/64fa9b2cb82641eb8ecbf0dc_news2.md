# 2023年8月10日，朝鲜领导人金正恩在劳动党中央军事委员会会议上下令朝鲜军队加强战备，并任命李永吉为新总参谋长。（news2）

会议分析,那些破坏朝鲜半岛地区和平与稳定的军事蠢动,通过将之彻底牵制的进攻性军事应对方案,并把做好一切战争准备,有事时以压倒性战略遏制力一举粉碎敌人的攻击,同时采取多发性军事攻势的问题列入议程进行讨论。金正恩概括和分析当前朝鲜半岛地区形势,并作了进一步做好军队战争准备的纲领性结论。会议解除朴秀日大将的总参谋长职务,任命李永吉次帅为新总参谋长,任免和调动了主要编制指挥成员。(责任编辑:贺翀 )
据朝中社6日报道，朝鲜劳动党总书记、国务委员长金正恩３日至５日前往重要军工厂，了解军工政策核心目标执行情况。报道称，金正恩视察了包括超大口径火箭炮弹、狙击武器、战略巡航导弹及无人攻击机发动机等生产厂，具体了解了近期取得的技术及生产工序现代化进展情况和现行生产情况。当地时间2023年8月6日，朝鲜，朝鲜最高领导人金正恩视察一个大型军工厂，正在试射新武器。
