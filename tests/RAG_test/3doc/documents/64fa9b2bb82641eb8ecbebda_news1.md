# 2021年8月8日，财政部和农业农村部针对黄淮、华北、东北等地受台风“杜苏芮”影响，农作物受灾、农业生产设施损毁情况，紧急下达农业生产防灾救灾资金7.32亿元。（news1）

近日，受台风“杜苏芮”影响，海河流域遭遇严重洪涝灾害。天津、河北、河南先后启用了海河流域8个国家蓄滞洪区，蓄洪18.47亿立方米，有效减轻了下游地区防洪压力。 8月9日，财政部、水利部紧急预拨10亿元，对国家蓄滞洪区运用期间民众的农作物、专业养殖、经济林、住房、家庭农业生产机械等水毁损失予以补偿，帮助受灾民众尽快恢复正常生产生活秩序。 包括上述拨款在内，财政部近日接连拨出多笔资金，支持各地防汛救灾。 针对黄淮、华北、东北等地受台风“杜苏芮”影响，农作物受灾、农业生产设施损毁情况，财政部、农业农村部8日紧急下达农业生产防灾救灾资金7.
