# 2022年7月26日，中国少年儿童文化艺术基金会回应部分培训机构冒名参加“致敬英雄”全国青少年文化艺术创作主题教育竞赛并向家长收费的问题，强调该竞赛坚持公益性，未授权任何机构和个人以竞赛名义收取费用。（news1）

两军之间的合作关系也是中新关系中的重要组成部分。来宾们对中国人民解放军建军89周年表示祝贺，招待会在热情友好的气氛中结束。
原标题：关于不得冒用“致敬英雄”主题教育竞赛违规开展活动的严正声明严正声明近日，“致敬英雄”主题教育活动组委会收到反映，有未经授权的校外机构及相关人员以“致敬英雄”全国青少年文化艺术创作主题教育竞赛为名开展活动。上述行为严重侵害了公众利益，扰乱了正常的活动秩序，损害活动的社会声誉，组委会在此严厉谴责上述不法行为，并发布严正声明如下：“致敬英雄”全国青少年文化艺术创作主题教育竞赛于本年8月入列教育部2022-2025学年全国性竞赛白名单后，组委会正在筹划第五届竞赛启动事宜。目前，关于本届竞赛的赛事细则及实施方案尚未对外公布。组委会从未授权任何单位和个人开展本届竞赛的组织、征集、宣传、推广等工作。在此特提醒广大学生、家长和老师提高警惕，注意甄别，切勿上当受骗。
