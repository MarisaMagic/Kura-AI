# 2023年7月31日，株洲市交通运输局查处了三起典型案例，包括易建文无证驾驶出租车、株洲欣达货运有限责任公司雇佣无证驾驶员何海龙以及陈兵擅自改装运输车辆。（news1）

湖南好望达安全物流有限公司名下危险品运输车辆产生重点交通违法16起。醴陵市江南物流运输有限公司名下危险品运输车辆产生重点交通违法15起。株洲市一汽运有限责任公司名下危险品运输车辆均产生重点交通违法14起。株洲市天成联运有限责任公司名下危险品运输车辆产生重点交通违法9起。省内危险品运输车辆产生重点交通违法较多的车辆名单（超速、超载、疲劳驾驶、不按规定时间线路行驶、违反禁限行规定）株洲市天意汽车运输有限责任公司湘BA6255产生重点交通违法6起。株洲市一汽运有限责任公司湘BA2896，产生重点交通违法4起。常德宜华物流有限公司湘J09821、常德市昌盛物流有限公司湘JB2919、株洲欣达货运有限责任公司湘BA3301均产生重点交通违法3起。终生禁驾人员名单全省共32人被终生禁驾。其中因酒驾或者醉驾发生交通事故构成犯罪被终生禁驾9人，因造成交通事故后逃逸构成犯罪被终生禁驾23人。
