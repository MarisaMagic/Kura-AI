# 2023年07月24日至25日，团中央“青春心向党 奋进新征程”示范宣讲团在黑龙江进行宣讲活动，深入基层一线宣传贯彻习近平总书记重要讲话精神。（news2）

贵州日报天眼新闻记者 潘德玉编辑 王恬二审 陈曦三审 许邵庭举报/反馈
