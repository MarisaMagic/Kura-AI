# 2023年7月19日，由中铁十局参与承建的中泰铁路一期工程3-1标段在泰国曼谷签约，中铁十局与泰国国家铁路局等相关方共同签约。（news1）

中铁十局负责该标段的土建工程，主要建设内容包括路基、桥梁、涵洞等。（新华社、中铁十局集团公众号）中建西部建设中标印尼铜箔厂混凝土供应项目7月17日，中国建筑所属中建西部建设股份有限公司海外公司印尼厂中标浙江海亮股份有限公司年产10万吨高性能电解铜箔厂混凝土供应项目，签约方量10万方。该项目于6月20日在印尼吉配经济特区正式开工，总投资8.6亿美元。（中建西部建设公众号）上海电气中标埃及康翁波光伏项目升压站一次设备供货项目近日，上海电气输配电工程成套有限公司中标埃及康翁波500兆瓦光伏项目升压站一次设备供货项目。（上海电气公众号）中国港湾签约多哥卡拉大学城主体建筑工程项目近日，中国港湾签约多哥卡拉大学城主体建筑工程项目。该项目位于多哥卡拉市，工期11个月，主要建设内容为三栋教学楼和一栋行政楼。
