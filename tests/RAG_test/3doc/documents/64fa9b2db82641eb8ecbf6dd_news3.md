# 2023年07月24日至25日，团中央“青春心向党 奋进新征程”示范宣讲团在黑龙江进行宣讲活动，深入基层一线宣传贯彻习近平总书记重要讲话精神。（news3）

[责任编辑: ]",
为深入学习宣传贯彻习近平总书记在同团中央新一届领导班子成员集体谈话时的重要讲话精神，全面落实团十九大各项部署，近日，团中央“青春心向党 奋进新征程”示范宣讲团走进贵州，深入基层团组织、企业、街道社区，针对不同行业领域青年，开展面对面宣讲和互动交流。示范宣讲活动现场。本次示范宣讲邀请到广西医科大学马克思主义学院副教授、硕导、博士、教研室主任温丽华，常州大学团委副书记、常州大学马克思主义学院副教授、博士曾晨，团十九大代表、贵州磷化（集团）有限责任公司团委书记田茂芳，团十九大代表、广西广播电视台第四团支部宣传委员李新蕊为大家集中授课。
