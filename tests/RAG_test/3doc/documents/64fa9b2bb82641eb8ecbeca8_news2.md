# 2023年7月25日，江门海关通过“江关普法”品牌集群联动帮助江门优质食品农产品产业“强链”“补链”，并且在6月下旬对开平重点特色食品企业进行了专题普法活动。（news2）

据悉，2017年全省食品安全宣传周活动自6月29日开始至7月13日结束。在启动仪式之前，省食安办已先期启动“第六届江西省食品安全知识竞赛”，省食品药品监管局开展了食品“四小四进”宣传活动、防范自采自食野生蘑菇中毒宣传等预热活动。启动仪式之后，还将有6家厅局开展“厅局主题日”宣传深化活动。省食安委成员单位联络员，南昌市、东湖区食安委成员单位负责同志，执法人员代表、食品企业代表、市民代表、志愿者代表、新闻媒体记者以及周边社区群众共800多人参加了现场活动。扫一扫在手机打开当前页打印本页关闭窗口
6月28日，深圳海关举行“进口食品企业安全责任年”启动仪式。深圳海关、深圳市市场监督管理局、盐田区政府等单位以及60余家深圳关区进口食品行业协会、企业代表参加活动。
