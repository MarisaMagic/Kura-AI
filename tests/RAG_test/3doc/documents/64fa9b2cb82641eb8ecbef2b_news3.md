# 2023年8月2日，武汉轨道交通12号线青菱站至罗家村站区间右线由武汉地铁集团、中铁开投集团投资建设、中铁四局承建的盾构区间顺利贯通。（news3）

12号线青菱站至罗家村站区间右线顺利贯通。记者刘斌摄上午9时30分，长江日报记者来到位于白沙洲的12号线青菱站，建设者们都在静静等待12号线首台盾构机破洞而出的激动时刻。当天，晴空万里，阳光直射至17米深的车站，掘进的“井冈山5号”盾构机刀盘转动，冲破最后一层障碍物，成功出洞。武汉地铁股份公司业主代表陆鹏介绍，12号线青菱站至罗家村站区间右线全长874米，3月8日由罗家村站始发，历时4个月顺利完成区间贯通任务，也是12号线全线第一个贯通的区间。周边有20余个小区，还有医院、学校、商业体等，12号线建成后这里的市民出行将非常便利。12号线青菱站至罗家村站区间右线顺利贯通，建设者们拿起手机记录这激动人心的时刻。记者刘斌摄施工方中铁四局该项目经理徐小龙介绍，青罗区间地质环境复杂，由于在软土地层掘进，500吨重的盾构机极易下沉，掘进姿态控制难度较大，同时还要下穿既有构筑物电力隧道和雨水箱涵。
