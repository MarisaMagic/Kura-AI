# 近日，朗进科技表示，将以技术为先导，以满足客户需求为目标，以实现绿色节能、助力国家“双碳”目标为己任，不断推出更具有挑战性和优越性的整体温控解决方案。（news1）

在节能减排方面，朗科科技坚持绿色发展理念，将绿色低碳理念融入公司日常运营中，在促进自身节能减排的同时，公司深研存储前沿技术，助力我国数据存储领域实现绿色低碳、为实现我国数字经济的稳定发展提供坚实的安全保障，积极促成能源消费强度和总量双控(能耗双控)、从而实现节能降碳减污协同增效以及生态环境质量的持续改善。在公益领域，朗科科技的蓝铅笔公益计划以十年为期，在2021年11月至2031年10月间，将蓝铅笔科普教室推广至100所学校，帮扶中小学生10万名，形成具有中国特色、可复制、可推广的经验，从而推动更大区域的蓝铅笔公益计划落地，让科学的精神遍地开花。未来，朗科科技仍将不断追求技术创新，为用户提供更好的存储及解决方案和服务。公司将始终将责任理念与企业发展深度结合，服务国家战略、服务社会发展需要，携手各利益相关方共护“为国担当、为民造福”的初心。
