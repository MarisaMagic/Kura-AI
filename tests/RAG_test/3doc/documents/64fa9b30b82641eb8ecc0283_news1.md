# 2023年8月4日，美国夏威夷州首府火奴鲁鲁举办中国海南之夜活动，海南省副省长陈怀宇和夏威夷州副州长西尔维娅·卢克出席，探讨扩展和深化共赢合作的机会。（news1）

贝合纳(Bernard Gollondo Balamoto)、OIiver k.Chimphano，Idriss Ahmat Djebere分别介绍了中非共和国、马拉维共和国和乍得共和国的投资环境和机遇。Idriss Ahmat Djebere表示，希望双方继续加强各层级对话与沟通，建立全面战略合作伙伴关系，实现经济高质量发展。中国及非洲国家的商协会及企业代表也分享了在中非经贸合作过程中积累的经验智慧。本次论坛由福州市人民政府、环球时报社、福州新区管委会、福建自贸试验区福州片区管委会主办，环球网、福州市商务局承办，是2023“一带一路国际商协会大会”的重要组成部分。(完)举报/反馈
▲ 这是8月10日拍摄的美国夏威夷州毛伊岛著名旅游城镇拉海纳野火过后的景象。美国夏威夷州毛伊岛8日燃起至少三处野火，过火面积逾800公顷。截至10日，野火造成至少53人死亡、约千人失联，超万户家庭断电。此外，野火还造成上千座建筑物被毁，岛上著名海滨度假小镇拉海纳几乎化为灰烬。
