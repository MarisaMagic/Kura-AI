# 2023年8月，华特迪士尼公司决定在其流媒体平台迪士尼+上不播放与土耳其“国父”穆斯塔法·凯末尔·阿塔图尔克相关的《阿塔图尔克》系列剧集，引发土耳其方面的批评。（news3）

报道称，记者在尼日尔首都尼亚美注意到，法国国际广播电台和法兰西24电视台的节目，从当地时间3日下午就接收不到了。一位尼日尔高级公务人员称，这两家媒体的信号“在新军事当局的指示下被切断了”。法国外交部在一份声明中批评说：“在尼日尔，针对媒体的措施属于政变始作俑者们实施的独裁镇压。在将尼日尔共和国总统扣为人质之后，他们对民主代表们展开了专横的逮捕行动。法国谴责这些对基本自由的严重践踏。”报道称，在2日晚的电视讲话中，因领导军事政变而在尼日尔掌权的阿卜杜拉赫曼·奇亚尼将军表示，保卫祖国国家委员会“已经避免了采取任何镇压行动”。法国国际传媒公司3日在一份公告中批评说，法国国际广播电台和法兰西24电视台节目的中断，是政变发生一周后的“一次完全违背宪法和法律的决定”。据报道，该公司表示，当局的决定“进一步剥夺了该地区民众接触自由、独立和已查证新闻的权利”，这一地区“最近几个月已因为马里和布基纳法索的新闻审查遭受了此类情况”。
