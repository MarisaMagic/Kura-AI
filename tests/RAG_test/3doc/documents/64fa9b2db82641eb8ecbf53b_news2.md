# 2023年7月20日，巴西圣保罗州，巴西航空工业公司及其子公司EVE公司宣布将建造“飞行车”工厂，生产电动垂直起降飞行器。（news2）

双方在现场签署了首批100架AE200的采购协议。 沃飞长空表示，这次与华龙航空的合作标志着国内电动垂直起降飞行器（eVTOL）与公务航空领域的首次创新联合。未来，双方将推进eVTOL持续适航方面的标准审定，以及eVTOL垂直起降机场建设、航线运营等领域的进展。 去年11月，AE200电动垂直起降航空器已正式获得型号合格证（TC）申请的受理。这是中国民用航空局颁发的中国首张有人驾驶载人电动垂直起降航空器TC受理申请通知书。根据中国民用航空局最新颁发的《型号合格审定程序》，AE200电动垂直起降航空器型号合格审定工作正式启航。 获得中国民用航空局颁发的型号合格证（TC）后，AE200电动垂直起降航空器可用于空中游览服务等，后续扩展型号可用于航空医疗救护、航空物流、应急救援、空中执法等多样化用途。本文属于原创文章，如若转载，请注明来源：吉利科技集团华龙航空签署战略协议 首批100架AE200电动垂直起降航空器https://news.zol.com.cn/826/8267862.
