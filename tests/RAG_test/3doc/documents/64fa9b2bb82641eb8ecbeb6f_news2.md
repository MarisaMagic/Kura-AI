# 2021年7月27日，国家金融监督管理总局召开银行业保险业上半年数据发布会，发布上半年末银行业金融机构不良贷款余额4万亿元的数据。（news2）

住房租赁贷款同比增长90．2％。积极支持就业创业，创业担保贷款同比增长14．9％。银行业主要风险监管指标均处于合理区间。初步统计，上半年末银行业金融机构不良贷款余额4万亿元，较年初增加2021亿元。不良贷款率1．68％，同比下降0．08个百分点。商业银行逾期90天以上贷款与不良贷款比例为84．8％，保持较低水平。另据初步统计，上半年，商业银行累计实现净利润1．3万亿元，同比增长2．6％，增速较去年同期下降4．5个百分点。当天披露的数据还显示，上半年末，中国保险公司总资产29．2万亿元，同比增长9．6％。上半年，保险公司原保险保费收入3．2万亿元，同比增长12．5％，提供风险保障金额6930万亿元，赔款与给付支出9151亿元，同比增长17．8％。（完）
8月18日，国家金融监督管理总局发布了2023年二季度银行业保险业主要监管指标数据情况。数据显示，2023年二季度，银行业和保险业总资产稳健增长。二季度末，我国银行业金融机构本外币资产总额406.2万亿元，同比增长10.4%。其中，大型商业银行本外币资产总额171.
