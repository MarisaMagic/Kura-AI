# 2023年8月10日，朝鲜领导人金正恩在劳动党中央军事委员会会议上下令朝鲜军队加强战备，并任命李永吉为新总参谋长。（news1）

报道称，会议由朝鲜劳动党总书记、中央军事委员会委员长、国务委员长金正恩主持。朝鲜劳动党中央军事委员会委员出席。 报道称，会议分析了影响朝鲜半岛及周边地区和平稳定的军事行动，决定了遏制这些行动的“进攻性军事应对方案”。朝鲜劳动党中央军事委员会发布了重要的军事行动准则，该准则适用于朝鲜人民军前线扩大、改变行动范围以及行动计划。会议还一致决定，将积极开展实战演练并加强军事战备。 报道称，金正恩在会上对朝鲜半岛及周边地区的形势进行了深入分析和总结，并就进一步加强朝鲜人民军的军事战备进行指示。他呼吁积极进行实战演练，强调了加强军事装备的重要性。 据报道，会议还解除了朴秀日大将的总参谋长职务，任命李永吉次帅为总参谋长。
