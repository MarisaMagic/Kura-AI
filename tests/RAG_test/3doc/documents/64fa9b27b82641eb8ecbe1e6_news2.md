# 2023年8月11日，中南大学湘雅三医院眼科副主任医师曹燕娜在接受人民网记者采访时指出，由于暑期孩子们过度使用电子产品等原因，干眼症症状会越明显。（news2）

容易出现误诊、漏诊。因此,一旦有这些症状,家长要带孩子及时就医检查。此外,在平时要调整饮食,多吃水果蔬菜,养成良好的用眼习惯:“好在我们大部分孩子的干眼症不是特别严重,平时生活上面注意。比如说我们使用电子产品的时候要严格控制时间,强调一个叫做‘20-20-20’原则,就是每用眼20分钟,就向20英尺处,也就是6米以外的地方看20秒。”(来源:江苏广电融媒体新闻中心/郑伟 编辑/玉洁)",
"原標題:暑期警惕孩子患上干眼症近日,全國各地中小學生紛紛開啟暑假模式。孩子是放假了,可孩子們的眼睛卻更“忙”了,看書、看電視、看手機.這也導致一些孩子的眼部健康亮起了紅燈。“進入7月,眼科門診干眼症患兒一下子多了起來。如今,干眼症患者群體正在從成人擴展至學齡兒童,兒童患者在門診中佔了近1/3。
