# 2023年8月8日，美国陆军负责采购、后勤和技术的助理部长道格·布什宣布，首批“艾布拉姆斯”主战坦克已获准移交乌克兰，并预计将于2023年秋季运抵。（news3）

(完)
中新社北京8月8日电 综合消息:美国陆军负责采购、后勤和技术的助理部长道格·布什当地时间7日说,美国向乌克兰提供的首批“艾布拉姆斯”主战坦克已于上周末获准移交。俄外交部发言人扎哈罗娃7日表示,美国国务院关于俄罗斯拒绝与乌克兰进行和平谈判的说法是谎言。据美国有线电视新闻网报道,道格·布什表示,首批“艾布拉姆斯”主战坦克将按计划于今年初秋运抵乌克兰。报道称,美国已于5月开始在德国对乌克兰士兵展开坦克使用训练。这31辆“艾布拉姆斯”主战坦克已经进行了几个月的整修和装运准备工作。另据乌通社报道,美国可能在8日宣布向乌克兰提供价值2亿美元的军事援助,其中包括“爱国者”导弹和“海马斯”火箭炮弹药。据“今日俄罗斯”网站报道,扎哈罗娃7日在社交平台上说:“美国告诉乌克兰总统泽连斯基在2022年4月退出和谈,美国导致乌克兰于2022年9月通过禁止与俄罗斯谈判的法令。他们一整年都在宣称‘这不是谈判的合适时机’,
