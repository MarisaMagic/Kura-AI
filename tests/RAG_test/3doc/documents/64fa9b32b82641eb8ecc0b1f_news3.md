# 2023年7月27日，西安战士战旗杂技团在新加坡滨海艺术中心上演新版杂技芭蕾剧《天鹅湖》，新加坡总统哈莉玛亲临现场观看。（news3）

肩上芭蕾、斜杠、抖杠、钻圈、柔术、流星球、高空吊环、空竹、单手顶等30多个杂技节目，在展示高难度技巧的同时，注重剧目的审美和文化表达的方式，令观众们印象深刻。此次演出作为助力新加坡“总统挑战”慈善募捐义演首场演出，首场演出的所有收益将作为慈善基金，用于帮助当地生活的弱势群体。西演·西安战士战旗杂技团新版杂技芭蕾剧《天鹅湖》精彩纷呈的表演受到新加坡各界人士的热烈欢迎和高度评价。新加坡总统哈莉玛·雅各布到场观看演出，并为团队颁发了义演纪念杯。据了解，此次演出不仅可以让新加坡的观众欣赏到中国多元化的杂技艺术，还可以品鉴到来自中国西安的特色文创，为中新建交33周年，共建“一带一路”的合作，弘扬中华传统杂技艺术、展示中华文化自信起到良好推动作用。
