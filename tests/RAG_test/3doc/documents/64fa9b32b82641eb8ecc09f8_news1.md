# 2023年8月8日，美国陆军负责采购、后勤和技术的助理部长道格·布什宣布，首批“艾布拉姆斯”主战坦克已获准移交乌克兰，并预计将于2023年秋季运抵。（news1）

美国陆军负责采购、后勤和技术的主管官员道格·布什当地时间7日表示，美国向乌克兰提供的首批“艾布拉姆斯”主战坦克已于上周末获得批准，这批坦克正按照预期计划于初秋运抵乌克兰。美制“艾布拉姆斯”坦克 图源：美联社布什在新闻发布会上对记者说，这批坦克连同与其配套的所有物资，包括弹药、备件、燃料设备、维修设施，将先运往欧洲，然后再运往乌克兰。“所以你知道，这不仅仅是坦克，还有配套的所有设备，这仍在按照原定计划进行。”他补充道。CNN报道称，向乌克兰提供的31辆坦克已经进行了几个月的翻新和装运准备工作，并于上周末正式获批移交。RT报道称，美国承诺总共提供31辆坦克，可以装备乌军一个营。美国“政治”新闻网（Politico）7月下旬报道称，到9月，可能只有6到8辆坦克能够运抵乌克兰。根据西方媒体报道，美国军方今年5月开始在德国培训乌克兰士兵操作“艾布拉姆斯”坦克。五角大楼一名官员告诉记者，为期10周的培训将在8月结束。
