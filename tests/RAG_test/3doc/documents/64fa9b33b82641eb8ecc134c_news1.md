# 2023年8月13日，美国夏威夷州毛伊岛的野火造成至少80人死亡，约4500人流离失所，2207座建筑物被损坏或摧毁。（news1）

“数百座房屋被夷为平地，港口里面的船也被烧毁了。”急救人员表示，这是所见过最可怕的火灾。美国媒体称，这场野火已成为美国过去100年来致死人数第二高的火灾，仅次于2018年11月造成85人死亡的加州坎普山火。当地居民在毛伊岛附近捞出遗体，海堤上仍然漂浮着尸体，预计死亡人数还会上升。据媒体消息，美国夏威夷州毛伊岛警察局局长约翰·佩列蒂耶对媒体表示：“坦白说，我们也不知道全岛确切有多少人失踪”，他称岛上没有足够的救援力量，没有网络，也没有无线电广播，这给受灾期间的各类工作带来了极大的障碍。当地有关部门估算，目前仍和各方失联的人数大约有1000人左右。目前，野火主要集中在美国夏威夷州毛伊岛西部旅游区和内陆山区，夏威夷州紧急事务管理部门表示，野火始于当地时间8月8日，目前过火面积已超过800公顷。毛伊岛西部已经完全封锁，只允许应急人员出入和民众撤离。位于该岛西北部的海滨小镇拉海纳大部分地区已毁于火海。
