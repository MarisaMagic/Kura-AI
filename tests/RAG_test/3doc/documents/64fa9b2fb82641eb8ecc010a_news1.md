# 2023年7月27日，刑侦鉴识专家李昌钰因1985年一起谋杀案中涉嫌伪造证据被美国联邦法官裁定负有责任，李昌钰对此表示失望并否认捏造证据。（news1）

因侦破金门岛军饷盗窃案而一举成名，随后又陆续在美国破获多起重大案件，赢得“中国侦探”称号，名声全球。美国法官21日判决，旅美刑事鉴识专家李昌钰针对1985年一起谋杀案“伪造证据”负有责任，导致康涅狄格州2名没有犯下谋杀罪的男子入狱数十年。李昌钰有支付损害赔偿的责任，金额将由陪审团决定。综合美联社、《哈特福德日报》报道，美国康涅狄格州联邦法官当地时间21日裁定，现年84岁、以刑事鉴定闻名全美的纽黑文大学名誉教授李昌钰，必须为上世纪80年代一桩谋杀案中伪造证据负责。报道称，此案导致2名当年未满20岁的年轻人入狱超过30年，一旦定罪，李昌钰可能要为此付出数千万美元的赔偿。李昌钰回应被指伪造证据！▲李昌钰（图源：美联社）这起命案发生于1985年12月1日，康州新密尔福镇65岁居民卡尔陈尸住所，身中27刀，现场十分血腥。
