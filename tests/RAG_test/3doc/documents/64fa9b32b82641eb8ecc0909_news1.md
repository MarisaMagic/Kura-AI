# 2023年8月3日，沙特阿拉伯航空公司联合沙特航空连通计划新开吉达至北京直飞航班，打通了中国北部与沙特的直达航线。（news1）

据沙特航空3日消息，此举将进一步加强沙特与中国之间的双边关系，充分体现了双方深化合作的坚定承诺。新航线于当地时间8月3日正式开通，首航航班由吉达直飞北京，将为中国北部约1.65亿人口提供直达沙特的途径。该航线的开通不仅将促进双边旅游业协同发展，同时也标志着沙特阿拉伯与全球航空市场之间的国际合作正日益紧密。消息称，吉达至北京新航线是沙特航空2023年开通的第九条新国际航线，这一新增的战略性航线与沙特“2030年愿景”相一致，该愿景旨在到2030年实现每年游客总数达到1亿人次的目标。沙特航空连通计划预计将于2023年下半年或2024年上半年开通更多往返沙特的航线，进一步拓展其航空网络，提升国际航空通达性。沙特阿拉伯航空公司首席执行官考希（Ibrahim Koshy）表示：“航空连通性为此前前往沙特阿拉伯存在困难的地区提供了关键的便利条件。
