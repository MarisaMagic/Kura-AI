# 2023年7月25日，贵州省应急管理厅在主题教育开展的背景下，做了深度的调查研究，推动解决应急管理突出问题，加强了生产经营单位全员安全生产责任制工作，提升了安全防范能力水平，同时还开展了“解剖式”调研，强化了正风肃纪，推动了作风转变。（news3）

针对当前老旧电梯多且新增速度快等情况，开展电梯安全监管模式调研，推进实施《电梯监督检验和定期检验规则》《电梯自行检测规则》新规，保障电梯运行安全。针对新能源汽车持续爆发式增长的情况，制定《江西省电动汽车充电桩强制检定工作实施方案（试行）》，进一步提升各地充电桩检定能力建设，更好满足群众需求。江西省市场监管局坚持把检视问题贯穿主题教育始终，深入查摆不足、列出问题清单、抓好整改整治。截至目前，已制定31项整改措施。针对群众反映强烈的突出问题抓好专项整治工作，出台《江西省企业变更“一件事一次办”攻坚方案》，实施项目信息化开发建设；坚持“当下改”与“长久立”相结合，把推动主题教育的各项任务举措以制度形式固定下来、加以规范，切实融入日常、抓在经常，形成常态、发挥长效。坚持主题教育与中心工作“两手抓、两促进”。
