# 2023年7月26日，日本政府的数据显示，日本人口连续14年下降，而外国居民数量却再创新高。（news1）

责任编辑:赵桂金(EK003)
来源：港股那点事 格隆汇7月26日丨日本政府周三公布的数据显示，日本公民人口总数以有史以来最快的速度减少，而外国居民总数则创纪录地增至接近300万人。这些数据表明，外国公民在日本社会中发挥着更大的作用，以弥补日本人口的萎缩。日本总务省公布的截至2023年1月1日的居民登记数据显示，日本国民人口在2022年连续第14年下降，减少了约80万人，降至1.2242亿人。日本47个都道府县的居民人数首次全部减少。截至今年1月1日，在日本有住址的外国人数量为299万人，比一年前大增10.7%。 举报/反馈
据央视报道,日本的低出生率、少子化之势愈演愈烈,有估算显示,日本2023年全年的出生人数可能只有大约70万人,连续8年创新低。11月24日,日本厚生劳动省发布人口动态统计数据,2023年1-9月出生人数为56.9656万人,同比减少5.0%,同期结婚人数365478对,同比减少4.4%,丝毫没有上升的迹象。参考2023年1月以来的日本人口动态统计数据,日本综合研究所估算,按照目前的趋势,日本2023年全年出生人数约为72.9万人,
