# 2023年8月10日，美国司法部特别检察官办公室向华盛顿联邦法院提议，自2024年1月2日开始审理前总统特朗普涉嫌试图推翻大选结果案。（news1）

海外网8月11日电据美国《新闻周刊》10日报道,美国前总统特朗普对特别检察官提议的国会骚乱案开审日期并不满意,表示审判应该在2024年大选之后进行。美国司法部特别检察官办公室向法庭提议,自2024年1月2日开始审理特朗普涉嫌试图推翻大选结果案。特朗普当天在社交平台抱怨说系列刑事诉讼将干扰他的总统竞选活动。特朗普表示,1月2日处在重要的艾奥瓦州大选预选会议之前,检方将日期定在此时就是要对艾奥瓦州的选举进行最大程度干扰。特朗普还表示,对他的审判永远不应该进行,即使有必要的话,也应该放在大选之后进行。特朗普的律师尚未提交文件答辩,但可能会寻求推迟开审日期。特朗普预计在2024年大选年将面临“繁忙的法庭行程”,分别将于3月和5月接受纽约州商业欺诈案、联邦机密文件案的审判。特朗普坚称应在大选结束后进行审判,理论上来说,如果特朗普既被定罪又赢得大选,他可以赦免自己。(海外网侯兴川)catalogs:115955;contentid:11703641;publishdate:2023-08-11;
