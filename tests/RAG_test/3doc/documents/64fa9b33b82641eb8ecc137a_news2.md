# 2023年8月13日，在尼日尔首都尼亚美，尼日利亚伊斯兰高级学者代表团与尼日尔政变领导人阿卜杜拉赫曼·奇亚尼会面后，尼日尔军方表示愿通过外交途径解决当前问题，缓和与西非国家经济共同体的对峙局面。（news2）

另据路透社8月12日报道，西共体的一位发言人当日表示，该组织将派遣一个议会委员会前往尼日尔，与上个月夺取政权的政变领导人会面。这是该地区为恢复文官统治而作出的最后努力之一。报道称，尼日尔军方上个月关押了总统穆罕默德·巴祖姆并解散了民选政府，引起了地区大国的谴责。这些国家已经启动了一支待命的军事力量，称如果谈判失败，就将派遣这支军队作为最后的手段。然而据报道，以阿卜杜拉赫曼·奇亚尼将军为首的政变领导人拒绝了西共体、美国和其他国家的外交努力，引发了对贫困的萨赫勒地区将进一步陷入冲突的担忧。报道称，西共体议会12日举行会议，讨论在尼日尔采取进一步行动的问题。该发言人表示，尽管没有作出决定，但议会成立了一个委员会，计划会见尼日利亚总统提努布，以获得他的许可前往尼日尔。根据尼日利亚总统府消息人士的说法，一群尼日利亚知名伊斯兰学者也与提努布会面，以获得他的批准，提努布同意了他们的请求。他们的计划是到尼日尔会见当地宗教人士，以化解外交僵局。
