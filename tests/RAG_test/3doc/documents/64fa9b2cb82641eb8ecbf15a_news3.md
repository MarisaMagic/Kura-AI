# 近日，北约在立陶宛举行的维尔纽斯峰会上，日本、韩国、澳大利亚、新西兰四个亚太地区国家领导人再次获邀参会，北约加速东进亚太的动向引发关注。（news3）

报道认为，此事的背景因素是，北约成员国内部对所谓“中国威胁”的认识有差别。美国政府和斯托尔滕贝格认为，中国与俄罗斯的关系加深，军事实力提升，应对“中国威胁”是北约安全战略必不可少的内容。美国一直敦促日韩与北约扩大合作。日本首相岸田文雄和韩国总统尹锡悦也会出席此次北约峰会。报道称，法国等部分北约成员国重视与中国的经济关系，打心底里不愿刺激中国。马克龙4月率财界人士访华，受到了热情接待，空中客车公司与中国企业签署订单，一系列商务合作取得进展。报道称，中国强烈反对北约开设东京办事处的方案。法国是欧洲核大国，马克龙提出在安保和经济领域实现“战略自主”，也是出于对美国主导地位的抵触。外交人士透露：“马克龙尤其反对北约撇开法国推进开设办事处方案一事。”报道称，北约峰会将在立陶宛维尔纽斯召开，探讨的课题包括，瑞典加入北约的谈判、对乌长期援助框架的创设、斯托尔滕贝格任期延长一年等。
