# 2021年8月3日，俄罗斯能源与安全研究中心主任安东·赫洛普科夫在维也纳表示，美英澳三国的核潜艇合作信息不透明，加剧了核扩散风险，冲击国际核不扩散机制，威胁地区安全稳定。（news3）

柬埔寨首相洪森5日警告说，美英澳核潜艇合作是一场危险的军备竞赛的开始，如果这种情况持续下去，世界将面临更大的危险。东盟坚决反对核武器扩散。从程序上看，美英澳作为《不扩散核武器条约》缔约国，推进核合作需要得到国际原子能机构的认可。面对国际社会的一致谴责与反对，三国千方百计地在程序上做手脚，强行给核潜艇合作“洗白”。近两年来，从企图胁迫秘书处提出豁免三国核潜艇合作的保障监督方案，到利用总干事发布内容片面的误导性报告，再到谋求在机构大会决议中写入核潜艇合作“合法化”的修正案，美英澳通过一系列暗箱操作想为核潜艇合作“开绿灯”，但无一例外被“亮红灯”。这充分表明，三国核潜艇合作不是它们可以私自处理的，必须由机构成员国共同说了算。从规则上看，在国际原子能机构内讨论三国核潜艇合作问题，必须坚持真正的多边主义，遵守协商一致的原则。
