# 美化知识库 [来源N] 标注 — 上标小胶囊 + 点击跳转

## 目标

正文中模型输出的 `[来源N]` 目前以普通文本随 Markdown 渲染，观感差且无交互。改为：**主题色上标小胶囊数字**（ChatGPT/Perplexity 风格），hover 显示「文件名 · P页码」，点击平滑滚动到消息底部对应来源 chip 并闪烁高亮。纯前端改造，后端提示词、`sources` 数据结构、SSE 时序全部不动，风险最低，不新增依赖。

## 核心机制

`[来源N]` 是模型按提示词输出的纯文本；后端已有与编号一一对齐的 `sources` 数组（`index`/`filename`/`page_number` 等，SSE `sources` 事件 + 落库），前端已在消息底部渲染 chip 列表。改造点全部集中在共享的 Markdown 渲染工具 `web/src/utils/agentChatMarkdown.js`（主聊天页与 Agent 编辑预览面板共用的唯一渲染出口，markdown-it + DOMPurify）。

## 改动 1：`web/src/utils/agentChatMarkdown.js`

1. 新增自定义 inline rule：`md.inline.ruler.before('text', 'kura_citation', ...)`，正则前缀匹配 `^\[来源\s*([\d\s、,，]+)\s*\]`（兼容 `[来源 3]` 带空格、`[来源1、2]` 多编号），命中则 emit 自定义 token `kura_citation`，`meta.indices` 为拆分后的编号数组。放在 inline ruler 的原因是：代码块/行内代码中的 `[来源1]` 不会被解析成标注（inline 解析不进入 code token），避免误伤工具输出引用。
2. 新增 renderer 规则 `md.renderer.rules.kura_citation`：输出 `<sup class="kcite-group">` 内嵌多个 `<span class="kcite" data-kcite="N" title="文件名 · P页码">N</span>`（多编号用细逗号分隔）。`title` 从 `md.render(src, env)` 的 `env.kuraSources` 按 index 查表拼接。编号用 `md.utils.escapeHtml` 转义。
3. `renderAgentChatMarkdown(text, sources)` 加可选第二参 `sources`，构造 `env = { kuraSources }` 传给 `md.render(String(text), env)`。现有调用点无第二参时行为不变。
4. 文件顶部 `import './agentChatMarkdown.css'` 引入共享样式（v-html 内容不受 Vue scoped 样式影响，必须用非 scoped 样式；由 JS 统一引入，两个消费页自动生效）。

## 改动 2：新建 `web/src/utils/agentChatMarkdown.css`

- `.kcite-group`：上标定位、与正文的间距；
- `.kcite`：主题色小胶囊（浅色：primary 淡蓝底/深字；`html.dark` 暗色对应），圆角 999px，字号约 12px，hover 加深边框，`cursor: pointer`；
- `.kcite-flash`：闪烁高亮 keyframes（用于滚动到 chip 后的视觉反馈）。

## 改动 3：`web/src/views/agent-chat/index.vue`

1. 第 167 行：`v-html="renderAgentChatMarkdown(m.content, m.sources)"`，并在该 `.agent-chat-md` div 上加 `@click="onAgentMdClick"`（事件委托，v-html 内容无法绑 Vue 事件）。
2. `<script setup>` 新增 `onAgentMdClick(e)`：`e.target.closest('.kcite')` 取 `data-kcite` 值，在 `e.currentTarget.parentElement`（`.agent-chat-feed-body`，涵盖 md 与来源区）内 `querySelector('[data-kcite-chip="N"]')`；命中则 `scrollIntoView({ behavior: 'smooth', block: 'nearest' })` + 加 `.kcite-flash` 类，约 1.4s 后移除；未命中（模型编错号）静默忽略。
3. 来源 chip（第 173-196 行）：`<a>` 和 `<span>` 两个变体都加 `:data-kcite-chip="src.index"`；scoped style 里给 `.agent-chat-source-chip` 加 `scroll-margin-top`，避免滚动后被吸附头部裁切。
4. 同一编号在正文多处出现时全部指向同一 chip，天然支持一键反查。

## 改动 4：`web/src/views/agents/components/AgentEditorPreviewPanel.vue`

- 第 153 行改为 `renderAgentChatMarkdown(m.content, m.sources)`：预览面板里标注渲染成相同胶囊，hover 标题同样生效（该面板不渲染来源 chip，点击无目标自然无动作）。共享 CSS 随 JS import 自动带入。

## 明确不改

- 后端提示词（`agent_service.py:261`、`search_tool.py:117`、`image_search_tool.py:141`）、模型输出格式、`sources` 结构/SSE 时序；
- 复制按钮 `copyAssistantPlain` 仍复制 `m.content` 原文（含 `[来源N]` 纯文本），不受渲染层影响；
- 不引入任何新依赖（不需要 footnote 插件）。

## 时序与降级

- `sources` SSE 事件在内容流式完成后才到达：流式期间胶囊即时渲染（暂无 title），`sources` 到达触发 Vue 重渲染后自动补上 hover 标题；
- 已有 DOMPurify `html:true` 配置默认放行 `sup`/`span`/`class`/`title`/`data-*`，生成的标记可存活；若实测被剥离，在 sanitize 配置补 `ADD_ATTR` 即可；
- 历史消息（`sources` 落库）加载后同样生效。
